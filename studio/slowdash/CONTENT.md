## 1. 별 틀(모든 판 같음)과 ★★★ 공짜 별 문제
- ★ 지나가기 · ★★ 한 번에 N 베기 · ★★★ 꼬리 하나도 안 잃기.
- '한 번에'에 들어가는 것: 통 펑으로 함께 날아간 적, 쓰러지지 않은 대장 타격(`doDash`가 n에 이미 센다).
- **N 확정 기준**(24시드)
  - 장인 ★★ ≥ 0.8이고, 버릇 4종 각각 ★★ ≤ 0.2여야 한다.
  - 장인이 못 미치면: N을 1 내리거나 줄이 되는 자리의 간격을 넓힌다.
  - 버릇이 넘치면: N을 1 올리거나, 첫 웨이브만으로는 N이 안 되게 다시 배치한다.
- **1-1·1-2의 ★★★ 결정: '선물 별'로 둔다.** 판을 깨면 ★★★가 저절로 들어온다. 결과 화면의 꼬리 3가닥은 금빛이다.
  - 이유 ① 별 칸 셋이 첫 판부터 다 보여야 1-3에서 처음 맞을 때 "아, 이게 꼬리 별이구나"를 바로 안다. 공방 교훈인 '하나로 통일 + 알려 주기'와 같다.
  - 이유 ② 다른 안은 다 더 나쁘다.
    - 1-1·1-2만 조건을 바꾸면 고정 틀이 깨진다.
    - 허수아비가 때리게 하면 1-3의 새것을 미리 쓰게 되고, 처음 10초 안전(F2)도 위험해진다.
    - 별 칸을 비워 두면 "못 딴 별"로 읽히고, 월드 잠금 계산도 꼬인다.
  - 이유 ③ 비용이 작다. 월드 1의 별 30개 중 2개다. 월드 잠금은 18개라서 나머지 28개 중 16개를 실력으로 따야 한다.
  - 측정: 1-1·1-2는 F7·F8 ★★★ 집계에서 뺀다(FUN 개정 ⓪과 같다). 두 판에서 별을 가르는 것은 ★★뿐이고, 그래서 1-1·1-2의 N은 버릇 봇에게 공짜가 아니게 짰다.
  - 1-3부터: 모든 판에 `wait`로 강제로 들어오는 웨이브와 휘두름·화살이 있다. 그래서 버릇 봇의 평균 맞음이 1 이상이어야 한다(공짜 별 0, FUN M0 빨간불 3).

## 2. 판별 설계

### 1-1 대숲 입구 · 꿰기 · N4 · G0 70 · 시작 [.5, 1.17] · 뒤집기·흔들기 없음
```
w1 { need:0, wait:1e9, foes:[['dummy',.5,.95,0],['dummy',.5,.79,0],['dummy',.5,.63,0]] }   // 바로 서 있음(instant)
w2 { need:0, wait:1e9, foes:[['dummy',.24,1.0,0],['dummy',.41,1.0,0],['dummy',.59,1.0,0],['dummy',.76,1.0,0]] }
w3 { need:0, wait:1e9, foes:[['dummy',.73,.58,0],['dummy',.62,.69,0],['dummy',.51,.80,0],['dummy',.40,.91,0],['dummy',.29,1.02,0]] }
```
- 첫 3초: 손가락 아이콘이 '꾹'을 보여 준다. 셋을 꿰면 ×3이 나오고 부엉이가 운다. w1에서 닌자는 y≈.55에 내리므로 w2 가로줄 위에 있지 않다.
- **느린 시간이 필요한 이유**: 이 판에는 시간 압박이 없다. 꾹은 '×N 미리 보기를 보는 시간'이다.
  - w2 가로줄에서 ×4를 내려면 줄 끝(.08, 1.0)에 서서 ±3° 안으로 겨눠야 한다. 칼 폭은 ±.068이다.
  - 꾹 없이 떼면 몇 명이 꿰이는지 보이지 않는다.
- **막 누르면 손해인 이유**: 맞을 일은 없지만 ★★가 없다. 아무 데서나 그으면 1~2명씩만 벤다.
  - w2와 w3은 줄의 연장선이 닌자가 서 있는 자리를 지나지 않게 놓았다. 먼저 줄 끝으로 옮겨 서야 ×4가 된다.
  - w2에서는 손가락이 이것을 시범으로 한 번 보여 준다(GDD §7).

### 1-2 갈림길 · 외톨이 남기기 · N4 · G0 40 · 시작 [.5, 1.17]
```
w1 { need:1, wait:1e9, foes:[['dummy',.38,.95,0],['dummy',.26,.73,0],['dummy',.14,.51,0],['dummy',.84,.56,0]] }  // 3줄 + 먼 외톨이
w2 { need:0, wait:1e9, foes:[['dummy',.72,.74,0],['dummy',.60,.92,0],['dummy',.48,1.10,0],['dummy',.16,.98,0],['dummy',.28,.98,0]] }
w3 { need:0, wait:1e9, foes:[['dummy',.20,.62,0],['dummy',.40,.62,0],['dummy',.60,.62,0],['dummy',.80,.62,0],['dummy',.30,1.05,0],['dummy',.70,1.05,0]] }
```
- 의도: w1 3줄을 베고 외톨이 하나만 남으면 2.5초 뒤 w2가 들어온다. 외톨이(.84, .56)는 w2의 셋과 한 줄(.48, 1.10 → .84, .56, 길이 .65)이 된다.
- **느린 시간이 필요한 이유**: ×4를 내는 자리(줄 아래 끝 .40, 1.22 근처)는 꾹 미리 보기로만 찾을 수 있다.
  - 그 줄을 끝까지 그으려면 먹이 5 + 22×.79 ≈ 22.4 이상 있어야 한다. 모자라면 선이 짧아져 ×3에서 멈추고, 그것도 미리 보기에 보인다.
- **막 누르면 손해인 이유**
  - 외톨이를 먼저 베면(값 ≈ 20, 받는 먹 +7) ×4 기회가 사라진다.
  - 1명짜리 획을 이어 그으면 G0 40이 금방 바닥나고, 깡충만 뛸 수 있게 된다. 그러면 w3의 긴 4줄(길이 .74)에 닿지 못한다.

### 1-3 오솔길 · 참기 · N3 · G0 60 · 시작 [.5, 1.12] · 첫 맞음 리플레이
```
w1 { need:1, wait:1e9, foes:[['sword',.10,.80,1],['sword',.22,.90,1],['sword',.12,1.02,1],['sword',.24,1.06,1]] }
w2 { need:1, wait:600, foes:[['sword',.90,.86,2],['sword',.78,.92,2],['sword',.90,1.04,2],['sword',.62,.52,3],['sword',.74,.56,3]] }
w3 { need:1, wait:660, foes:[['sword',.10,.70,1],['sword',.22,.78,1],['sword',.90,.70,2],['sword',.78,.78,2],['sword',.44,.52,3],['sword',.56,.52,3]] }
```
- 의도: w1은 같은 방향 쌍 둘이다(방향 차 25°). 지금은 2명 줄 둘이고, 닌자 쪽으로 걸어와 거리 .25 안에 들면 3~4명이 한 줄이 된다.
- **느린 시간이 필요한 이유**: 칼잡이는 걷다 .1에서 멈추고 칼을 든다(42틱 × 1.5 = 1.05초).
  - 셋째가 칼 폭 안으로 들어오는 순간부터 첫째가 휘두를 때까지 실시간으로 0.3~0.5초다. 사람 반응 0.5초와 같거나 짧다.
  - 꾹(×0.12)이면 이 틈이 2.5~4초가 된다.
- **막 누르면 손해인 이유**
  - 일찍 그으면 1~2명만 벤다. 한 명은 +7인데 획 값은 10~20이라 먹이 줄어든다.
  - 먹이 바닥나 깡충만 남으면, 양쪽에서 몰려든 칼잡이 반달 안에 갇힌다.
  - 헛방 벌(개발 메모 2)이 있으면 바로 옆 칼잡이가 그 틈에 휘두른다.

### 1-4 두 갈래 · 옮겨 서기 · N4 · G0 55 · 시작 [.5, 1.10]
```
w1 { need:1, wait:1e9, foes:[['sword',.16,.80,1],['sword',.28,.80,1],['sword',.72,.80,2],['sword',.84,.80,2]] }         // y .80 가로축
w2 { need:1, wait:720, foes:[['sword',.50,.52,3],['sword',.50,.64,3],['sword',.50,.76,3],['sword',.44,1.22,1],['sword',.56,1.22,2]] }  // x .5 세로축
w3 { need:1, wait:720, foes:[['sword',.18,.56,1],['sword',.28,.66,1],['sword',.62,1.00,2],['sword',.72,1.10,2],['sword',.82,1.20,2]] }  // y=x+.38 대각축
w4 { need:0, wait:720, foes:[['sword',.30,.52,3],['sword',.40,.52,3],['sword',.60,.52,3],['sword',.70,.52,3]] }          // y .52 가로축
```
- 의도: 웨이브마다 두 무리가 축 하나 위에 있다. 축 끝(예: w1은 .07, .80)으로 빈 획(값 ≈ 15)을 먼저 그어 서면 양쪽이 같은 방향에서 다가와 줄이 된다.
- **느린 시간이 필요한 이유**: 가까운 무리가 칼을 드는 0.7초(너그러움 끝) 안에 먼 무리가 칼 폭 안으로 들어와야 한다. 겹치는 틈이 실시간으로 0.4초 안팎이다.
- **막 누르면 손해인 이유**
  - 가운데에 머물거나 가운데로 그으면 두 무리가 반대쪽에서 동시에 칼을 든다. 반달 두 개가 겹쳐서 피할 곳이 없다.
  - 빈 획을 두 번 하면 먹 55가 바닥나 ×4 획을 그을 수 없다.

### 1-5 달빛 언덕 · 마감 · N4 · G0 50 · 시작 [.5, 1.15]
```
w1 { need:1, wait:1e9, foes:[['archer',.30,.50,3],['archer',.70,.50,3],['sword',.12,.84,1],['sword',.12,.98,1],['sword',.24,.91,1]] }
```

- 의도: w2 오른쪽의 세로 4명은 위나 아래 끝에 서야 ×4다. 그런데 기다리는 동안 화살병이 1.5~2.5초마다 겨눈다.
- **느린 시간이 필요한 이유**
  - 화살병은 겨누는 1.2초 중 마지막 18틱(0.3초)에 방향을 굳힌다. 화살은 초당 .96을 날아 0.5~0.7초 만에 닿는다.
  - 굳은 걸 보고 비키기(0.3초)도, 날아오는 화살을 선으로 끊기도 실시간 반응 0.5초로는 못 한다. 꾹 상태에서만 된다.
- **막 누르면 손해인 이유**
  - 화살병은 닌자가 .24 안으로 오면 물러선다. 그래서 막 그으면 헛방이 나고 먹(획당 10~20)이 샌다.
  - 줄을 만들 때까지 버티지 못하면 칼잡이를 1명씩 베게 되고, 그 사이 화살 마감이 계속 찾아온다.

### 1-6 바위 고개 · 돌아가기 · N4 · G0 60 · 3웨이브 16명 · 시작 [.5, 1.15]
- w1 방패 1 + 칼잡이 3(방패 뒤 같은 줄) · w2(need 1, wait 780) 방패 2 + 칼잡이 3 · w3(need 0, wait 780) 방패 2 + 칼잡이 4 + 화살병 1.
- 너그러움 [1.5, 1.2, 1]: 새 적 판이라 숨 고르기. 톱니 곡선용이다.
- **느린 시간이 필요한 이유**: 방패는 초당 1.8라디안으로 돈다. 옆으로 지나친 뒤 등이 보이는 시간이 약 0.8초다. 그 안에 등 + 졸개 셋을 한 줄로 겨눠야 한다.
- **막 누르면 손해인 이유**: 앞에서 그으면 '챙' 튕겨 획이 방패 앞에서 끝난다. 먹은 나가고, 닌자는 방패 칼 범위(.13) 안에 내려서 맞는다.

### 1-7 숯막 마당 · 꾀어 모으기 · N5 · G0 45 · 3웨이브 17명 + 통 4 · 시작 [.5, 1.17]
- 미리 놓인 통 [.30, .80] · [.70, .80] · [.50, 1.0].
- w1 칼잡이 5(왼쪽 3 · 뒤 2) · w2(need 1, wait 780) 칼잡이 4 + 방패 1 + 통 1 · w3(need 0, wait 780) 칼잡이 6 + 화살병 1.
- 무리는 4명 이하로 들어온다. ×5는 통 펑으로만 닿는다.
- **느린 시간이 필요한 이유**: 통 곁(.2 밖)에 서 있으면 칼잡이가 통 둘레로 모인다. 모인 순간부터 첫 칼이 떨어질 때까지 0.7초다.
