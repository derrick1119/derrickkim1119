# FUN.md — 🎈 풍선 팡 연쇄 재미 기준표 (🧪 FUN QA v1.2, C002 개정)

> v1.2 (C002, 코드보다 먼저): 하트가 없어지자 점수비가 "완주했나"만 재게 되어(무작위 봇도 끝까지 감), **숙련 격차 = 시도당 별 비**(모은 별 ÷ 판 시도 수, 실패 시도는 0별)로 바꾼다. 범위 2.5~5×는 그대로.
> v1.1 (C002, 코드보다 먼저): 하트 폐기에 맞춰 사망 → **막힘**, 3회 안 클리어 추가, 첫 톡 연쇄는 **중앙값**, 겹침 상한 1판 분리, 판당 시간은 봇 시계로 이름 변경, 첫 팡 시간 측정 정의.

측정: `npx tsx studio/balloonpop/funqa.ts` → `reports/funqa.json`.
봇 (C001 개정):
- **처음** = 아무 데나 톡(random) — 빈 하늘도 누른다. 1판·첫 톡 지표에만 쓴다.
- **캐주얼** = **사람형 캐주얼 봇**(human): 보이는 풍선(철 제외) 위만 톡, 판이 열리고/연쇄가 끝나고 0.3~0.8초(18~48틱) 반응 지연, 고르는 풍선은 무작위. §2 판정은 이 봇으로 한다.
- **숙련** = 내다보는 봇(smart).
(C002부터 하트 없음 — 실패하면 같은 하늘을 무제한 다시. funqa는 한 판을 **10번** 시도해도 못 깨면 그 런을 '막힘'으로 끝낸다.)
표본: 판별 도착 런 수 n < 10이면 그 판 수치는 "표본 부족" — 판정에서 뺀다.

## 1. 처음 하는 사람 (첫 1~2판, 첫 1분)
| 지표 | 목표 | 왜 |
|---|---|---|
| 1판 캐주얼 첫 시도 클리어 | ≥ 0.95 | 기준 7: 첫 판은 거의 못 진다 |
| 2판 캐주얼 첫 시도 | ≥ 0.85 | 새것 첫 판에서 바로 지면 "규칙이 이상하다"로 읽힌다 |
| 시작 → 첫 팡 (1판, 캐주얼) | ≤ 3초 (funqa `firstPopSec`) | 기준 2: 첫 3초 안에 재미 |
| 톡 → 다음 팡(연쇄 첫 박자) | ≤ 1.0초 — 구조상 1박자(BEAT 9틱 = 0.15초), 테스트로 고정 | 기준 2: 첫 손짓에 큰 일 |
| 1판 첫 톡 연쇄 길이 **중앙값** | ≥ 4 | 아무 데나 눌러도 크게 |
| 1판 무작위 첫 톡 연쇄 ≥ 3 확률 | ≥ 0.8 | 아무 데나 눌러도 "와" |
| 규칙 문장 | 타이틀 2줄, 각 2행 이내(390px) | 기준 8 |
| 새것 설명 | 1문장 + 그 물건이 화면에 보임 | 기준 8 |

## 2. 캐주얼
| 지표 | 목표 | 왜 |
|---|---|---|
| 각 판 캐주얼 첫 시도 하한 | 모든 판 ≥ 0.45, 판 사이 낙폭 ≤ 0.3 | 절벽이 있으면 그 판에서 이탈 |
| 평균 도달 판 reach | ≥ 6.0 / 8 (월드 구조로 바뀌면 재정의) | 펼쳐짐을 캐주얼도 봐야 함 |
| 완주율 finish | 0.3 ~ 0.6 | 0이면 벽, 1이면 고민 없음 |
| 평균 별(깬 판) | 1.5 ~ 2.2 | 별 3은 숙련의 몫 |
| 3회 안 클리어 | 1~8판 모두 ≥ 0.9 (도착한 런 중 세 번째 시도까지 깬 비율) | 기준 7: 실패해도 금방 넘어간다 |
| 막힘 | 막힌 런 비율 ≤ 0.05, 막힘이 한 판에 40% 이상 몰리지 않음 | 그만두게 만드는 벽 찾기 |

## 3. 숙련
| 지표 | 목표 | 왜 |
|---|---|---|
| 숙련 격차 skillGap = 숙련 시도당 별 ÷ 캐주얼 시도당 별 (v1.2) | 2.5× ~ 5× | 선택이 결과를 바꾸되 캐주얼이 소외될 만큼은 아니게 |
| 숙련 평균 별 | 2.4 ~ 2.8 (전 판 3.0이면 실패) | 별 3이 노려야 하는 것 |
| 후반 판 숙련 별 3 비율 | ≤ 0.7 | 후반 깊이 |
| 숙련 완주율 | ≥ 0.95 | 운이 아니라 실력 |

## 4. 흐름·볼륨
| 지표 | 목표 | 왜 |
|---|---|---|
| 판 시도 시간(봇 시계) | 참고값만 — 사람 20~60초는 오너 테스트로 확인 | 봇은 읽고 겨누는 시간이 없어 사람과 비교 불가(C001 🧪) |
| 새것 등장 간격 | 1~2판마다 1개, 같은 동사 변종 연속 2회 금지 | 기준 5·10 |

| 판당 풍선 수 | ≤ 18(390px) — C001 확정(FUN 16 / ART 18 / GDD 22 → PM 제안 18) | 터치 정확도·가독성 |
| 반경 원 겹침 지수 | 1판 ≤ 0.6, 2판~ ≤ 0.35 (판 시작 배치에서 반경 원이 겹치는 쌍 ÷ 전체 쌍, 철·폭죽 제외) | 빽빽함을 숫자로. 1판은 "아무 데나 눌러도 대연쇄"가 목적이라 따로 |
| 레이아웃(390×844) | 놀이 영역(캔버스) 세로 점유 ≥ 75%, 위·아래 빈 띠 각 ≤ 10% | 기준 9: 빈 띠 없는 디오라마 |
| HUD 겹침(360·390·768·1280) | 일시정지 버튼이 캔버스 위 HUD 띠와 겹침 0 | M0 결함 |

## 측정 정의 (C001에서 funqa.ts·shots.ts에 들어감)
| 지표 | 정의 | 어디 |
|---|---|---|
| 판별 n | 그 판에 도착한 런 수 | funqa |
| 막힘 판 분포 `stuck` | 10번 시도해도 못 깬 판에서 런을 끝냄 → **막힌 런 중** 그 판 비율(합 1). `stuckRate` = 막힌 런 ÷ 전체 런 | funqa |
| 3회 안 클리어 `within3` | 판별, 도착한 런 중 세 번째 시도까지 깬 비율 | funqa |
| 첫 팡 `firstPopSec` | 게임 시작 → 첫 팡(초), 런 평균 | funqa |
| 첫 톡 연쇄 | 각 판 첫 톡이 일으킨 팡 수(다음 톡 또는 판 끝까지) — **중앙값**, 1판 ≥3 확률도 | funqa |
| 판 시도 시간(봇) `sec` | 판 한 번 시도의 평균 초(소개·결과 포함, 봇 시계) | funqa |
| 밀도·겹침 | 판별 풍선 수(철 포함), 겹침 지수(시드 40개 평균) | funqa |
| 숙련 ★3 비율 | 판별, 깬 시도 중 별 3 비율 | funqa |
| 레이아웃·HUD 겹침 | 캔버스 세로 점유, 위·아래 빈 띠, 일시정지 버튼 ∩ HUD 띠 | shots → reports/layout.json |
