# FUN.md — 🎈 풍선 팡 연쇄 재미 기준표 (🧪 FUN QA v1, C001 개정)

측정: `npx tsx studio/balloonpop/funqa.ts` → `reports/funqa.json`.
봇 (C001 개정):
- **처음** = 아무 데나 톡(random) — 빈 하늘도 누른다. 1판·첫 톡 지표에만 쓴다.
- **캐주얼** = **사람형 캐주얼 봇**(human): 보이는 풍선(철 제외) 위만 톡, 판이 열리고/연쇄가 끝나고 0.3~0.8초(18~48틱) 반응 지연, 고르는 풍선은 무작위. §2 판정은 이 봇으로 한다.
- **숙련** = 내다보는 봇(smart).
(M0~M1-1 빌드: 하트 3, 실패 시 그 판 재도전 — M1-2에서 하트 폐기 후 "3회 재도전 안 클리어"로 바뀐다)
표본: 판별 도착 런 수 n < 10이면 그 판 수치는 "표본 부족" — 판정에서 뺀다.

## 1. 처음 하는 사람 (첫 1~2판, 첫 1분)
| 지표 | 목표 | 왜 |
|---|---|---|
| 1판 캐주얼 첫 시도 클리어 | ≥ 0.95 | 기준 7: 첫 판은 거의 못 진다 |
| 2판 캐주얼 첫 시도 | ≥ 0.85 | 새것 첫 판에서 바로 지면 "규칙이 이상하다"로 읽힌다 |
| 첫 톡 → 첫 연쇄 | ≤ 1.0초, 첫 톡 연쇄 길이 중앙값 ≥ 4 | 기준 2: 첫 손짓에 큰 일 |
| 1판 무작위 첫 톡 연쇄 ≥ 3 확률 | ≥ 0.8 | 아무 데나 눌러도 "와" |
| 규칙 문장 | 타이틀 2줄, 각 2행 이내(390px) | 기준 8 |
| 새것 설명 | 1문장 + 그 물건이 화면에 보임 | 기준 8 |

## 2. 캐주얼
| 지표 | 목표 | 왜 |
|---|---|---|
| 각 판 캐주얼 첫 시도 하한 | 모든 판 ≥ 0.45, 판 사이 낙폭 ≤ 0.3 | 절벽이 있으면 그 판에서 이탈 |
| 평균 도달 판 reach | ≥ 6.0 / 8 (월드 구조로 바뀌면 재정의) | 펼쳐짐을 캐주얼도 봐야 함 |
| 완주율 finish | 0.3 ~ 0.6 | 0이면 벽, 1이면 고민 없음 |
| 평균 별(깬 판) | 1.5 ~ 2.2 | 별 3은 숙련의 몫 |
| 사망 판 분포 | 한 판에 40% 이상 몰리지 않음 | 벽 찾기 |

## 3. 숙련
| 지표 | 목표 | 왜 |
|---|---|---|
| 숙련 격차 skillGap | 2.5× ~ 5× | 선택이 결과를 바꾸되 캐주얼이 소외될 만큼은 아니게 |
| 숙련 평균 별 | 2.4 ~ 2.8 (전 판 3.0이면 실패) | 별 3이 노려야 하는 것 |
| 후반 판 숙련 별 3 비율 | ≤ 0.7 | 후반 깊이 |
| 숙련 완주율 | ≥ 0.95 | 운이 아니라 실력 |

## 4. 흐름·볼륨
| 지표 | 목표 | 왜 |
|---|---|---|
| 판당 시간(사람 기준) | 20 ~ 60초 | 한 정거장 한 판 |
| 새것 등장 간격 | 1~2판마다 1개, 같은 동사 변종 연속 2회 금지 | 기준 5·10 |
| 동시 반경 원 | ≤ 10, 겹침 면적 ≤ 50% | 빽빽하면 결과가 안 읽힘 |
| 판당 풍선 수 | ≤ 18(390px) — C001 확정(FUN 16 / ART 18 / GDD 22 → PM 제안 18) | 터치 정확도·가독성 |
| 반경 원 겹침 지수 | ≤ 0.35 (판 시작 배치에서 반경 원이 겹치는 쌍 ÷ 전체 쌍, 철 제외) | 빽빽함을 숫자로 |
| 레이아웃(390×844) | 놀이 영역(캔버스) 세로 점유 ≥ 75%, 위·아래 빈 띠 각 ≤ 10% | 기준 9: 빈 띠 없는 디오라마 |
| HUD 겹침(360·390·768·1280) | 일시정지 버튼이 캔버스 위 HUD 띠와 겹침 0 | M0 결함 |
