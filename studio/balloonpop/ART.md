# ART.md — 🎈 풍선 팡 연쇄 아트 디렉션 (M0 초안, 🎨 디자이너)

> 기준: `BRIEF.md` 오너 기준 3·8·9번(웃김도 와우 · 결과가 읽힌다 · 화면 수준 높음, 디오라마, juice, 390px에서 읽힘)
> 출발점: 프로토타입 그리기(`game.ts`의 `drawBalloon`·`drawAnimal`·`drawClown`·`drawTramp`·`drawAll`)와 `art` 필드
> 원칙: **모든 리소스는 코드(캔버스 2D/SVG)로 직접 그린다. 외부 이미지·폰트·음원 없음. 실존 게임·캐릭터 참조 없음.**

## 1. 컨셉과 무드보드

**한 줄 컨셉:** *"놀이공원 하늘 위에 떠 있는 작은 축제 상자 — 톡 하나에 온 하늘이 박수 치듯 팡팡 터지고, 매달린 동물들이 우산을 펴고 둥실 내려온다."*

**무드 키워드:** 손바닥만 한 디오라마 · 말랑한 고무 광택 · 종이 오린 듯한 배경 층 · 장난감 같은 동물 · 소리 나는 듯한 글자.

### 레이어 구성 (뒤 → 앞)
| # | 레이어 | 내용 | 움직임 | 채도/대비 |
|---|---|---|---|---|
| L0 | 먼 하늘 | 2색 그라데이션, 해/노을 해/달, 밤엔 별 | 거의 정지 | 가장 낮음 |
| L1 | 높은 구름층 | 납작한 구름 띠 2~3장 | 아주 천천히(0.2×) | 낮음 |
| L2 | 지평선 구름 둑 + 먼 언덕 | 둥근 구름 둑 | 정지 | 낮음 |
| L3 | 놀이공원 실루엣 | 대관람차·롤러코스터·서커스 천막·솜사탕 가게 | 관람차만 회전 | **단색 실루엣 + 창문 불빛 점** |
| L4 | 줄깃발·광장 바닥 | 삼각 깃발 줄(밤엔 전구), 바닥 타일 | 깃발만 펄럭 | 중간 |
| L5 | **놀이 층** | 풍선·반경 원·동물·트램펄린·게임 구름 | 게임 로직 | **가장 높음** |
| L6 | 전경 | 구경꾼(피에로·아기 곰·아기 토끼), 흐린 꽃가루 | 반응 애니메이션 | 높음 |
| L7 | HUD·연출 | 위 띠, 아래 목표 띠, 떠오르는 글자, 연쇄 카운터 | — | 최고 |

규칙: **L0~L4는 풍선 색(빨·노·파)과 같은 채도로 칠하지 않는다.** "눈이 먼저 가는 곳 = 풍선".

### 시간대 3종 (1~3판 한낮 → 4~6판 노을 → 7판~ 불빛 밤, 월드마다 반복)
- **한낮:** 맑은 하늘색, 크고 하얀 뭉게구름, 파스텔 곤돌라. "소풍 첫날".
- **노을:** 위는 보랏빛 파랑, 지평선은 복숭아·산호색. 곤돌라에 첫 불. "축제가 무르익는 시간".
- **불빛 밤:** 남보라 하늘에 별·달, 거의 검은 남색 실루엣 + 노란 불빛 점. 풍선에 림라이트, 반경 원은 밝은 선. "불꽃놀이 직전의 설렘".

### 풍선 색 체계 — "크기 = 반경"을 **색 + 모양 + 무늬** 세 겹으로
| 반경 | 이름 | 색 | 모양 | 무늬 | 반경 원 대시 |
|---|---|---|---|---|---|
| 작게 | 콩풍선 | 산호 빨강 `#FF4D6D` / `#FF5F8A` | 동그란 공(세로비 1.05) | 없음, 광택 점 1 | 짧은 점선 |
| 보통 | 통풍선 | 해바라기 노랑 `#FFC53D` / `#FFB11F` | 달걀(1.17) | 가로 띠 1줄 | 중간 대시 |
| 크게 | 왕풍선 | 하늘 파랑 `#3F8CFF` / `#2FA3FF` | 길쭉한 물방울(1.3) | 띠 2줄 + 별 1 | 긴 대시 |

- 흑백 출력에서도 크기 3단이 구분되는지 테스트 항목으로 둔다.
- **색약 모드(설정)**: 몸통에 숫자 점(●, ●●, ●●●), 반경 원 두께 1/2/3단.
- 같은 크기 안의 색 변주는 명도 ±5% 이내 — 장식이지 정보가 아니다.

## 4. 기믹 풍선 시각 언어
원칙: **풍선이 하는 일이 몸에 그림으로 쓰여 있고, 반경 원 모양이 그 행동과 같다.**

| 기믹 | 몸 | 반경 미리보기 | 터질 때 |
|---|---|---|---|
| 철 | 무광 은회색 + 리벳 4 + 띠, 항상 '흥' | 원 없음. 연쇄가 닿을 곳에 방패 아이콘 | '깡!' 불꽃 3~4개 |
| 물 | 반투명 하늘색, 출렁이는 물·기포 | **아래쪽 반원만** + 아래 화살표 물결 | '촤악!' 물보라 + 물줄기 |
| 폭죽 | 주황 + 노란 사선, 심지 불꽃 | 화면 가로 끝까지 띠, 양끝 ▶◀ | 띠 따라 불꽃이 달림 |
| 대왕 | 2배 크기, 무지개 줄무늬, 왕관 | 큰 원, 무지개 테두리 | 무지개 링 2겹 + 번쩍 + 하늘 무지개 |
| 구름 | 두툼한 회보라 구름 + 속 풍선 실루엣 | 속 풍선 원은 숨김 | 퐁퐁 흩어짐 |
| 새 기믹 여지 | 자석(N/S 반반, 곡선 화살표) · 시한(시계 눈금, 줄어드는 게이지) · 쌍둥이(리본으로 묶음) · 얼음(서리, 육각 테두리) | | |

### '반경 원' 미리보기 규칙 (가장 중요한 정보 그래픽)
1. **기본은 조용하게:** 채움 4% + 크기별 대시, 불투명 35%. 원이 10개 넘게 보이면 **원 대신 짧은 호 꼬리 4개**.
2. **가리키면 선명하게:** 누르는 중/커서가 올라간 풍선은 원을 진하게, **원 안에서 같이 터질 풍선에 '헉' 미리 얼굴**(오너 기준 8). 2단계 이후는 흐린 점선.
3. **터지는 중:** 실선 + 0.15초 충격파 링.
4. 색은 풍선 계열에 밤엔 흰색, 낮엔 남보라 12% 섞기.
5. 원은 L5 맨 아래 — 얼굴을 덮지 않는다.

## 5. UI 스타일 가이드
- 폰트: `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", "Segoe UI", Roboto, sans-serif` (외부 웹폰트 없음). 숫자·제목 900, 본문 700~800.
- '팡!' 연출 글자: 2px 진한 외곽선(`#3A1030`) + 3px 그림자 + ±8° 기울기 + 2색 그라데이션.
- HUD 이모지(🎈♥★)는 기기마다 모양이 달라 **코드로 그린 아이콘으로 교체**.
- **위 띠(48px):** 판 번호 · 판 제목 · 하트 3(잃으면 금 가는 애니메이션) · 별 합계.
- **아래 띠(64px):** 목표(아이콘 + 진행 막대) + **톡 토큰 3개**(검지 실루엣, 쓰면 눌려 들어감, 마지막은 깜빡) + 별 조건 칩 3개(달성 즉시 금색 '딩').
- 버튼: 반지름 14px, 아래 4px 그림자, 주 `#FFD166` + `#341C5C` 글자.
- **결과 화면:** 놀이공원 입장권 모양 카드. 판 이름 → 별 1·2·3 쾅쾅쾅(0.35초 간격, 음 상승) → "최대 14연쇄!" → 구한 동물이 카드 위에서 손 흔듦 → [다음 판] [다시]. 실패는 "앗, 아깝다!" + 엉덩방아 동물 + 피에로 웃음, 빨간 벌 화면 금지.
- **390px 규칙:** 본문 14px·HUD 숫자 16px·연출 글자 18px 이상. 동시 '팡!' 글자 최대 4개. 놀이 영역 풍선 최대 18개, 최소 간격 = 콩풍선 지름 × 0.6.
- **터치:** 버튼 44×44px 이상. 풍선 판정 원 최소 지름 44px, 겹치면 가까운 중심 우선. 누르는 순간 1.1배 '꾹'.
- 키보드 커서 링: 흰 테두리 + 바깥 남색 테두리 2겹.

## 6. Juice / 이펙트 (연쇄 n번째마다 커짐, 상한 있음)
| 이펙트 | 기본 | 커지는 규칙 | 상한 |
|---|---|---|---|
| 팡 파티클 | 반짝이 10개 | +1/n | 22개 |
| 고무 조각 | 6장 회전 낙하 | n≥5 8장 | 10장, 화면 60장 |

| 꽃가루 | — | n≥10 또는 별 3개 | 80장 |

## 7. 사운드 (WebAudio 합성만)
- AudioContext 1개, 첫 터치에 resume. 마스터 게인 → 컴프레서. 음소거 토글·저장.
- **팡:** 노이즈 버스트 10ms + 삼각/사인 '퐁'(피치 1.6배→1배). **연쇄 n번째마다 C 장조 펜타토닉 한 칸씩 위로**(C5 D5 E5 G5 A5 C6…, 10칸 상한). 같은 박자 다중 팡은 화음, 최대 3보이스. 크기별 음색(콩=삼각 고음, 통=사인, 왕=사인+옥타브 아래).
- **철 '깡':** 비조화 사인 3개(1:2.76:5.4, 900Hz) + 코믹 하강 블립.
- **물 '촤악':** 노이즈 밴드패스 스윕 2.5k→600Hz + '똑' 2~3개.
- **폭죽:** '취이익' 상승 스윕 + '펑'. **대왕:** 팡 + 킥 + 펜타토닉 아르페지오.
- **톡 토큰:** 나무 블록 '톡'(1.2kHz 30ms), 마지막 톡은 한 음 낮게.
- **동물:** 우산 '퐁', 트램펄린 '뾰잉', 엉덩방아 '쿵' + '뾰로롱'.
- **클리어:** C–E–G–C 아르페지오 + 별마다 '딩'. 실패: 장난스러운 하강 '뾰로로롱'(단조 금지).
- **BGM:** 아주 작게(-24dB), 합성 오르골 왈츠 8마디 루프, 시간대별 변주. 연쇄 중 덕킹, **BGM 박자 = 연쇄 BEAT(9틱)**에 맞춰 팡팡이 음악처럼.

## 8. 리소스 제작 방식
- 전부 코드: `drawX(ctx, x, y, size, state, t)` 함수, 화면 너비 비례. 아이콘·로고는 SVG 문자열로 `assets/`.
- L0~L4는 판 시작 때 **오프스크린 캔버스에 캐시**(관람차·깃발만 매 프레임) — 저사양 60fps.
- 캐릭터는 "부품 + 상태" 구조.

## 9. 프로토타입 화면 약점 진단
1. **빽빽함 — 반경 원이 전부 겹친다(특히 8판).** → 원 2단 표현, 풍선 상한 18, 8판 간격 완화(기획 협의).
