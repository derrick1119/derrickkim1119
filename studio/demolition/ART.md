## 1. 컨셉
**한 줄**: "책상 위 장난감 블록 마을, 해 질 녘 — 헬멧 쓴 비버 반장이 귀를 막으면 3·2·1 쾅, 옆집 고양이 할머니가 찻잔을 든 채 지켜본다."

**무드보드(글)**
- **빛**: 지기 직전의 **밝은 살구빛 노을**. 해는 판 뒤 왼쪽 아래, 블록 오른쪽 면에 따뜻한 반사광, 왼쪽 면엔 연보라 그늘. 어둡게 가라앉은 저녁이 아니라 "놀이터에 아직 사람이 있는 6시".
- **재질**: 모서리가 둥글게 닳은 **칠한 나무 블록**(칠이 벗겨져 나뭇결이 보이는 귀퉁이), 매끈한 **회색 돌 벽돌**(잔금 두 줄), 광택 있는 **빨간 장난감 가스통**(위에 노란 뚜껑), 리벳 박힌 **양철 쇠판**. 땅은 **코르크 판** 같은 연갈색 바닥 + 펠트 잔디.
- **스케일**: 진짜 철거 현장이 아니라 **장난감**이다. 블록 윗면에 작은 둥근 **꼭지(못 머리)**를 하나씩 — 칸 단위 물리가 "블록 하나 = 한 칸"으로 눈에 읽히게.
- **감정**: 쾅은 시원하고, 실패는 웃기다. 피·불길·잔해에 깔리는 캐릭터 없음. 연기는 전부 **둥근 먼지 뭉게**(크림·연보라).
- **차별화(기준 13)**: 사실적 물리 파괴·폭파 해체 시뮬 느낌을 피한다. 우리 것은 ① 격자 꼭지가 보이는 장난감 블록, ② 비버(댐을 짓던 동물이 허무는) 반장의 귀 막기, ③ 울타리 너머 고양이 할머니의 반응 — 이 셋이 화면의 얼굴이다. 로고·버튼은 둥근 **나무 표지판** 형태(공사장 노랑-검정 사선은 띠 장식으로만, 버튼 면엔 쓰지 않음).

**키워드 5**: `장난감 블록 마을` · `살구빛 노을` · `귀 막는 반장` · `뭉게 먼지` · `찻잔 할머니`

## 4. 재료별 블록 표현
모든 블록 = **앞면 사각 + 윗면 평행사변형(밝게) + 오른쪽 옆면(어둡게)**(프로토타입 `DX/DY` 입체 유지), 모서리 반지름 12%, 잉크 외곽 1.5px, 윗면 가운데 **꼭지 원**(장난감 표식).

| 재료 | 색(면/윗/옆) | 무늬(색맹 대비) | 규칙 표시 |
|---|---|---|---|
| 나무(집) | 6색 순환 — 꿀 `#E7B36A`·분홍 `#F29BB2`·노랑 `#FFD36B`·하늘 `#86BDE8`·민트 `#9AD68F`·주황 `#F08A5D` (윗 +15% 밝게 / 옆 −25%) | 가로 판자 줄 2 + 귀퉁이 못 2, 지붕 블록은 삼각 기와 | 폭약 1개 |
| 돌 | `#AAA6B9` / `#CDC9DA` / `#7C788C` | 벽돌 엇갈림 줄눈 + 잔금 1 | **폭약 2개**: 앞면 아래 작은 칸 2개(빈 칸 `○○` → 붙으면 `●○`→`●●`) |
| 가스통 | `#E8453A` / `#FF7A6B` / `#A92A22` | 둥근 통(사각 아님) + 노랑 뚜껑 + 흰 **⚠ 삼각** | 쾅 반경 미리 보기 = 둘레 8칸 빨강 점선 고리 |
| 쇠 | `#7F8896` / `#A9B2BF` / `#5A626E` | 네 귀 리벳 4 + 대각 하이라이트 1줄 | **안 터짐**: 누르면 ✕ 회색 방패 + "땡" |

**폭약 붙은 표시**: 블록 앞면 가운데에 빨강 막대 3개 묶음(`#C7362E`, 노랑 띠) + 위로 도화선 곡선 + 끝 노랑 불씨(평소 정지, 카운트 때 지글 점멸). 붙는 순간 블록이 92%→100%로 튀어(6프레임) "탁". 돌은 묶음이 반쯤(1/2) 차오르는 표시. 남은 폭약은 아래 HUD와 **기폭 상자 위 막대 수**가 같은 모양.

**터치**: 블록 최소 시각 크기는 칸(32px@390) 그대로 두되, **누를 수 있는 영역은 44×44px 이상**(가까운 블록 스냅). 누른 블록엔 노랑 테 3px + 꼭지가 반짝.

## 5. 미리 보기(무너질 모양) 시각 언어
"꾹 = 미래가 보인다"가 이 게임의 와우. 실제 블록과 절대 헷갈리지 않게 **유령 레이어** 한 가지 문법만 쓴다.
1. **진입**: 누른 지 8프레임 뒤 화면 채도 −40%, 살구빛 비네트(가장자리 15%) — "생각 중" 모드.
2. **사라질 블록**(터짐·먼지): 제자리에 흰 **점선 윤곽** + 안쪽 대각 빗금, 원본 30% 투명.
3. **넘어질/떨어질 블록**: 원래 자리 흐리게(35%) + **도착 자리에 하늘 반투명 유령**(`#FFFFFF` 55%, 잉크 점선 외곽) + 두 자리를 잇는 **곡선 화살표**(굵기 4px, 끝 삼각) — 방향이 한눈에.
4. **결과 판정 배지**(유령 위에 직접): 목표선 아래면 목표 깃발이 초록으로 펄럭 · 이웃집에 닿으면 그 칸에 빨강 ✕ 원 + 이웃집 창이 흔들 · 꽃밭을 덮으면 꽃 아이콘 위 ✕.
5. **한 줄 말풍선**(HUD 아래 고정): `✓ 성공 ★★☆` / `✗ 이웃집 쾅!` / `✗ 아직 높아요 (5칸)` — 18px, 색 + 기호.
6. 손을 떼면 유령이 실제 자리로 0.12초 빨려 들어가며 폭약이 "탁". 미리 보기 = 실제(결정적)이므로 유령 모양은 **실제 쾅과 1칸도 다르면 안 된다**(테스트 대상).

## 7. UI 스타일 가이드 (390px 기준)
- **글자**: 시스템 산세리프, 굵기 800~900. 제목 22px · 본문 16px · 보조 14px(숫자만 13px 허용) · 판 위 글자 최소 18px. 프로토타입의 14px(0.036w) 라벨은 전부 16px 이상으로.

- **결과 카드**(DOM, 판 아래 2/3를 덮지 않고 아래에서 올라옴): 별 3칸(48px) · 한 줄 이유("이웃집을 쳤어요!" 18px) · 반장/할머니 얼굴 작은 원 · 버튼 [다시](보조) [다음 판 ▶](노랑 주 버튼). 실패 카드에는 **유령으로 '이렇게 됐어요' 1초 리플레이** 버튼(M2).

## 9. 현재 프로토타입 — 상용화 대비 부족한 점 TOP 5
1. **터치가 빗나간다**: 칸 32px, 기둥(1칸)은 그보다 좁게 보이고 히트박스도 칸 그대로 → 44px 미달(공장도 확인). 코어 조작이 실패하면 나머지가 무의미.
2. **글자가 작고 HUD가 비좁다**: 라벨 대부분 14px(0.036w), 위 띠 33px에 판 이름·하트·별이 몰림, 별 조건 칩 라벨이 잘림.
3. **어두운 화면**: 바탕 `#2a2340`·보라 하늘·반투명 원경 → "라이트한 노을 디오라마"가 아니고 블록 색이 탁하다. 장난감 재질(꼭지·둥근 모서리)이 안 보여 "칸 단위"가 화면으로 설명되지 않는다.
4. **미리 보기 문법이 약하다**: 흐린 원본과 점선 윤곽이 실제 블록과 비슷하고, 결과(이웃집·목표·꽃밭)가 아래 말풍선 글로만 나온다 → 기준 8 "결과가 읽힌다"의 핵심 화면이 약함.
5. **쾅의 손맛이 반쪽**: 소리 0, 느린 화면이 검은 띠 + "▶▶ 느린 화면" 글자(설명조), 결과·시작 카드가 캔버스 글자라 버튼이 작고 키보드 포커스가 없다. 하트 3개가 기준 7과 충돌.
