# 🎨 ART: 손맛(쾌감) 설계 v1 (M0 오너 피드백 대응)

> 오너 원문: "재밌네 근데 뭔가 쾌감이 좀 부족해 기믹도 좀 부족한거 같아". 🎨는 **쾌감(손맛)** 을 맡고, 기믹 규칙은 📐가 맡는다.
> 기준 수치(390px 화면): 1틱 = 16.7ms(60틱 고정). 캔버스 폭 w = 390이라 R(0.01) = 3.9px다. 나사 반지름 12.5px, 상자 폭 97px. 톡에서 쏙까지 26틱(433ms) 걸린다.
> 원칙: 연출과 소리는 **draw의 이벤트 루프에서만** 부른다. 시뮬레이션 상태는 건드리지 않고, RE 기록에 필드만 더한다. 그래서 봇·결정성·funqa는 그대로다.

## 1. 진단: 쾌감이 부족한 이유 5개

1. **귀와 손이 비어 있다.** 소리 0, 진동 0이다. 나사 풀기의 손맛은 "드르륵 → 뽁 → 쏙" 3박인데 셋 다 무음이다. 아이폰은 진동 API가 없으니 손맛을 주로 맡을 것은 소리다.
2. **'딱' 하는 순간이 없거나 어긋난다.** 화면이 멈추는 순간(히트스톱)이 0프레임이라 모든 것이 흘러가 버린다.
   - (a) 나사가 구멍을 떠나는 순간(t0+9)에 아무 일도 일어나지 않는다.
   - (b) 상자 착지 연출이 크림색 점 10개(나사 색이 아님)와 상자 4.7px 들썩임뿐이다.
   - (c) 상자 닫힘의 burst 22·흔들림 2.5가 뚜껑이 닫히기 *시작할 때*(tc) 터진다. 뚜껑이 실제로 닿는 tc+8에는 아무것도 없다.
   - (d) 덜컹은 흔들림이 두 번 온다. 떨어지기 시작할 때 6, 작업대에 닿을 때 5로, 큰 쪽이 먼저다. 톱밥도 두 번 나온다(첫 번째는 판자가 아직 공중에 있을 때).
3. **입력 첫 프레임의 반응이 약하다.** 누르면 흰 고리만 생기고 눌리는 느낌이 없다. 떼면 나사 크기가 1.0에서 9틱에 걸쳐 1.35로 커지기 때문에, 손을 뗀 첫 프레임에는 거의 변화가 없다. 그래서 입력과 반응 사이가 늦게 느껴진다.
4. **쌓이는 맛이 0이다.** 연속 1번째 쏙과 8번째 쏙이 똑같다. 연속 표시는 3·C·C+4k번째에만, 그것도 작업대 오른쪽 아래(X 0.82, Y 1.27)에 16px로 뜬다. 시선은 맨 위 상자에 있어서 거의 안 보인다. 아래 띠의 "지금 연속 N"도 12px다.
5. **와우와 마무리가 조용하다.** 진자 빙글(우리 정체성)은 고리와 14px "빙글~"뿐이다. 마지막 나사도 평소 속도로 지나간다. 실패는 빨간 번쩍과 흔들림 8·9라서 벌처럼 느껴진다(기준 3과 어긋남).
   - 덤(버그): `Juice.render`가 *화면 프레임마다* 파티클·글자·흔들림을 움직인다. 그래서 120Hz 폰에서는 파티클이 2배 빨리 사라진다. 손맛이 좋은 폰일수록 오히려 약해진다.

## 2. 쾌감 순간 표 (핵심)

### 2.1 소리 재료: 합성 원형 5개 (WebAudio, 샘플 파일 없음, 표의 칸이 이 이름을 쓴다)

- **M(f) 마림바 톡**: 사인 f(어택 3ms, 지수 감쇠 220ms, 0.38) + 사인 3.98f(45ms, 0.12) + 노이즈 하이패스 4kHz(8ms, 0.08). 나무 실로폰 소리로 쏙을 낸다.
- **R 래칫 드르륵**: 노이즈 → 밴드패스 Q8. 클릭 5번을 30ms 간격(0·30·60·90·120ms)으로 낸다. 클릭마다 12ms 지수 감쇠, 중심 2400→4200Hz(+450씩), 크기 0.14→0.30.
- **P 뽁**: 사인 380→980Hz 지수 70ms 0.32 + 노이즈 하이패스 2kHz 20ms 0.10. 코르크가 빠지는 소리다.
- **T(f) 나무 쿵**: 삼각파 f→0.45f 지수 160ms 0.5(로우패스 900Hz) + 노이즈 로우패스 1.2kHz 50ms 0.22.
- **K 끼익**: 톱니파 95→70Hz 380ms → 밴드패스 1.1kHz Q9(LFO 사인 11Hz, ±250Hz로 주파수를 흔듦). 어택 40ms, 200ms까지 유지, 380ms에 0. 크기 0.22.
- **공통 설정**
  - 마스터 0.5 → DynamicsCompressor(threshold −14dB, knee 6, ratio 4, attack 3ms, release 120ms)로 겹쳐도 깨지지 않게 한다.
  - 같은 소리가 25ms 안에 또 오면 하나로 합친다.
  - 노이즈 버퍼는 0.5초짜리 하나를 만들어 재사용한다.

### 2.3 구현 메모

- **새 이벤트**: `playRec`의 box·slot 분기에서 `ev(s,'twist',px,py,…,t0)`, `ev(s,'pluck',px,py,…,t0+SPIN)`. drawAll의 `due` 종류 목록에도 둘을 추가한다.
- **RE 필드 추가**: `place()`에서 box에 `n: S.streak`, slot에 `lost: S.streak`(0으로 되돌리기 *전* 값)를 담는다. `in`·`slot` 이벤트의 text로 넘긴다.
- **소리 훅**: game.ts에 `export let onCue = (c: Cue, v?: number) => {}` + `setCue()`(🐑 sfx 방식). 이벤트 루프에서 연출과 같은 줄에 `onCue(kind, v)`를 부른다. 누름은 `fx.memo.pk !== pressK`, 진자 되돌이는 `fx.memo['sg'+k]` 부호로 감지한다.
- **멈춤·시계** (juice.ts + main.ts)
  - `Juice.hold(n)`은 `stop = max(stop, n)`.
  - main 루프에서 `latch = null` *앞에* `if (j?.stop) { j.stop--; acc -= TICK; continue; }`를 둔다. 누른 입력을 잃지 않기 위해서다.
  - 슬로모는 `s.phase==='settle' && s.ok && s.pt<40`일 때 틱을 하나 걸러 건너뛴다.
  - **120Hz 보정**: `render(ctx,w,h,n)`에서 n = 이번 프레임에 쓴 1/60 조각 수(멈춘 조각 포함)만큼만 파티클·흔들림을 진행한다.
  - `prefers-reduced-motion`이면 흔들림 ×0.3, 멈춤 0, 번쩍 ×0.3.
- **진동**: `buzz(p)`는 꺼져 있거나 `!navigator.vibrate`면 무시한다. 45ms 안에 또 오면 버린다. 첫 사용자 입력 뒤에만 부른다.

## 3. 연속 쏙 누적감

- **음계**(5음계라 겹쳐도 불협이 없다): f(n) = 523.25 × 2^((12·⌊(n−1)/5⌋ + [0,2,4,7,9][(n−1)%5]) / 12)
  - n = 1~11 → C5 523 · D5 587 · E5 659 · G5 784 · A5 880 · C6 1047 · D6 1175 · E6 1319 · G6 1568 · A6 1760 · C7 2093. 12 이상은 C7에 고정한다.
- **숫자 팝**: 착지한 상자 앞판(Y = BOX_Y+0.03)에서 40틱 동안 24px 떠오른다. 크기 = min(36, 14 + 2.6n)px이고, 처음 6틱은 1.6→1.0 펀치(juice Popup에 3줄 추가). 지금의 오른쪽 아래 `streak` 팝과 "지금 연속 N" 글자는 지운다.
- **칩 게이지**: 아래 띠 "연속 쏙 C" 칩 안을 왼쪽부터 min(n,C)/C만큼 채운다(연두 .35, C에 닿으면 금 .5). 쏙마다 칩이 1.08배로 맥박친다(6틱).

## 5. 소리 끄기 토글과 자동재생

- **위치**: HTML 헤더(캔버스 밖, 화면 맨 위 44px 띠)의 오른쪽 끝. **🔊 44×44 버튼**을 오른쪽 여백 8px에 둔다. 그 왼쪽에 **📳 44×44 진동 버튼**을 두되, `navigator.vibrate`가 없으면(아이폰) 숨긴다.
  - 엄지가 움직이는 판 영역(화면 y 약 190~520px)과 아래 띠에서 멀어서 플레이 중에 손가락에 가리거나 잘못 눌리지 않는다.
  - 지금의 "스튜디오 빌드 M0" 작은 글씨는 타이틀 오버레이 아래로 옮긴다(390px에서 제목 약 170px + 버튼 2개 + 여백이 들어가게).
- **상태 표시**: 🔊/🔇 아이콘, `aria-pressed`, `aria-label`("소리 끄기"/"소리 켜기"). 키보드는 **M**이다. `localStorage 'screwshop:mute'`, `'screwshop:buzz'`에 저장하고(try/catch, 막혀 있으면 기본 켬), 소리를 켜는 누름에서 미리 듣기 쏙을 한 번 낸다.
- **자동재생 정책**
  - AudioContext는 **타이틀 '시작' 클릭 핸들러 안에서** 처음 만든다(`sfx.wake()`). 페이지가 로드될 때는 절대 만들지 않고, 꺼 둔 상태면 아예 만들지 않는다. 첫 소리는 그 시작 클릭의 "딸"이다.
  - `pointerup`·`keydown`마다 wake()로 suspended/interrupted 상태를 복구한다(아이폰은 무음 1샘플). `visibilitychange` hidden이면 `ac.suspend()`.
  - `navigator.audioSession?.type = 'ambient'`로 iOS 17+의 무음 스위치를 존중하고, 듣던 음악과 섞이게 한다.
  - 진동도 첫 사용자 입력 뒤에만 낸다.

## 6. 실존 게임을 닮지 않게 하는 원칙 (2줄)

1. **소리 재료는 '나무 공방'에서만 가져온다**: 마림바·목탁·래칫·나무 쿵·장난감 종. 8비트 사각파 코인 2음, 슬롯머신 롤링, 영어 칭찬 낭독(Great!/Perfect!), 특정 게임의 시그니처 징글·음 순서는 쓰지 않는다. 연속 음계는 우리가 정한 5음계 C5→C7이고, 🐑의 C-E-G 팡파르·"와와와" 실패음과도 겹치지 않게 했다.
2. **칭찬은 공방 사물이 한다**: 숫자는 상자 앞판에서, 연속은 햄스터 망치 장단과 상자 빛으로, 완성은 장난감 리빌로 보여 준다. 화면을 가득 채우는 'PERFECT' 리본, 무지개 콤보 바, 장르 관용 결과창 배치는 그대로 쓰지 않는다.
