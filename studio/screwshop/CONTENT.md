## 원칙
1. **새 기믹 첫 판은 못 지는 소개 판이다.** 무작위·막 누르기 클리어는 0.9 이상이고, 함정 밑은 비운다. 판 사이의 차이는 별로만 가른다.
2. **같은 핵심 첫 결정과 같은 ★3 종류는 연속해서 나오지 않는다.** 판마다 "먼저 할 일"이 달라야 한다.
3. **보상형 : 제약형 ≥ 1:1.** 1~3판은 전부 보상형이다. 새 제약형은 짝이 되는 보상형과 같은 판에 낸다(4·5판).
4. **장전 → 격발.** 준비가 화면에 보이고, 톡 한 번에 쏜다. 일찍 쏘거나 엉뚱하게 쏘면 손해가 화면에 *보인다*(💨 허공, 빈칸, 한 방 1).
5. **3판부터 ★3은 1수 미리 보기로 안 풀린다.** ★3에는 2톡 이상 앞을 보는 준비(아껴 두기)가 든다. buildLevel은 "장인 ★3 · 막 누르기 ★2 이상 ≤ 0.2 · 미리 보기 봇 ★3 실패"인 칠하기를 고른다.

- **흐름 점검**

  - ★3 종류: 톡 → 한 방 → 연속 → 톡 → 한 방 → 톡 → 연속 → 한 방. 연속이 0이다.
  - 새 종류는 보상 4(🔨🪵🔑🌀) : 제약 3(📌🪟⏰)이다. 제약형은 4·5판에서 짝 보상형과 함께 나오고, 7판만 혼자 나온다.
- **판 수치**
  - 색 수(상자는 늘 2개): 3·4·5·5·5·6·6·6.
  - N 합계 120. 모두 3의 배수다.
  - 판 순서: 지금 game.ts는 3판 풍차, 4판 기차다. S004에서 둘을 맞바꾼다.
- **8판 ★3을 ≥ 5에서 ≥ 7로 올린 이유**
  - 🔒는 열쇠를 빼기 전에는 어떤 기믹으로도 못 친다.
  - 그래서 발사하면 열쇠 1 + 🔒 5 = 6이 살아남기만 해도 저절로 나온다. ≥ 5는 클리어와 같은 조건이 된다.
- **완료 기준 ② "장인 한 방 ≥ 3인 판 ≥ 6/8" 맞추기**
  - 2·3·5·8판은 구조상 한 방이 3 이상이다.
  - 1판은 2다(망치 한 번에 2개).
  - 그래서 4판(날개 끝 🔨가 매달린 판자의 마지막 나사를 친다)과 6판(🌀 → 🌀)에 연쇄 1단을 넣어 6/8을 맞춘다. 7판은 1~2다.

```ts
key: 'train', name: '태엽 기차', emoji: '🚂', news: '🔑 태엽 열쇠 — 빼면 🔒 바퀴가 한꺼번에 튀어나와요!', tip: '🔑 🔒 바퀴 색 상자가 다 열렸을 때 열쇠를 톡!', tip2: '🔑 바퀴 색 상자 둘이 같이 열릴 때까지 아껴요', boxes: 2, colors: 5, P: 2, C: 13, wind: true,
// #0 레일 · #1~#3 보일러 · #4 #5 운전실(위·아래) · #6 #7 굴뚝 · #8 앞 등 · #9 증기 돔 · #10 🔑 · #11~#14 🔒 바퀴(왼→오른)
toy: () => [
  bar(0.12, 1.125, 0.88, 1.125, 0.022, '#7d7f86', [[0.5, 1.125]], { deco: 'rail' }),
  plate(0.52, 0.9, 0.44, 0.15, 0, 0.07, '#2f6fd6', [[0.37, 0.9], [0.52, 0.93], [0.67, 0.9]], { deco: 'boiler' }),
  plate(0.22, 0.82, 0.2, 0.3, 0, 0.03, '#e2574c', [[0.22, 0.74], [0.22, 0.9]], { deco: 'window' }),
  bar(0.66, 0.83, 0.66, 0.6, 0.032, '#3a3a44', [[0.66, 0.64], [0.66, 0.76]], { deco: 'chimney' }),
  plate(0.83, 0.93, 0.1, 0.12, 0, 0.03, '#ffcf3a', [[0.83, 0.93]], { deco: 'lamp' }),
  disc(0.47, 0.79, 0.045, '#f7c531', [[0.47, 0.79]], { deco: 'hub' }),
  plate(0.22, 0.655, 0.13, 0.15, 0, 0.04, '#ffd23a', [[0.22, 0.62]], { deco: 'windkey', key: 0 }),
  disc(0.24, 1.035, 0.05, ...wheel lock), disc(0.41, ...), disc(0.59, ...), disc(0.76, ...),
],
```

**판자 구조**
- 처음 막힌 나사는 #4 하나다. 🔑 판자가 누르고 있다.
- 🔑는 맨 위(y 0.62)에 있고 처음부터 뺄 수 있다.
- 굴뚝 #6을 먼저 빼면 굴뚝이 180° 뒤집혀 보일러 #3을 잠시 덮는다. 다른 판자의 진자 자세는 아무것도 덮지 않는다.

**칠하기 `wind`**
- 상자 순서는 [A, B, X, Z, E]이고, 🔑는 B 색이다.
- 🔒 넷(왼→오른)은 `Z B Z Z` 또는 `Z Z B Z`다. 맨 왼쪽은 늘 Z다.
- 남은 B 하나와 A·X·E 셋씩은 섞는다. 🔑 판자 밑 #4는 E 색이다.

**언제 빼느냐**
| 언제 빼나 | 결과 |
|---|---|
| 처음(A·B 열림) | Z 셋이 빈칸으로 간다(빈칸 3/5, ★2도 잃음) |
| X·B 열림 | 맨 왼쪽 Z가 빈칸으로 가서 연속이 끊긴다 |
| A·X를 닫아 B·Z가 같이 열림 | 한 톡에 다섯이 다 상자로 간다. 한 방 5, 연속 15 |

**정답 수순**: A 셋 → X 셋(그 사이 B 하나) → 🔑 → E 셋. 톡 11.

**C = 13을 고른 이유**
- 규칙대로 장인 분포 하위 30%를 보면 **15**다(24·48시드 전부 15).
- 그런데 C 15는 '빈칸 0'과 같은 조건이 된다.
- 잘못 뺀 태엽이 닿는 최대 연속은 10이다(버릇·✨ 최다 전부 10, 구조상 상한 10).
- 그래서 그 위에 여유 2를 둔 13으로 했다. 장인 ★3은 그대로 1.00이다.

## 2. 새 4판 🌬️ 풍차 (N 15 · 색 4 · P 2 · ★3 톡 ≤ 13)
```ts
key: 'mill', ..., news: '📌 못 날개 — 다 풀어도 못에 매달려 계속 가려요', tip: '📌 꾹 눌러 ⚠ 뜨는 나사는 맨 나중에!', tip2: '🎯 망치가 칠 나사는 손으로 빼지 말고 남겨요', boxes: 2, colors: 4, P: 2, C: 6, T: 13,
toy: () => [
  plate(0.5, 0.93, 0.3, 0.4, 0, 0.03, '#d98b5f', [[0.5, 0.86], [0.44, 0.88], [0.56, 0.88]], { deco: 'brick' }), // #0 ⚠ · #1 #2 🎯
  roof(#3 #4) · door(#5) — 그대로,
  ...[-1, 1].map((sx) => bar(0.5, 0.61, 0.5 + 0.2 * sx, 0.41, 0.04, BLADE, [[0.5 + 0.1 * sx, 0.51], [0.5 + 0.175 * sx, 0.435]], { deco: 'blade' })), // 위 날개: 보통 판자
  ...[-1, 1].map((sx) => bar(0.5, 0.61, 0.5 + 0.2 * sx, 0.81, 0.04, BLADE, [[0.5 + 0.1 * sx, 0.71], [0.5 + 0.175 * sx, 0.785]], { kind: 'nail', nail: [0.5 + 0.0424 * sx, 0.6524], ham: [0.5 + 0.2 * sx, 0.81], deco: 'blade' })),
  hub(#14),
],
```

**📌 못 날개와 🔨**
- 아래 날개 둘만 📌 못 날개다. 각자 축 테두리의 제 못에 매달려 세로로 내려온다(x 0.42~0.50 / 0.50~0.58).
- 왼쪽 날개는 #0·#1을 덮고, 오른쪽 날개는 #0·#2를 덮는다.
- 날개 끝 🔨는 (0.458, 0.875) / (0.542, 0.875)에 떨어진다. 가까운 순서로 #1 → #0(왼쪽), #2 → #0(오른쪽)을 친다.
- 지붕 #3·#4는 처음엔 아래 날개에 깔려 있다가, 날개가 매달리며 비키면 풀린다.

**CONTENT와 다르게 바꾼 것 두 가지**
1. 못을 하나로 같이 쓰면 두 날개가 같은 자리에 매달린다. 그러면 둘째 망치는 늘 💨 허공이라 톡 13이 아예 안 된다. 그래서 날개마다 못을 따로 박았다.
2. 색 5 → 4로 줄였다. 색 5에서는 무작위 클리어가 0.33이었다(첫 함정 판 숨통).

**칠하기 (매달린 못 날개가 덮는 자리 = 탑 셋)**
- 탑 셋은 첫 상자 색 A다.
- 나머지 12개는 남은 세 색에 한 색을 더 넣어 섞는다.
- 그래서 맞는 색이라고 탑 셋을 다 손으로 빼면 쾅이 0이다.

**정답 수순**: #0(⚠)을 손으로 → 왼쪽 날개 → 🔨가 #1을 쾅 → 오른쪽 날개 → 🔨가 #2를 쾅(A 닫힘) → 나머지. 톡 13.
- 다른 길도 있다. #1을 손으로 빼고 왼쪽 날개를 먼저 풀어도 13이다.
- 실패하는 길: 탑 둘이 남은 채 날개를 다 풀면 ⚠가 영영 덮여 실패한다.

## 3. 고르기 반증 식 (buildLevel stage 2·3)
- 버릇 3종과 따라 하기의 ★3 실패는 **칠하기 구조가 맡는다**. 고르기 없이도 3판은 각각 0/0/0·0.23, 4판은 0/0/0·0.05다.
- 고르기는 싼 것부터 재고, 그 후보가 지금까지 가장 나을 때만 장인 ★3 플레이아웃을 돌린다.
  - 3판: v = 3.95 − 막 누르기 클리어(16판). 0.3 이하면 멈춘다.
  - 4판: v = [버릇 클리어]·2.65 + min(1, 무작위 클리어(16판)/0.6). 3.5 이상이면 멈춘다.
  - 장인이 ★3을 못 따면 v = −9로 탈락이다.
- 고르기 시간(노드): 3판 2.3~3.0ms, 4판 3.6~5.0ms. 폰을 2~3배로 잡으면 4판은 10ms를 넘길 수 있다(위험 ③).
- **장인 봇 가치 두 곳을 고쳤다.** 패치에 들어 있다.
  - 🔑: 태엽이 튈 🔒는 이미 빠진 것으로 센다. 고치기 전에는 '한 톡에 다섯'의 n×100 때문에 장인이 열쇠를 바로 뺐다.
  - T판: 아직 칠 수 있는 망치 하나당 +90을 준다(`live`는 bonkDead와 같은 정의). 고치기 전에는 깊이 2 탐색에서 🎯를 손으로 빼서 4판 장인 ★3이 0이었다(고친 뒤 칠하기만으로도 0.81).
  - 1판은 장인 ★3 1.00, 손가락 → 막 누르기 ★2 이상 0.04로 그대로다. 다만 고르는 칠이 조금 바뀌어 버릇 ★3이 0.75 → 0.79, 따라 하기가 0.83 → 0.75로 움직였다(1판은 상한 없음).

## 4. 되짚기 F13 + ④태엽 (패치에 들어 있음)
- `canWin`: 되짚기 전용 전지 탐색이다. 예산은 4000칸이고, 실패 판은 막다른 길이라 보통 수십 칸이다.
  - `la` = 본 적 있는 뺄 수 있는 나사 중 '그 수를 뒀으면 아직 깰 수 있었던' 다른 수가 있던 마지막 톡이다.
  - retrace 비용: 중앙 0.04ms, 최대 0.57ms.
- 원인별로 짚는 톡:
  - ①깔림·①잠김 → `[la]`
  - ②진자 → `[매단 톡, la]`
  - ②못 → 그대로
  - ①색·①연쇄 → `[원래 톡, la]`. 이건 요청 범위 밖인데, 5·8판까지 0.8을 넘기려고 넣었다. 문구의 색 이름은 빈칸에 간 톡의 색만 쓴다.
- **④태엽**: 태엽 톡에 튄 🔒가 실패 순간에도 빈칸에 남아 있으면 이 원인으로 판정하고 `[태엽 톡, la]`를 짚는다. 우선순위는 ③보다 앞이다.
  - 문구: '태엽을 일찍 뺐어요! 🔒가 빈칸으로'(19자)
  - 💡: '🔒 바퀴 색 상자가 다 열리면 🔑를 톡!'(22자)
  - 같은 패치로, 태엽 판에서는 ①잠김 💡와 🔒를 톡했을 때 뜨는 말('🔒 🔑를 빼면 한꺼번에!')도 바꿨다. 원래 '열쇠 나사부터'는 태엽 판에서 일찍 빼라는 말이 되기 때문이다.
- **funqa**: `pnrHit(s)`를 넣었다. 게임과 따로 전지 탐색을 하고, 🧪 S003과 같은 PNR 정의를 쓴다.
  - `measure()`의 newbie 행에 `fails`·`f13`을 넣고, summary에 `f13_38min`을 넣었다.
  - `tryStage`는 이제 끝난 판 `s`도 돌려준다.
