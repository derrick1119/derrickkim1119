## 1. 세계관 (한 단락)
'**들썩섬**'은 동물들이 매일 씨름 잔치를 여는 섬들이다. 섬마다 마당이 있고, 관중석의 새들이 깃발을 흔들며 소리를 지른다.
싸움은 무섭지 않다 — 쓰러진 동물은 펑 하고 콩알만 한 '빈 몸'으로 줄었다가 관중석으로 굴러가 박수를 친다. 주인공은 몸이 없어서
씨름에 한 번도 못 껴 본 **꼬마 유령 '훌'**. 훌은 남의 몸에 쏙 들어가 그 몸의 힘을 잠깐 빌릴 수 있고, 몸을 떠날 때 남은 힘이 펑 터진다.
그래서 마당의 센 동물일수록 훌에게는 '다음에 입을 옷'이다. 섬을 하나씩 건널수록 시간이 흘러 아침 → 한낮 → 노을 → 오로라 밤 → 달빛 축제로 바뀌고,
섬마다 가장 센 대장이 왕관 보호막을 쓰고 기다린다. 훌의 목표는 마지막 섬 달빛 축제의 그림자 거인 몸으로 온 마당을 들썩이게 해 보는 것.
(이 세계관은 화면 연출용이다. 글로 설명하지 않고 관중·왕관·빈 몸 굴러가기로만 보여 준다.)

## 2. 비주얼 필라 (모든 화면 판정의 기준)
1. **말랑한 장난감 입체** — 소프트 비닐·털 인형·젤리 같은 손바닥 크기 장난감. 모든 형태는 둥근 덩어리 + 명암 3단 + 림 라이트 + 접지 그림자.
   선은 굵은 외곽선 하나(어두운 고유색), 안쪽 선은 쓰지 않고 명암으로 형태를 낸다.
2. **유령 빛이 주인공** — 화면에서 가장 밝고 차가운 색(청록 빛)은 오직 훌과 '훌이 들어간 몸'. 어디를 봐도 내 몸이 1초 안에 찾아진다.
3. **사건은 크게, 평소는 조용히** — 평소 화면은 채도 중간·움직임 작게(숨쉬기·관중). 펑·대장·연쇄 때만 빛·흔들림·멈칫이 터진다.
   대비가 손맛이다. 큰 글자는 한 번에 하나.
4. **무대가 살아 있다** — 첫 프레임부터 바람·관중·깃발·물결이 움직인다. 톡하기 전에도 '이미 잔치 중'인 세상.

## 3. 렌더 방식 결정: **캔버스 2D + 부품 아틀라스 + 가산 글로우 층** (WebGL은 M1에서 쓰지 않는다)
| 안 | 얻는 것 | 잃는 것 | 판정 |
|---|---|---|---|
| A 캔버스 2D(지금 엔진 확장) | 프로토타입 코드·측정 그대로, iOS·저가폰 안정, 번들 작음 | 실시간 블러·셰이더 조명 없음 | **채택** |
| B 직접 짠 WebGL | 진짜 블룸·노멀맵 조명·수천 파티클 | 렌더러·셰이더·컨텍스트 소실 처리 = +15~25KB, 4~6사이클, 그 동안 화면 진전 0 | 보류(M2 게이트) |
- **입체감은 '구울 때' 만든다**: 부품(몸통·머리·팔·다리·꼬리·귀·소품)을 로딩 때 명암 3단·림·반사광까지 칠해 아틀라스에 굽는다.
  빛 방향은 게임 전체 고정(왼쪽 위 → 오른쪽 아래)이라 부품이 돌아도 ±25° 안에서는 그대로 써도 어색하지 않다. 더 돌면 회전 변형 1장을 더 굽는다.
- **글로우**: `ctx.filter`(iOS 불안정)·`shadowBlur`(느림) 금지. 미리 구운 방사형 빛 도장(32·64·128px 3장, 색은 흰색으로 굽고 틴트 캐시)을
  `globalCompositeOperation='lighter'`로 찍는다. 화면 전체 블룸 대신 **사건 자리에만** 빛을 둔다(필라 3과 같은 말).
- **임팩트 프레임용 흰 실루엣**: 부품마다 `source-in` 흰판을 같이 굽는다(지금 `silhouette`의 방식을 부품 단위로).
- **성능 예산(CPU 4배 느림, 게임 코드 p95 ≤ 12ms, 중앙 ≤ 7ms)**: 배경 층 찍기 ≤ 1.5ms · 몸 24 × 부품 ≤ 10 = drawImage ≤ 240회 ≤ 4ms ·
  파티클 ≤ 150(사건 순간 ≤ 220, 2초 안에 150으로) ≤ 2ms · 글로우 도장 ≤ 40 ≤ 1ms · HUD ≤ 1.5ms · 여유 2ms.
  부품 아틀라스는 배율 ≤ 2배, 전체 ≤ 16MB. 굽기는 판 시작 전·결과 화면에서 나눠서(지금 `warmSprite` 방식 유지), 판 중 새 굽기 0.
- WebGL 재검토 조건: M1 끝에 👁 비평이 '빛이 납작하다'를 [큼] 이상으로 두 번 내면, M2에 **후처리 한 장짜리**(블룸+비네트, ≤ 6KB)만 직접 짠다.

## 5. 조명·재질 규칙
**명암 3단(모든 덩어리)**: 밝은 면 = 고유색 +18% 명도·광원 색 10% 섞음 / 중간 = 고유색 / 그림자 = 고유색 −28% 명도·월드 그림자 색 25% 섞음.
경계는 부드럽게(그라데이션 폭 = 덩어리 반지름의 25%). 그림자 쪽 가장자리에 **반사광** 한 줄(바닥 색 α .35) — 이것이 '입체'의 절반이다.
**림 라이트**: 광원 반대쪽 테두리에 2px(배율 1 기준) 밝은 선. 적 = 광원 색 α .6 / **내 몸 = 유령 빛 `#7ff3ff` α .9 + 바깥 글로우** — 내 몸 판독의 핵심.
**접지 그림자(AO)**: 발밑 타원 2겹 — 진한 심(폭 0.7r, α .38) + 옅은 테(폭 1.3r, α .16). 몸이 뜨면(점프·튕김) 높이에 따라 작아지고 옅어진다
(높이 h일 때 크기 × (1 − h/2r), α × (1 − h/r)). 그림자가 없는 몸은 반려.
**재질 4종**
| 재질 | 몸 | 규칙 |
|---|---|---|
| 털 | 곰·멧돼지·너구리·염소·두더지 | 실루엣 가장자리에 짧은 톱니 털뭉치(덩어리당 5~9개), 밝은 면에 결 방향 짧은 획 3~5개, 반짝이 없음(무광) |
| 껍질·단단함 | 거북 등·집게·곰 돌주먹·고슴도치 가시 | 강한 반짝이(타원 1 + 작은 점 1), 명암 경계 단단하게(폭 10%), 모서리에 밝은 테 |
| 젤리·말랑 | 콩알이·개구리·포자 버섯 갓 | 그림자 쪽에 **속빛**(고유색 밝게 α .4 — 빛이 비쳐 드는 느낌), 큰 반짝이 + 작은 반짝이, 스쿼시가 가장 큼 |
| 구름·기체 | 번개 구름·천둥 용 갈기·훌 | 외곽선 대신 바깥으로 옅어지는 테, 덩어리 3~5개를 겹친 몽글함, 안에서 빛(가산) |

## 6. 캐릭터 시트 원칙
- **실루엣 판독**: 모든 몸은 검게 칠했을 때 **24px에서** 서로 구별돼야 한다(👁이 실루엣 시트로 확인). 구별 수단은 머리 위 특징(귀·뿔·가시·갓) 1개 + 몸 비율.
- **크기 계층**(마당 폭 대비 반지름): 콩알이 0.034 < 보통 몸 0.043~0.054 < 큰 몸(곰·거북) 0.064~0.066 < 대장 0.10~0.11. 시뮬 반지름 = 그림 반지름(판정과 그림이 같다).
- **비율**: 2.5등신 이하. 머리:몸 = 1:1(작은 몸)~1:1.4(큰 몸). 눈은 머리 폭의 18~22%, 눈 사이 넓게 — 멀리서도 표정이 읽힌다.
- **적 vs 내 몸**: 적 = 눈썹 내린 화남/투닥, 림은 광원색. 내 몸 = 눈에 유령 빛 동공(청록 점) + 청록 림 + 머리 위에 훌의 꼬리 불꽃이 살짝 보임.
**유령 주인공 '훌' 표정 5종** (지금 mood 0~4를 대체)
| 표정 | 언제 | 눈 | 입·몸 |
|---|---|---|---|
| 호기심(평소) | 등불 위·떠다님 | 둥근 눈, 깜박 3~5초 | 작은 o, 꼬리 느리게 |
| 결심(슝) | 날아가는 9틱 | 반달 눈 + 앞으로 기울어진 눈썹 | 입 꾹, 몸 늘어남(§7) |
| 신남 | 연쇄 4+·별·판 깸 | ^ ^ 웃는 눈 + 반짝 2점 | 크게 벌린 입, 양팔(꼬리 끝) 번쩍 |
| 겁먹음 | 몸이 쓰러져 튀어나옴·하트 위험 | 커진 눈 + 작은 동공 + 땀 한 방울 | 물결 입, 몸 떨림 1px |
| 의기양양 | 대장 몸에 탐·결과 ★3 | 한쪽 눈 감은 윙크 | 씩 웃음, 가슴 내밀기(위로 스트레치 1.08) |
(어질 = 겁먹음 + 눈 X 표, 별도 표정으로 세지 않는다.)
**몸 13종 형태 언어** (덩어리 · 특징 · 재질)
- 콩알이: 물방울 하나 + 새싹 잎 하나 · 젤리, 색 3변형 · '작고 많음'이 읽히게 가장 단순하게.
- 돌주먹 곰: 둥근 사각 몸 + 몸보다 큰 회색 돌주먹 둘 · 털 + 돌(껍질) · 무게가 아래에.
- 가시 고슴도치: 뒤로 눕힌 가시 부채(9개) + 작은 코 · 가시는 껍질 · 굴러가면 완전한 공 실루엣.
- 긴 혀 개구리: 낮고 넓은 반원 + 머리 위 큰 눈 둘 · 젤리 · 혀는 분홍 띠, 끝은 둥근 공.
- 폭탄 두더지: 도토리 몸 + 머리 위 심지 불꽃 + 큰 앞발 · 털 · 심지가 위험 빨강으로 깜박.
- 박치기 염소: 앞으로 기운 삼각 몸 + 말린 뿔 둘 · 털(흰) + 뿔(껍질) · 늘 돌진 방향을 향함.
- 방패 거북: 높은 돔 등껍질(육각 무늬 3) + 작은 머리 · 껍질 · 가장 넓고 낮음.
- 번개 구름: 몽글 덩어리 4개 + 아래로 늘어진 번개 꼬리 · 구름 · 안쪽 노란 빛 맥동.
- 포자 버섯: 큰 점박이 갓 + 짧은 기둥 다리 · 갓은 젤리 · 갓 아래에서 포자가 늘 조금씩 떨어짐.
- 분신 너구리: 둥근 몸 + 눈가 검은 띠 + 머리 위 나뭇잎 · 털 · 분신은 같은 실루엣 α .7 + 연기 테.
- 대장 멧돼지: 앞이 무거운 쐐기 몸 + 엄니 둘 + 갈기 · 털 · 왕관 보호막(금 + 유리 돔).
- 대장 집게: 넓은 타원 등딱지 + 몸만 한 집게 둘(좌우 크기 다름) · 껍질 · 거품 몇 개.
- 대장 천둥 용: 긴 S자 몸 + 구름 갈기 + 작은 날개 · 비늘(껍질) + 구름 · 숨결 때 목이 앞으로 늘어남.

## 7. 뼈대 애니메이션 원칙 (몸 전부, 코드 리그)
**리그 구성**: 뿌리(발 접지점, 시뮬 좌표) → 골반 → 몸통 → 머리 / 팔 L·R(어깨·손 2관절) / 다리 L·R(1관절) / 부속(귀·꼬리·뿔·갓·심지 = 스프링 2차 동작).
관절당 각도·늘임만 시간 함수로 계산, 부품 스프라이트를 변환해서 찍는다. 다리 없는 몸(콩알이·구름·버섯)은 몸통 1관절 + 부속 스프링.
2차 동작 스프링: 강성 k = 0.18, 감쇠 0.72(틱 단위) — 귀·꼬리는 몸통보다 3~5틱 늦게 따라온다. 모든 시간은 60틱 기준.
| 동작 | 길이 | 핵심 포즈와 수치 |
|---|---|---|
| 대기 숨쉬기 | 90~120틱 주기(몸마다 다름) | 세로 ×1.03 ↔ ×0.98, 가로는 반대(부피 보존 sx·sy ≈ 1). 시드로 위상 흩뜨림 |
| 걷기 | 걸음 18~28틱(작을수록 빠름) | 몸통 위아래 0.06r 통통, 걸음마다 착지 스쿼시 1.06×0.94, 다리 ±25° |
| 예비동작 | 적 wind 틱 전부(22~60) | 뒤로 젖힘 −15°, 웅크림 1.12×0.86, 끝 4틱 떨림 + **위험 빨강 림 깜박**(이것이 피할 신호) |
| 타격 | 3~4틱 | 늘어남 0.85×1.22(치는 방향), 팔·머리 앞으로 과장 +30%, 임팩트 프레임 |
| 여운 | 10~16틱 | 지나쳐 갔다 되돌아옴(오버슛 12%), 부속 스프링 흔들림 |

| 기절 | 반복 | 머리 위 별 3개 회전, 몸 좌우 ±8° 휘청, 눈 X |
| 쓰러짐(적) | 20틱 | 뒤로 넘어가며 납작 1.3×0.6 → 펑 → 콩알 '빈 몸'이 관중석으로 굴러감 |
| 빙의 변신 | 9틱 날기 + 12틱 | 훌이 몸에 닿는 순간: 몸 1.25×0.8 꾹 → 1.0×1.18 쭉 → 1.0, 눈이 청록으로 켜짐, 청록 고리 파동 1, 이름 배지 |

- 대장 3종은 부품을 2배(엄니·집게 개별 관절, 용 목 4마디 체인)로 하고 등장·보호막 깨짐·타기 컷신 포즈를 따로 둔다.

## 9. 무대 설계
**3층 시차 + 전경**: 원경(하늘·먼 섬·구름, 카메라 이동 ×0.2) · 중경(관중석·깃발·문, ×0.6) · 마당(×1.0) · 전경(화면 가장자리 풀·꽃·말뚝, ×1.4, 살짝 어둡고 크게).
카메라는 평소 고정, 사건 줌·흔들림 때만 층이 서로 다르게 움직여 깊이가 드러난다. 층은 각각 구워 두고 찍기만 한다.
**살아 있는 요소(월드마다 4개 이상, 전부 합쳐 ≤ 1ms)**: 관중 새 떼(박자 맞춰 들썩, 큰 펑에 일어섬·연쇄 10+에 파도), 깃발 펄럭(사인파 3마디),
구름 흐름, 바람에 풀 흔들림. 월드 고유: 2 물결·갈매기, 3 떠다니는 풍선·무지개, 4 눈발·오로라 물결, 5 등불 줄·불꽃놀이.
**월드 1 '풀밭 씨름 마당' 구체 묘사**: 늦은 아침, 왼쪽 위 해. 원경 — 연두 언덕 두 겹 위로 둥근 정자 지붕 둘과 바람개비 하나(빙글), 하늘엔 큰 뭉게구름 셋이 천천히 오른쪽으로.
중경 — 마당 위쪽 반원으로 나무 관중석 3단, 둥근 새 관중 20~30마리(색 4가지, 각자 다른 박자), 관중석 꼭대기 삼각 깃발 줄이 바람에 출렁,
가운데 나무 문(적이 우르르 뛰어드는 곳)은 열릴 때 문짝이 덜컹 흔들린다. 마당 — 흰 줄 두 겹으로 그린 둥근 씨름 마당, 모래빛 흙에 발자국이 남았다 사라짐,
가장자리에 짚단 4개. 판 시작 등불 기둥(훌이 앉는 곳)은 마당 위쪽에 따뜻한 빛. 전경 — 왼쪽 아래 큰 풀포기, 오른쪽 아래 노란 꽃과 나비 한 마리.
대장 판(멧돼지): 하늘이 한 단계 진해지고 관중석에 대장 깃발(엄니 문양), 등장 때 땅이 울려 짚단이 넘어진다.

## 10. UI 스타일
- **글꼴 결정**: 외부 글꼴 파일 없이 시스템 스택 `ui-rounded, "SF Pro Rounded", "Arial Rounded MT Bold", "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", system-ui, sans-serif`
  굵기 800~900. 통일감은 **처리**로 만든다: 모든 큰 글자 = 둥근 외곽선(lineJoin round, 글자 크기 18%, 진한 고유색) + 아래로 2px 그림자 + 위쪽 밝은 그라데이션.
  **숫자 0~9·×·+·!만** 직접 그린 둥근 벡터 숫자로 굽는다(점수·연쇄·별 수가 화면의 주인공이라서). 한글 글자를 직접 그리는 일은 하지 않는다(§12).
- **아이콘 세트**: 24px 격자, 선 없이 덩어리 + 명암 2단 + 외곽선 2px — 별·하트·왕관·일시정지·소리·음악·진동·흔들림·도감·지도·다시·다음·자물쇠 13개를 한 세트로.
- **버튼**: 둥근 알약(반지름 = 높이 50%), 아래 두께 4px(어두운 같은 색). 누르면 두께 0px로 내려가며 0.94배 + 6틱 되돌아옴(오버슛 4%), 소리 '톡'. 최소 높이 48px.
- **전환**: 화면 사이는 유령 꼬리 모양 와이프(훌이 화면을 휙 가로지름, 18틱) — 게임 전체에서 전환은 이것 하나.
- **큰 글자는 한 번에 하나**: 띠·제목·결과 숫자가 겹칠 때는 늦은 것이 줄을 선다. 화면 위 큰 글자 영역은 중앙 위 1곳만.
- 결과 화면: 별이 하나씩 쾅(단계 2 타격감 재사용) · 숫자 굴러감 · 도감 몸이 실루엣 → 색으로 '뿅'.

## 11. 승인 체크리스트 (👁 화면 비평 · 🖌️ 아트 디렉터 공용, 스크린샷만 보고 판정 — 하나라도 ✗면 반려)
1. **내 몸 1초 판독**: 적 20마리가 붐빈 장면에서 내 몸(청록 림·눈)과 훌이 1초 안에 찾아지는가.
2. **입체**: 모든 몸·소품에 명암 3단 + 림 + 접지 그림자가 보이는가(납작한 스티커 하나라도 있으면 ✗).
3. **실루엣**: 몸 13종을 검게 칠한 시트에서 24px로 서로 구별되는가.
4. **팔레트 규율**: 빨강은 위험에만, 금은 보상에만, 청록은 내 힘에만 쓰였는가. 검정 외곽선 없음.
5. **움직임**: 정지 스크린샷 연속 3장(0.5초 간격)에서 몸 포즈·관중·깃발이 서로 다른가(미끄러지는 몸 없음).
6. **타격 단계**: 펑 크기별 스크린샷에서 단계(§8)가 눈으로 구별되는가 — 작은 펑이 큰 펑처럼 보이면 ✗.
7. **무대 깊이**: 원경·중경·마당·전경이 명도·크기로 분리되어 보이는가. 월드마다 시간대가 한눈에 다른가.
8. **글자 하나**: 어느 프레임에도 큰 글자가 둘 이상 겹치지 않는가. 390px에서 모든 글자 12px 이상.
9. **UI 한 벌**: 버튼·아이콘·글자 처리가 한 세트로 보이는가(다른 그림체가 섞이면 ✗).
10. **AAA 나란히 놓기**: 대형 스튜디오 모바일 게임의 같은 종류 화면 옆에 두었을 때 '프로토타입'이라는 말이 먼저 나오지 않는가.

## 12. 피할 것
- **작은 그림 고치기로 사이클 소모 금지**(닌자 팀 F1~F8 교훈): 머리 모양·글자 렌더·눈 위치 같은 [작음]은 모아서 마일스톤 끝에 한 사이클로 처리한다.
  한 사이클의 아트 작업은 반드시 '한 화면 전체가 한 단계 좋아짐'이어야 한다(예: 몸 4종 리그 완성, 월드 1 무대 3층 완성).
- 한글을 직접 그리는 도트·벡터 글꼴 만들기 금지(숫자 13자만 예외).
- 시스템 전체를 갈아엎는 렌더러 교체(WebGL)를 M1에 하지 않는다 — 화면이 좋아지지 않는 사이클이 생긴다.
- 평소 화면에 글로우·흔들림·파티클 상시 켜기 금지(닌자 M2 "연출이 과도해서 보는 맛이 없다"의 재발).
- `ctx.filter`·`shadowBlur`·판 중 굽기 금지(렉). 외부 이미지·글꼴·특정 실존 게임의 캐릭터·그림 참고 금지.
- 스타일 시안 여러 개를 만들어 오너에게 고르게 하는 데 마일스톤을 쓰지 않는다 — 이 바이블이 방향이다. 오너 반려가 오면 그때 바꾼다.
