# 👻 몸 갈아타기 — 아트 바이블 (ART.md) v1.0

> 🖌️ 아트 디렉터 · 2026-11-21. **v0.1(프로토타입 2D 스티커를 옮겨 다듬는 계획)은 폐기한다.** 프로토타입에서 가져오는 것은 시뮬레이션 규칙뿐이다. 그림·화면·아트 컨셉은 이 문서가 백지에서 정한다.
> 틀(팀 결정): 실시간 3D · 직접 짠 WebGL2 · 외부 이미지/모델/글꼴 파일 0. 모든 형상은 코드로 만든다(SDF → 마칭 큐브 굽기 → 관절 애니메이션). 수치는 첫 값이다. 바꾸면 이 문서를 고친다.

## 0. 단위·좌표·예산
- 1u = 1m. 월드 +x = 화면 오른쪽, +y = 위, +z = 카메라 쪽(화면 아래). 시뮬 (x, y) → 월드 (X, Z) = ((x − 마당 중심 x) × 10, (y − 마당 중심 y) × 10). 시뮬 y가 클수록 화면 아래.
- 마당 반지름 R = 시뮬 마당 반지름 × 10. 이 문서는 **R = 5u** 기준이며 R에 비례해 늘인다. 몸 크기 s = 시뮬 r × 10 × 1.1(말랑한 모양이 충돌 원을 꽉 채워 보이게).
- 렌더는 시뮬 틱 사이를 보간만 한다. 그림 쪽 무작위(깜빡임·관중)는 렌더 전용 RNG를 쓴다 — 시뮬 결정성을 건드리지 않는다.
- 예산(상/하 품질 자동): 드로콜 ≤ 100 · 삼각형 ≤ 300k/150k · 그림자 패스 드로콜 ≤ 30 · 해상도 DPR(최대 2) × 1.0/0.75(처음 120프레임 평균이 18ms를 넘으면 하) · CPU 4배 느림 게임 코드 p95 ≤ 12ms(렌더 CPU 포함). 같은 종 몸·관중·풀·파티클은 인스턴싱, 뼈 행렬은 float 텍스처.
- 로딩: 타이틀에 필요한 것(1-1 마당 + 곰·콩알이·유령)을 먼저 굽고(중간 폰 ≤ 600ms), 나머지는 타이틀 동안 프레임당 6ms씩 이어 굽는다. 첫 화면 2초 안.

## 1. 비주얼 목표
**손에 쥐고 싶은 장난감들이 햇살 아래 진짜 미니어처 씨름판에서 투닥거리는 장면.** 대형 스튜디오가 만든 고급 모바일 3D 난투 게임의 품질대를 노린다. 캐릭터는 굵고 단순한 실루엣에 통통한 비율이고, 털 인형·반질한 비닐·말랑한 젤리가 한눈에 다른 재질로 보인다. 따뜻한 햇빛과 차가운 하늘빛이 대비되고, 부드러운 그림자와 가장자리를 감싸는 림 라이트가 형태를 세운다. 공기는 멀수록 푸르게 옅어진다. 정지 화면 한 장에서도 풀·깃발·관중·구름이 움직이고 있음이 보인다. 펑은 화면에서 가장 밝은 순간(HDR 섬광 + 블룸)이고, 그 순간에만 세상이 멈칫한다.

| 필라 | 뜻 |
|---|---|
| **만지고 싶은 물성** | 형태는 외곽선이 아니라 빛으로 읽힌다. 털·비닐·젤리·금·자연물이 스크린샷에서 구분된다 |
| **빛이 상태를 말한다** | 청록 = 나, 붉은 주황 = 위험·대장, 금 = 보상·보호막, 따뜻한 흰 = 펑 범위. 그 밖의 것은 발광하지 않는다 |
| **실루엣 먼저** | 회색조 64px에서도 모양만으로 몸이 갈린다(콩+새싹 · 돌주먹 · 가시 돔 · 눈 혹 · 말린 뿔 · 엄니 쐐기) |
| **살아 있는 디오라마** | 마당 밖 모든 층이 숨 쉬고, 마당 안 사건에 반응한다(관중 들썩, 풀 눕기, 깃발 펄럭) |

**절대 아닌 것**: 굵은 외곽선 스티커 · 평면 단색 원이나 2D 아이콘 캐릭터 · 이모지 · 회색 사각 상자와 시스템 기본 단추·글꼴 · 네온 사이버 색 · 사진 같은 실사 · 순검정 그림자 · 블룸으로 화면 전체가 뿌연 것.

## 4. 후처리
순서: 장면(RGBA16F, 상은 MSAA 4×) → 블룸 → 합성 → 노출 → ACES → 색보정 → 비네트 → 낟알 → 디더. 하 품질 또는 부동소수 버퍼 불가 기기: RGBA8 + 재질 셰이더 안에서 톤맵, 블룸은 발광 마스크(알파)로만.

| 항목 | 값 |
|---|---|
| 블룸 | 문턱 1.1(노출 뒤 선형 휘도), 부드러운 무릎 0.6, 입력 휘도 상한 12(반딧불 방지). 반 해상도에서 5단(하 4단) — 13탭 다운 / 3×3 텐트 업, 퍼짐 0.68. 세기 0.28 평소 · 펑 L 이상 0.45(0.3s) · 보호막 깨짐 0.6 |
| 톤맵 | ACES 근사(Narkowicz): x(2.51x + 0.03) / (x(2.43x + 0.59) + 0.14) |
| 색보정(톤맵 뒤) | 화이트밸런스 × (1.025, 1.0, 0.965) · 대비 1.06(중심 0.45) · 채도 1.07(Rec.709 휘도) · 그림자(휘도 < 0.3)에 + (0, 0.006, 0.018) 푸른 기 · 밝은 곳 × (1.01, 1.0, 0.98) |
| 대장전 보정 | 대비 1.10 · 채도 1.02 · 화이트밸런스 × (1.05, 1.0, 0.93) · 비네트 0.30 |
| 비네트 | 화면비에 맞춘 타원, 안 0.62 → 밖 1.05(반 대각선 기준), 세기 0.22, 색 #142040(남색, 검정 아님). 펑 L 이상은 0.2s 동안 0.32로 맥동 |
| 낟알·디더 | 낟알 0.012(상만, 프레임마다 해시) · 하늘 띠 방지 디더 ±0.5/255 |
| 굴절 고리(상만) | 펑 M 이상 충격파 자리에 화면 UV 굴절 고리, 세기 0.006, 0.15s |
| 쓰지 않음 | 피사계 심도 · 색수차 · 화면 전체 모션 블러 · 렌즈 플레어 — 값싸 보이고 무겁다 |

## 5. 재질

## 8. VFX

## 10. 화면 승인 체크리스트 (스크린샷만 보고 판정 — 하나라도 ✗면 반려)
1. **실루엣**: 회색조로 바꿔 64px 높이로 줄여도 콩알이·곰·고슴도치·개구리·염소·멧돼지·유령이 모양만으로 갈린다.
2. **입체**: 모든 캐릭터에 밝은 면·중간·그림자 3단(휘도 비 2~3.5 : 1) + 가장자리 림 + 발밑 접지 그림자가 보인다. 단색 평면으로 칠한 캐릭터 0.
3. **내 몸 1초**: 처음 보는 사람이 1초 안에 내 몸을 가리킨다. 화면의 청록 빛은 내 몸·유령·기운 고리뿐이다.
4. **금지 0**: 외곽선 스티커 · 2D 평면 그림 · 이모지 · 기본 웹 글꼴/단추 · 회색 상자 · 순검정 그림자가 한 군데도 없다.
5. **깊이 층**: 판 중 한 장에 전경 소품 · 마당 · 관중석/깃발/큰 나무 · 비탈 숲 4층, 타이틀·결과 한 장에 + 먼 언덕 · 산 · 하늘·구름이 보이고, 멀수록 안개로 옅고 푸르다.
6. **빛 절제**: 평소 블룸은 발광체(유령·고리·눈·해)에만 걸린다. 모래·하늘이 뿌옇지 않고, 순백으로 날아간 넓이가 화면의 1% 미만.
7. **펑 한 장**: 섬광 · 충격파 고리 · 파편 · 먼지 · 빛(점광/그을림) 다섯이 다 보이고, 세상의 반응(관중 들썩·풀 눕기)이 하나 이상 보인다.
8. **읽힘**: 360·390·430px 세로와 가로 태블릿에서 HUD 글자 ≥ 12px, 큰 글자는 한 번에 하나, HUD·글자가 마당 테두리 안을 가리지 않는다. 가로 스크롤 0.
9. **팔레트**: 그림자는 푸르스름하고, 마당 모래가 따뜻한 중심이며, 하늘·풀이 형광으로 튀지 않는다. 오방색 깃발은 마당 캐릭터보다 채도·크기가 낮아 눈을 뺏지 않는다.
