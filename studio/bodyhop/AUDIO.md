# 👻 몸 갈아타기 — 오디오 바이블 (`AUDIO.md`, M0 초안)

> 🎧 사운드 디자이너 · 2026-11-21 · 근거: `BRIEF.md` AAA 표 '사운드·음악' 행 + 오너 기준 7("모든 사건에 효과음, 높낮이로 크기, 연쇄는 음이 올라가게. 끄기 단추").
> 원칙: **샘플 파일 0개, 외부 음원 0개.** 모든 소리는 WebAudio로 그 자리에서 합성한다(런타임 의존성 없음). 시뮬레이션은 소리를 모른다. `draw()`의 사건 처리에서만 부른다(지금처럼).

## 0. 지금 상태 (프로토타입 `studio/bodyhop/sfx.ts` = `arcade/sfx.ts` 복사본, 92줄)
- 소리 모양 16개(pop·thud·whoosh·ding·chime·splash·crack·boing·swell·shrink·rewind·coin·fail·clear·tick·zap). 각각 사인/삼각/사각 1~2개와 걸러낸 잡음을 섞는다.
- 길: 소리 → `out`(0.45) → 컴프레서(−16dB, 4:1) → 스피커. **버스·리미터·울림이 없다.**
- 사건 약 55가지가 모두 소리를 낸다(`game.ts`의 사건 처리): tap·deny·hop·pop·in·kill·slam·punch·ping·zap·thunder·boom·break·ko·heart·ready·clear·end 등. 두근두근은 펑 범위에 다섯 넘게 들면 44틱마다 thud 두 번. 연쇄는 `pop` 높낮이를 n×0.085만큼 올린다.
- 모자란 것: ① 음악 없음 ② 몸마다 같은 소리(곰도 너구리도 `boing`) ③ 같은 소리를 35ms 안에 거르는 것만 있고 동시 발음 상한·우선순위 없음 ④ 높낮이가 늘 같아 기계 같다 ⑤ 연쇄 사다리가 음계를 따르지 않음(음악이 생기면 어긋남) ⑥ 끄기만 있고 크기 조절은 없음 ⑦ 진동 없음.

## 1. 소리 정체성
**한 줄: "장난감 북 치는 꼬마 유령의 운동회."** 무겁지 않게 통통하고 따뜻하게. 쾅은 크게 내되 귀를 찌르지 않는다.

| 층 | 음색 팔레트 (합성으로) | 쓰는 곳 |
|---|---|---|
| 유령 | 사인 + 살짝 흔들리는 비브라토(5.5Hz ±12cent), 유리잔 같은 삼각파 배음 | 슝·쏙·기운 고리·유령 튀어나옴 |
| 몸(동물) | 나무 북(사인 하강 + 짧은 저역 잡음), 고무(삼각 상승 boing), 금속(FM 링) | 몸마다 다름(§4) |
| 펑 | 잡음 파열 + 저음 쿵 + 반짝이 | 버린 몸 펑·연쇄 |
| 보상 | 실로폰·첼레스타(삼각 + 빨리 사라지는 2배 배음), 종(FM 비율 1:3.5) | 별·판 깸·도감 |
| 음악 | 마림바·우쿨렐레풍 뜯음(카플러스-스트롱 1줄), 부드러운 패드(톱니 2개 ±7cent + 로우패스), 장난감 북 세트 | §5 |

- **조성**: 장마다 하나. 풀밭 = **F장조(리디안 #4로 유령 느낌 한 방울)** · 바닷가 = D 믹솔리디안 · 하늘 = A♭장조. 대장전 = 같은 으뜸음의 단조(도리안).
- **템포**: 평소 **112 BPM**(4/4). 대장전 132. 타이틀 92. 지도 100. 두근두근은 음악 박에 맞춘다(따로 놀면 어지럽다).
- **연쇄 음 오름 사다리**: n번째 펑 = 지금 조의 **5음 음계**에서 n칸 위(으뜸음부터 2옥타브, 10칸이 넘으면 맨 위 칸에서 크기와 반짝이만 키움). 음악 코드와 어긋나지 않게 음계는 음악 엔진이 알려 준다. 음악이 꺼져 있어도 같은 음계를 쓴다.

## 2. 엔진 구조 (`studio/bodyhop/audio/`, 직접 합성)
```
[효과음 목소리들] → sfxBus(gain) ─┬────────────→ preMaster
                                  └→ sendFx → reverb(Convolver) → reverbRet ─┘
[음악 층 L0~L3]  → musicBus(gain) ─┬→ duck(gain) → preMaster
                                   └→ sendMu → reverb (같은 것 하나)
preMaster → 컴프레서(글루) → 리미터(컴프레서 −1dB, 20:1, attack 1ms) → masterGain → destination
```
- **버스 3개**: 효과음 · 음악 · 마스터. 크기는 설정 값(0~1)을 데시벨 곡선으로 바꾼다(`gain = 10^((v−1)·30/20)`, 0이면 0).
- **컴프레서(글루)**: threshold −18dB, ratio 3, knee 6, attack 5ms, release 120ms. **리미터**: −1dB, ratio 20, attack 1ms, release 80ms. 펑 열여섯 개가 겹쳐도 찢어지지 않게.
- **덕킹**: 큰 사건(펑 대·대장 보호막 깨짐·대장 타기·별 셋째)이 나면 musicBus `duck`을 −5dB로 30ms 동안 내리고 350ms 동안 되돌린다. 펑 중·연쇄는 −2dB.
- **공간 울림 = 합성 임펄스**: 시작할 때 한 번, 스테레오 잡음 버퍼에 지수 감쇠(1.4초, `e^(−t·4.5)`)를 곱하고 고역을 조금씩 깎아 만든다. 장마다 길이를 바꾼다: 풀밭 1.1초 · 바닷가 1.6초 · 하늘 2.2초. 컨볼버는 **하나만** 두고 모두 send로 보낸다.
- **스테레오 자리**: 사건의 x좌표를 `StereoPanner`에 넣는다(−0.6~+0.6). 음악은 가운데.
- **동시 발음 제한·우선순위**: 효과음 목소리는 최대 **24개**. 사건마다 우선순위 0~3(3 = 판 깸·실패·대장·별, 2 = 갈아타기·펑·쓰러짐, 1 = 연쇄·맞음·기술, 0 = 발소리·부딪힘·UI 틱). 자리가 차면 우선순위가 가장 낮고 가장 오래된 목소리를 15ms 페이드로 끊는다. 0등급은 같은 종류 4개까지만, 같은 소리는 **30ms 안에 다시 울리지 않고 한데 합친다**(합칠 때마다 +1.5dB, 최대 +6dB).
- **무작위 ±**: 모든 소리에 높낮이 ±3%(사다리 음은 ±0.5%만), 크기 ±1.5dB, 시작 0~8ms. 시드 없는 `Math.random`(연출이라 결정성과 무관).
- **깨우기**: 첫 누름에서 `AudioContext({latencyHint:'interactive'})`. 탭이 숨으면 suspend, 돌아오면 resume. Node(봇·테스트)에서는 아무것도 하지 않는다.
- **지연**: 사건 → 소리는 `currentTime + 5ms`. 효과음은 박자에 맞추지 않는다(손맛이 먼저다). 음악만 박자를 따른다.

## 3. 사건별 효과음 (층: 타격음 + 저음 쿵 + 고음 반짝 + 울림 send)
| 사건 (지금 이벤트) | 우선 | 층 | 합성 레시피 한 줄 |
|---|---|---|---|
| 톡 (`tap`) | 0 | 타격 | 사각 1.8kHz 25ms + 고역 잡음 10ms, 울림 0 |
| 못 탐 (`deny`, 보호막) | 1 | 타격·반짝 | 사각 340Hz→300 60ms 두 번(부-부), 금속 FM 링 2kHz 짧게 |
| **갈아타기 슝** (`hop`) | 2 | 타격·반짝·울림 | 대역 잡음 400→3.2kHz 180ms(거리에 맞춰 길이) + 사인 600→1400Hz 비브라토, 팬이 출발점→도착점 |
| **쏙** (`in`) | 2 | 타격·쿵·반짝 | 몸 크기로 음높이: 사인 고무 boing(작은 몸 1.4×, 대장 0.6×) + 사인 90Hz 쿵 60ms + 유리 반짝 2.6kHz 120ms, 울림 15% |
| 펑 소 (작은 몸) | 2 | 타격·반짝 | 잡음 파열 40ms(밴드 2.5kHz) + 사인 520→1100Hz 90ms + 반짝 3kHz |
| 펑 중 (범위에 2~4) | 2 | +쿵·울림 | 위 + 사인 110→45Hz 280ms 쿵 + 잡음 로우패스 500Hz 80ms, 울림 25% |
| 펑 대 (범위에 5+ · 대장 · `boom`) | 3 | 4층 전부 | 위 + 서브 55→30Hz 500ms + crack + 금빛 반짝이 아르페지오 3음, 울림 40%, 덕킹 −5dB |
| **연쇄** (`kill`, n) | 1 | 타격·반짝 | 사다리 음의 삼각 + 2배 배음 120ms + 잡음 톡 20ms. n≥5에서 5도 위를 겹침, n≥10에서 옥타브 위 반짝 |
| 맞음 (`ouch` 내 몸 · `myhit` 적) | 1/0 | 타격·쿵 | 내 몸: 사인 300→160Hz 70ms + 부드러운 잡음 · 적: 나무 톡 1kHz 30ms |
| 체력 위험(빨간 깜박) | 1 | 반짝 | 삼각 880Hz 40ms를 0.5초마다, −14dB |
| **쓰러짐** (`ko`) | 3 | 타격·쿵·울림 | 하강 삼각 392→247Hz 2음 + 사인 쿵 80Hz + shrink, 울림 30% |
| **유령 튀어나옴**(떠다님 4초) | 3 | 반짝·울림 | 사인 400→1200Hz 비브라토 '뿅' + 음악 로우패스 1.2kHz 400ms + 울림 ×2 + 남은 시간마다 유리 틱(마지막 1초는 0.25초 간격) |
| 하트 −1 (`heart`) | 3 | 쿵·울림 | 단3도 하강 2음(삼각) + 저음 쿵 70Hz, 덕킹 −5dB |
| **기운 고리 다 참** (`ready`) | 1 | 반짝 | 첼레스타 2음 상행(조의 5도→으뜸 옥타브) 각 70ms, −10dB, 울림 20% |
| 두근두근 (범위 5+) | 1 | 쿵 | 사인 60Hz 두 번(음악 박에 맞춤), 범위 수가 늘면 +1dB씩 최대 +4dB |
| 대장 보호막 깎임 (`shield`) | 0 | 타격 | 유리 crack 2.4kHz 30ms, 남은 양이 줄수록 높낮이 +2% |
| **대장 보호막 깨짐** (`break`) | 3 | 4층 전부 | 큰 유리 와장창(고역 잡음 400ms) + 서브 쿵 45Hz + FM 종 화음 + 울림 50%, 음악 1마디 쉼표 |
| **대장 타기** (`in`, 대장) | 3 | 4층 전부 | 쏙(0.6×) + 상행 스윕 톱니 200→2kHz 600ms + 팀파니풍 쿵 3번, 음악이 '대장 탔다' 층으로 |
| 대장 큰 기술 (`slam` 대·`thunder`) | 3 | 4층 전부 | 몸 고유 소리 ×1.5, 서브 30Hz, 덕킹 −5dB |
| 큰 띠 'N마리 한 방!' | 3 | 반짝·울림 | 실로폰 3음 상행(사다리 끝 음에서 이어 올림) |
| **별** (하나씩 쾅 · `star3`) | 3 | 쿵·반짝·울림 | 사인 쿵 + 첼레스타 화음(Ⅰ→Ⅳ→Ⅰ 옥타브 위), 셋째 별은 반짝 꼬리 0.8초 |
| **판 깸** (`clear`) | 3 | — | 승리 팡파르(§5)로. 효과음은 쿵 하나 + 반짝 비 |

| 새 물결 문 (`wave`) | 1 | 쿵·타격 | 북 2번 + 먼지 잡음 로우패스 300Hz 200ms |
| 졸개 부르기 (`summon`) | 2 | 쿵·울림 | 톱니 스웰 220→660Hz + 저음 북 1번 |
| 둘 중 하나 열림/고름 | 2/3 | 반짝·울림 | 열림: 패드 스웰 / 고름: coin + chime + 종 |
| UI 클릭 | 0 | 타격 | 누를 때 나무 톡 1.2kHz 20ms, 뗄 때 0.9× · 뒤로 가기는 하강 2음 · 잠긴 것은 deny |

## 4. 몸 13종 고유 소리 (쏙 = 탈 때 · 짓 = 저절로 하는 공격 · 펑 색 = 버릴 때 펑에 섞는 층)
| 몸 | 음역 | 쏙 | 짓 | 펑 색 |
|---|---|---|---|---|
| 콩알이 | 높음 | 삑 사인 1.2kHz 40ms | '콩!' 나무 톡 + 작은 boing | 팝콘 톡 |
| 돌주먹 곰 | 낮음 | 사인 쿵 70Hz + 그르릉 | 주먹: 예비 스웰 → 쿵 60Hz + crack + 먼지 | 저음 쿵 +3dB |
| 가시 고슴도치 | 중고 | 고무 boing 상행 | 핀볼 `ping`: 금속 FM 1.6kHz, 튕긴 횟수마다 사다리 한 칸 위 | 바늘 흩뿌림 |
| 긴 혀 개구리 | 중 | '꾸륵' 삼각 2음 | 혀: 고무줄 늘어남 / 꿀꺽: 사인 400→120Hz + 물방울 | 물 첨벙 |
| 폭탄 두더지 | 중저 | 도화선 칙칙 0.4초 | 대폭발: 펑 대 + 긴 서브 꼬리 | 흙더미 |
| 박치기 염소 | 중 | '메에' 톱니 비브라토 | 돌진: 발굽 다다닥 → 쿵 + boing / 도미노: 나무 톡 사다리 | 쿵 + 종 |
| 방패 거북 | 낮음 | 단단한 껍질 톡 | 빙글: 대역 잡음 원 그리기 / 튕김: 통통 boing | 나무통 쿵 |
| 번개 구름 | 고·넓음 | 정전기 지직 | 연쇄 번개: 톱니 1.4k→200Hz + 크랙, 칸마다 사다리 위 | 작은 천둥 |
| 포자 버섯 | 중고 | 퐁(물방울) | 포자: 부드러운 잡음 + 퐁퐁 / 터짐: 퐁 1.55× | 거품 터짐 여럿 |
| 분신 너구리 | 중 | 휘익 + 뿅 | 분신: chime 3음 / 나뭇잎: 종이 바스락 | 사다리 3칸 연달아 |
| 대장 멧돼지 | 아주 낮음 | 콧김 + 꿀꿀 | 대지진: 서브 30Hz 1초 + 우르릉 + 돌 crack | 큰 북 ×3 |
| 대장 집게 | 낮음·금속 | 집게 딱딱 | 집게 쾅쾅: 금속 링 + 쿵, 좌우 팬 | 조개 와장창 |
| 대장 천둥 용 | 전 음역 | 낮은 포효 | 천둥 숨결: 긴 톱니 스윕 + 크랙 연발 + 서브, 울림 60% | 하늘 천둥 |
- 규칙: **몸마다 음역이 겹치지 않게**(작은 몸 = 높고 짧게, 큰 몸 = 낮고 길게). 도감에서 몸을 누르면 그 몸의 쏙+짓 소리를 미리 들려준다.

## 5. 적응형 음악 (코드 합성, 미리 짠 마디를 스케줄러가 깐다)
- **스케줄러**: 25ms마다 앞으로 120ms 안의 음을 `currentTime` 기준으로 예약. 곡 = 2마디 패턴 × 4 = 8마디 고리. 음 데이터는 코드 안의 작은 배열.

| 층 | 내용 | 켜지는 때 |
|---|---|---|
| L0 바탕 | 패드 코드(Ⅰ–Ⅵ–Ⅳ–Ⅴ) + 뜯는 베이스 4분 | 판 시작 |
| L1 걸음 | 장난감 북: 킥 1·3박, 스네어 2·4박, 셰이커 8분 | 첫 톡 뒤 |
| L2 붐빔 | 마림바 멜로디(5음 음계) + 하이햇 16분 | 붐빔 ≥ 0.4 |
| L3 꽉 참 | 현 아르페지오 16분 + 탐 필인 + 박수 | 붐빔 ≥ 0.7 |
| 떠다님 필터 | 전체 로우패스 1.2kHz + 울림 ×2, 북 빠짐 | 유령 튀어나옴 4초(바로) |

- **붐빔 측정**(0~1, 0.5초 지수 평균): `0.45·min(1, 마당 적 수/18) + 0.35·min(1, 펑 범위 안 수/6) + 0.2·min(1, 최근 2초 처치 수/8)`. 히스테리시스: 올라갈 때 0.4/0.7, 내려갈 때 0.3/0.55.
- **전환 규칙 (마디 단위)**: 층 켜기·끄기는 **다음 마디 첫 박**에만. 켤 때 반 마디 페이드인, 끌 때 한 마디 페이드아웃. 켜지면 **최소 2마디** 유지. 예외(바로): 떠다님 필터, 덕킹, 판 깸, 실패.
- **대장전**: 같은 으뜸음 도리안, 132 BPM, 낮은 현 오스티나토 + 팀파니. 보호막 깨짐 = 1마디 쉼표 → **'대장 탔다' 층**(장조로 전조, 브라스풍 영웅 테마).
- **승리 팡파르**: 지금 마디를 반 박 안에 끊고 Ⅰ–Ⅳ–Ⅴ–Ⅰ 4박 → 결과 화면 루프(L0만). 별이 쾅 할 때마다 화음이 한 단 올라간다.
- **타이틀**: 92 BPM, 유령 테마 4마디(사인 리드 + 비브라토, 리디안 #4 강조) + 먼 관중 웅성·깃발 펄럭.
- **지도**: 100 BPM, 장마다 다른 조의 같은 테마를 우쿨렐레로. 판을 고르면 1박 안에 그 판의 L0로 크로스페이드.
- **장 테마 연결**: 모든 곡이 같은 유령 모티프 4음(5–6–1–3)을 쓴다.

## 6. 믹스 균형 기준값 (기준 0dB = 갈아타기 쏙, 리미터 전)
| 소리 | dB | 소리 | dB |
|---|---|---|---|
| 쏙·슝 | 0 | 판 깸·실패·팡파르 | +2 |
| 펑 소/중/대 | −4 / −1 / +2 | 대장 보호막 깨짐·대장 타기 | +2 |
| 연쇄 한 음 | −8 (n마다 +0.4, 최대 −4) | 별 | 0 |
| 몸 자동 공격 | −10 ~ −6 | 맞음(내 몸) | −8 |
| 발소리·부딪힘·셰이커 | −20 ~ −16 | 기운 고리 다 참 | −10 |
| 두근두근 | −12 ~ −8 | UI 클릭 | −14 |
| 음악 버스(판 안) | 효과음보다 **−9dB**(L3까지 켜져도 −6) | 음악(타이틀·지도·결과) | −3 |

- 목표: 마스터 단기 음량 약 **−16 LUFS**(폰 스피커), 정점 −1dBTP. 폰 스피커는 저역이 사라지므로 쿵에는 늘 2배 배음(140~200Hz)을 함께 넣는다.
- 측정: OfflineAudioContext로 '큰 연쇄 10초'를 렌더해 정점·RMS를 테스트에서 잰다.

## 7. 설정
- 소리 크기 · 음악 크기 **따로**(0~10, 기본 8/6) · 진동 켜기/끄기 · 화면 흔들림 줄이기. 일시정지 화면과 타이틀 설정에.
- 기억: `localStorage` `bodyhop:sfxVol`·`musicVol`·`vibe`(저장 안 되면 이번 판 동안만, 에러 0). 지금 쓰는 `bodyhop:muted`는 처음 한 번 읽어 옮긴다.
- 소리 0이면 sfxBus만 0, 둘 다 0이면 suspend(배터리).
- **진동**(`navigator.vibrate`, 있으면): 갈아타기 10ms · 펑 대 30ms · 보호막 깨짐 [20,40,40] · 하트 −1 60ms. 연쇄에는 쓰지 않는다. 미지원 기기는 조용히 넘어간다.

## 8. 성능 예산
- 오디오 코드 gzip **≤ 14KB**(음악 패턴 포함), 샘플 0바이트.
- 동시 목소리 ≤ 24(효과음) + 음악 ≤ 16. 소리 하나의 노드 ≤ 8개. 끝난 노드는 `onended`로 끊는다. 컨볼버 1개, 잡음 버퍼 1개와 임펄스는 장마다 1개만.
- 메인 스레드: 사건 처리 + 스케줄러가 프레임당 **≤ 0.5ms**(CPU 4배 느림). 프레임 측정에 소리 켠 항목을 더한다.
- 저사양 대비: 목소리 20개를 넘으면 울림 send를 끄고 반짝 층을 생략하는 '가벼운 모드'.
- 테스트(`tests/studio-bodyhop-audio*.test.ts`): Node에서 소리 0 · 모든 사건 이름에 소리 있음 · 사다리 음이 음계 안 · (가능하면) 정점 ≤ −1dBFS.

## 9. M1에서 할 것 / 나중
**M1 (풀밭 4판 + 대장 멧돼지)**
1. 엔진 교체: 버스 3개 + 글루 컴프레서 + 리미터 + 합성 울림 + 팬 + 목소리 상한·우선순위 + 무작위 ±.
2. §3 사건 표 전부(4층) + 콩알이·곰·고슴도치·개구리·염소·멧돼지의 고유 소리.
3. 음계 사다리 연쇄 + 두근두근을 박에 맞춤.
4. 음악: 풀밭 L0~L3 + 떠다님 필터 + 대장전 + 대장 탔다 층 + 승리 팡파르 + 타이틀 + 지도(풀밭 하나).
5. 설정(크기 따로·기억·진동) + 믹스 기준값 테스트 + 성능 측정.
- 허들 기여: 폰 스피커로 첫 5분을 들었을 때 "소리가 대형 게임 같다" — 쿵이 들리고 연쇄가 노래가 된다.

**나중 (M2~)**: 바닷가·하늘 조와 악기 색, 나머지 몸 소리 · 장 끝 물건 소리 · 유령 레벨 차림마다 슝 음색 진화 · 무한 모드 음악(붐빔에 따라 템포 +4 BPM씩) · 도감 '소리 듣기' · 필요하면 오디오워클릿 · 접근성: 중요한 소리를 화면 표시로도.
