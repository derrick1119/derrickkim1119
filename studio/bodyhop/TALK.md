## 사이클 1″ · 2026-11-21 · 📱 아이폰에서 화면이 검은 블록으로 깨짐

💬 **오너**(아이폰 스크린샷): "그래픽이 이렇게 깨져서 보여" — 화면 대부분이 큰 검은 사각형, 귀퉁이 몇 군데만 제대로.

✏️ **개발자**: 모양이 빛 번짐(블룸) 단계의 저해상도 블록과 같다 → 장면 HDR 버퍼에 NaN·Inf 한 점이 생기면 블룸이 그것을 사각 블록으로 번지고, 톤맵 뒤 검게 된다. 데스크톱 크롬(소프트웨어 GL)에선 NaN이 0개라 재현이 안 됐다(`?nan=1` 버퍼 검사) — 애플 GPU에서만 나는 값들을 원인으로 보고 전부 막았다:
- 셰이더의 pow 밑이 아주 작은 음수가 될 수 있던 곳(프레넬 `1 − N·V`, GGX의 `1 − H·V`) → 0~1로 묶음. 0 벡터 normalize(넓이 0 삼각형 — 회전체 꼭지의 법선 0, 수명 끝 파편의 크기 0 행렬) → 위쪽 법선으로 대체·크기 하한.
- 이중 안전망: 블룸 입구와 마지막 합성에서 이상한 값(NaN·Inf·과대)을 0으로 지움 → 한 점이 남아도 블록으로 번질 수 없음. 장면 출력도 0~60으로 묶음.
- 이 기기가 반정밀도 MSAA 버퍼를 못 만들면 8비트로 자동 대체 · WebGL 컨텍스트를 잃으면 다시 불러옴 · `?safe=1` = 블룸 끈 비교 모드.
- 이 환경엔 사파리(WebKit)가 없어 아이폰에서 직접 확인은 못 했다 — 오너 확인 필요.
