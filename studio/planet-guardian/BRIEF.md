# 스튜디오 브리프 — 행성 수호대 (상용화)

> 게임 발견 공장(`arcade/`)에서 오너가 8라운드에 걸쳐 고른 최종 아이디어를 **상용 수준의 게임**으로 다듬는 작업장.
> 이 세션의 운영자는 **전문 게임 기획자 겸 개발자**다. 기획 문서로 먼저 결정하고, 만들고, 직접 플레이해 확인한다.

## 출발점
- 프로토타입: `arcade/games/guardian2.ts` (행성 수호대 2) — 이 파일은 **읽기만** 한다(공장 소유). 코드는 복사해서 `studio/planet-guardian/`에서 새로 키운다.
- 한 줄 요약: 작은 행성을 운석에서 지키는 수호 편대. 화면 왼쪽/오른쪽을 누르고 있는 동안 편대가 궤도를 돌며 자동 사격·몸으로 막기.
  행성은 광석을 캐고, 광석이 차면 건설 카드 셋 중 하나를 골라 광산·포탑·위성·방어막을 짓거나 강화(Lv3). 판이 끝나면 기지 전경.

## 오너가 고른 길 (A|B 기록, `arcade/ab.json`)
| 라운드 | 결과 | 오너가 알려준 것 |
|---|---|---|
| 1 | 궤도 꼬리 > 벽돌 수비대 | — |
| 2 | 궤도 수비 > 궤도 꼬리 | 바깥에서 밀려오는 압박 + 처치 → 무작위 강화 |
| 3·4 | 궤도 수비 방어 | 성장 연출이 있는 쪽 |
| 5 | **행성 수호대 > 궤도 수비** | 오너 요청 확장: "아군이 늘고, 행성을 지키는 수호 느낌, 행성에서 생산·채굴, 확대하면 기지 건설" |
| 6·7 | 행성 수호대 방어 | — |
| 8 | **행성 수호대 2 > 행성 수호대** | "굳이 원버튼을 고집할 필요 없어" → 직접 이동·건설 카드 선택·건물 레벨 |

정리하면 오너는: **행성을 지킨다는 정체성**, **저절로 쌓이는 생산·건설 층**, **내 기지가 커지는 걸 보는 맛**, **단순하지만 판단이 있는 조작**을 좋아한다.
초기 피드백도 기억할 것: 논리 퍼즐 시절 "너무 복잡해서 이해하기 어렵다" → 규칙 설명은 3줄 이내, 첫 판 30초 안에 이해.

## 이 세션이 할 일 (전문 기획자 방식)
1. **기획서 먼저** — `studio/planet-guardian/GDD.md`: 핵심 루프(30초·5분·하루), 조작, 적·웨이브 설계, 경제(광석 수입·건설 비용 곡선),
   건물·위성·업그레이드 트리, 판 사이 영구 성장(메타), 온보딩/튜토리얼, 난이도 곡선, 아트·사운드 방향, 수익화 *설계안*(실제 결제·광고 연동은 하지 않음),
   리텐션 장치(데일리·도전 과제), 성공 지표(D1 리텐션 가정, 평균 세션 길이 등). 각 결정에 "왜"를 붙인다.
2. **기획 리뷰어** — 마일스톤마다 Agent 도구로 별도 "시니어 게임 기획자" 서브에이전트에게 GDD와 빌드 스크린샷을 주고 냉정한 비평을 받는다.
   비평 중 받아들인 것·안 받아들인 것과 이유를 `REVIEWS.md`에 남긴다.
3. **마일스톤으로 구현** (한 번에 다 하지 않는다): M1 핵심 손맛(타격감·화면 흔들림·파티클·사운드) → M2 튜토리얼·첫 5분 →
   M3 메타 성장·저장(localStorage, 불가 환경에서도 동작) → M4 콘텐츠(적 종류·보스 웨이브·건물 트리) → M5 다듬기(성능·접근성·모바일).
4. **확인** — 결정적 시뮬레이션을 유지해 봇으로 밸런스를 잰다(`arcade/core.ts`의 방식 참고). UI는 Playwright로 390px 모바일·데스크톱 스크린샷을 찍어 직접 본다.
   콘솔 에러 0, 가로 스크롤 없음, 키보드만으로 플레이 가능.
5. **기록** — `studio/planet-guardian/STATUS.md`: 현재 마일스톤, 플레이 주소, 다음 할 일, **"오너에게"**(결정이 필요한 것만).

  **https://derrick1119.github.io/derrickkim1119/studio/planet-guardian/** (오너가 승인한 공개 주소. 이 환경에서는 github.io에 직접 접속이 막혀 있으니 배포 확인은 GitHub Actions `deploy` 실행 결과로.)

## 가드레일
- 다른 작업장 파일은 수정하지 않는다: `arcade/`, `fusion/`, `factory/`, `engine/`, `web/index.html`, `web/fusion*`, 다른 테스트. 공유 파일은 *추가만*.
- `npm run verify`(전체 테스트) 실패 상태로 push 금지. 테스트 약화·삭제·skip 금지. push가 거절되면 `git pull --rebase origin factory` → verify → push. force push 금지.
- 런타임 의존성 추가 금지(번들은 직접 esbuild로). 외부 서비스 가입·결제·광고 SDK 연동 금지. 비밀값을 저장소에 쓰지 않는다.
- 기존 게임의 이름·캐릭터·아트·레벨을 가져오지 않는다. 행성 수호대는 장르 조각을 조합한 독자 게임이다.
- 커밋 메시지: "스튜디오 행성 수호대: <요약>".
- 오너 결정이 필요하면 STATUS.md "오너에게"에 쓰고 `PushNotification`으로 알린다. 결정이 필요 없으면 알리지 않는다.
