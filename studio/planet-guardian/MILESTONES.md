## M2 첫 5분: 라이트 유저가 첫 판을 이해하고, 지루하지 않게 버틴다

F1·F2는 이제 설정값이라 저절로 통과하므로 '참고'로 내린다. 남은 문제는 **판단이 진짜인가**다. 다시 뽑기는 고르면 비용이 4로 돌아가서 무조건 누르는 게 이득이고(466 > 441), 판이 끝나도 광석이 676 남는다. 그래서 경제를 먼저 고쳐 R1(선택적 다시 뽑기가 이득)을 세운 뒤 롤아웃 봇으로 '갈리는 카드'를 잰다. 순서를 바꾼 이유가 이것이다. 원탭 능력은 오너 결정 사항이라 M2는 그것에 기대지 않는다.

## M3 끝이 있는 판: 끝판이 생기고, 실력이 그 끝을 넘는다
**설계**: 끝(승리)을 먼저 만들고 적은 그 다음에 넣는다. 끝이 있어야 클리어율로 난이도를 잴 수 있다. 실력은 빌드 판단(카드·다시 뽑기·슬롯)에서 나오고, 오너가 승인하면 원탭 능력에서도 나온다. 하드 기준이 되는 롤아웃 봇은 M2-4에서 만든다.
- [ ] M3-1 최종 웨이브(약 8분) + 승리 판정 + 승리 기지 전경 + `?wave=N` 시작 옵션 + **H7 클리어율**(롤아웃 봇 기준) → H1·H2 재측정
- [ ] M3-2 끝판 연쇄 사망 벽 해소(FUN QA C002 P0-3) + **체력 +1 계단 벽을 빌드로 대응하는 위협으로 바꾼다**(FUN QA C004 P0-4, H8) + 쪼개짐(4웨이브부터)
- [ ] M3-3 혜성(6웨이브부터) + 꼬리 경고선. 경고선은 1.5초로 L5와 맞춘다(FUN QA와 합의)
- [ ] M3-4 보스 "모행성 조각": 중간·최종 웨이브, 작은 돌을 뿌리고, 맞을 때마다 금이 간다
- [ ] M3-5 궤도포 카드(10/7/5초 저격). M4에서 메타 해금으로 옮긴다. **오너가 원탭 능력을 승인하면 이 칸에서 함께 구현**(쿨다운 필수)
- [ ] M3-6 밸런스 1: 클리어율과 처치 보상 곡선, 광석 소비처 2종째(등급업, M2에서 옴), 점수에 실력 반영(H4: 콤보 배수·무피격 웨이브 보너스)
- [ ] M3-7 밸런스 2: 정답 빌드 하나를 해소한다(M4 ≥ 2 유지, 방어우선 지배 확인). 궤도포 포함 + 기획 리뷰 R4 반영
- [ ] M3-8 QC + 버퍼

|---|---|
| **H7** 하드(롤아웃) 봇 최종 웨이브 클리어율 20~40% · 미들 봇 10% 이하 · H1·H2·H4·H5·H6 통과 · **H8 최고 빌드 사망 시각 사분위 범위 ≥ 30초**(벽 없음) · **M4 ≥ 2** · L1–L8·M2·R1 유지(혜성 포함 L5) · QC 전부 | ① 한 판에서 쪼개짐·혜성·보스를 모두 만나고, 각각 처음 봤을 때 어떤 카드로 대처할지 보이는가 ② 보스 등장이 판 중반의 절정처럼 느껴지는가 ③ (`?wave=19`로 바로 가서) 최종 웨이브를 깨면 승리 화면과 기지 전경이 "해냈다"로 느껴지는가 |

## M4 메타: 다음 판, 내일 판의 이유
**설계**: 저장 계층을 먼저 만들고 그 위에 화폐→소비처→데일리→과제 순으로 쌓는다. 영구 강화는 작게 한다("다음 판이 조금 쉬워진다" 수준, GDD §6).
- [ ] M4-1 저장 계층: localStorage + 메모리 폴백, 스키마 버전, 깨진 데이터 복구, 음소거 설정 저장. 예외가 나도 게임은 멈추지 않는다
- [ ] M4-2 별 조각(점수/10) 정산 + 결과 화면 표시
- [ ] M4-3 사령부: 1갈래 × 5단계(각 +5~10%) + 궤도포 해금을 여기로 옮김
- [ ] M4-4 오늘의 행성: 날짜 시드(UTC 고정, STATUS에 명시), 오늘 최고 기록, 스포일러 없는 공유 텍스트(클립보드 실패 시 텍스트 표시)
- [ ] M4-5 도전 과제 5개 + 별 조각 보상. 과제마다 봇이나 테스트로 달성 가능함을 증명
- [ ] M4-6 메타 밸런스: 사령부 0단계 vs 5단계 비교 → 기획 리뷰 반영
- [ ] M4-7 QC + 버퍼
- 잘라낸 것: 연속 출석 표시, 행성 꾸미기, 기지 앨범 → 보류(수익화 결정 뒤)

| 완료 기준 | 오너 테스트 시나리오 |
|---|---|
| localStorage가 없거나 예외를 던져도 동작 + 저장/복구 테스트 · 같은 날짜는 같은 운석·같은 카드 박자 테스트 · 공유 텍스트에 시드·기지 구성 없음 · 사령부 5단계를 다 채워도 H7 상승 15%p 이하, 0단계에서 L1–L8 유지 · 과제 5개 달성 경로 테스트 · QC 전부 | ① 두 판을 해서 별 조각을 모으고 사령부 1단계를 산다. 다음 판이 "조금" 쉬워졌다고 느끼는가 ② 새로고침해도 진행이 남아 있는가 ③ 오늘의 행성을 하고 공유 텍스트를 붙여 보면 친구가 스포일러 없이 점수만 보는가 |

## M5 다듬기: 출시 품질
- [ ] M5-1 성능: Playwright에 CPU 4배 감속을 걸고 파티클이 가장 많은 장면의 프레임 시간을 잰다. 필요하면 저사양 모드
- [ ] M5-2 접근성: prefers-reduced-motion, 흔들림 끄기, 색만으로 구분하지 않기, 포커스 표시, aria 라벨
- [ ] M5-3 모바일: safe-area(노치), 가로 화면, 판을 세로로 더 쓰기(M2에서 미룬 R2), visibilitychange 자동 일시정지, 광석 흡수 소리
- [ ] M5-4 최종 기획 리뷰(첫 방문자 관점) 반영
- [ ] M5-5 전체 회귀 QC + 오너 출시 점검표 작성

## 일정 규칙
1. 마일스톤이 예상 사이클의 **150%**(위 표의 한도)에 닿으면 PM이 범위 축소를 결정한다. 남은 항목 중 완료 기준과 무관한 것은 다음 마일스톤이나 보류로 옮기고, 이유를 TALK 📋에 남긴다. 완료 기준 자체는 낮추지 않는다. 한도는 처음 추정을 기준으로 하며, 재추정한다고 올리지 않는다.
2. 한 작업 항목이 2사이클 연속 끝나지 않으면 다음 사이클 시작 전에 PM이 반으로 쪼갠다.
3. FUN 지표 목표를 바꾸려면 FUN QA의 근거(유저군 논리)와 TALK 기록이 있어야 하고, 오너 테스트 요청 때 그 사실을 밝힌다. 통과시키려고 목표를 옮기는 것은 금지다.
4. 완료 기준을 모두 넘으면 남은 체크박스와 상관없이 QC로 간다. 남은 항목은 다음 마일스톤으로 넘긴다.
5. 오너 피드백이 오면 다음 사이클은 그 피드백이 최우선이다(1~2사이클, 마일스톤 일정과 별도로 센다). 반영 뒤 다음 마일스톤을 시작한다. 그 사이클에 끝난 마일스톤 항목은 체크하되 사이클 수에는 넣지 않는다.
6. 전체 예산은 M2–M5 27사이클이고 절대 상한은 35다. C003에서 M2 +1, M3 −1로 옮겼다. **C004에서 M2 +1(롤아웃 봇 밀림)로 합계 28이 되어 예산을 1 넘었다.** M3는 체력 계단 벽이 더해져 줄이지 않는다. M3 시작 때 다시 본다. 35에 닿으면 M5 범위를 PM이 잘라서 끝낸다.
7. 매 사이클 PM은 "지금" 표(진척 %, 다음 오너 테스트 시각 UTC/KST)를 다시 계산한다.
