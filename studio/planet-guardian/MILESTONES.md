## M2 첫 5분: 라이트 유저가 첫 판을 이해하고 버틴다
**설계**: 원래 범위의 절반은 "판이 작고 운석이 갑자기 나타난다"(R2, L5) 문제다. 튜토리얼보다 판 크기를 먼저 고친다. 리뷰 R2: "입력 충돌과 화면 크기를 고치기 전엔 튜토리얼을 쓰지 마라."
- [ ] M2-1 판을 세로로 더 쓴다. 크기 기준을 가로폭이 아니라 짧은 변·긴 변 혼합으로 바꾸고, 배·운석을 키운다 → 밸런스 재측정 (R2)
- [ ] M2-2 **L5 해결**: 운석이 화면 안에서 1.5초 이상 보이게 한다(출발 반지름과 화면 비율, 첫 등장 감속). 화면 밖 화살표 시간은 경고로 치지 않는다
- [ ] M2-3 카드 입력 모델: 숨 고르기 동안 카드를 펼친다. 전투 중에는 "카드 준비됨" 표시만 띄우고, 실수 선택을 막는 장치를 하나만 둔다(꾹 누르기 또는 위로 밀기). 첫 판 0.3배속 안은 **뺀다**(숨 고르기로 대체)
- [ ] M2-4 튜토리얼 웨이브: 첫 30초는 운석이 한쪽에서만 천천히 오고, 손가락 아이콘이 누를 곳을 가리킨다. 첫 카드에 "새 포탑"을 보장한다. 결정성 테스트도 갱신
- [ ] M2-5 자비 장치(같은 카드 두 장 금지, 내구도 1이면 방어막 확률 상승) + 카드 정보 위계(공격·방어·경제 색과 아이콘, 현재값→다음값)
- [ ] M2-6 결과 화면: 무엇에 죽었는지 + 다음 목표 한 줄("광산 하나만 지었어도…")
- [ ] M2-7 기획 리뷰 R3(스크린샷) 반영 + QC + 버퍼
- 잘라낸 것: 광석 흡수 소리 → M5. 판 중 0.3배속 → 삭제

## M3 끝이 있는 판: 끝판이 생기고, 실력이 그 끝을 넘는다
**설계**: 끝(승리)을 먼저 만들고 적은 그 다음에 넣는다. 끝이 있어야 클리어율로 난이도를 잴 수 있다. **H3**(몸으로 막기 82.6%)는 쪼개짐 적이 해결하는 문제로 본다: 몸으로 막으면 작은 돌 2개가 남아서 총이 필요해진다.
- [ ] M3-1 최종 웨이브(약 8분, 웨이브 20 근처) + 승리 판정 + 승리 기지 전경 + 오너 테스트용 `?wave=N` 시작 옵션. funqa에 **H5 클리어율** 추가를 FUN QA에 요청
- [ ] M3-2 쪼개짐(4웨이브부터) → H3 재측정. 아직 40% 넘으면 M3-6에서 몸 막기 처치 보상을 줄인다(경직 안은 계속 보류)
- [ ] M3-3 혜성(6웨이브부터) + 꼬리 경고선. **주의**: GDD의 "경고선 1초"는 L5(1.5초)와 충돌한다. 경고선 1.5초로 맞추거나 L5에서 경고선 시간을 경고로 친다(FUN QA와 합의)
- [ ] M3-4 보스 "모행성 조각": 중간·최종 웨이브에 등장, 작은 돌을 뿌림, 맞을 때마다 금이 감

## M4 메타: 다음 판, 내일 판의 이유
**설계**: 저장 계층을 먼저 만들고 그 위에 화폐→소비처→데일리→과제 순으로 쌓는다. 영구 강화는 작게 한다("다음 판이 조금 쉬워진다" 수준, GDD §6).
- [ ] M4-1 저장 계층: localStorage + 메모리 폴백, 스키마 버전, 깨진 데이터 복구, 음소거 설정 저장. 예외가 나도 게임은 멈추지 않는다
- [ ] M4-2 별 조각(점수/10) 정산 + 결과 화면 표시
- [ ] M4-3 사령부: 1갈래 × 5단계(각 +5~10%) + 궤도포 해금을 여기로 옮김
- [ ] M4-4 오늘의 행성: 날짜 시드(KST 자정 기준인지 오너 결정 없이 UTC로 고정하고 STATUS에 명시), 오늘 최고 기록, 스포일러 없는 공유 텍스트(클립보드 실패 시 텍스트 표시)
- [ ] M4-5 도전 과제 5개 + 별 조각 보상. 과제마다 봇이나 테스트로 달성 가능함을 증명
- [ ] M4-6 메타 밸런스: 사령부 0단계 vs 5단계 비교 → 기획 리뷰 반영
- [ ] M4-7 QC + 버퍼
- 잘라낸 것: 연속 출석 표시, 행성 꾸미기, 기지 앨범 → 보류(수익화 결정 뒤)

| 완료 기준 | 오너 테스트 시나리오 |
|---|---|
| localStorage가 없거나 예외를 던져도 동작 + 저장/복구 테스트 · 같은 날짜는 같은 운석 테스트 · 공유 텍스트에 시드·기지 구성 없음 · 사령부 5단계를 다 채워도 H5 상승 15%p 이하, 0단계 L1–L5 유지 · 과제 5개 달성 경로 테스트 · QC 전부 | ① 두 판을 해서 별 조각을 모으고 사령부 1단계를 산다. 다음 판이 "조금" 쉬워졌다고 느끼는가 ② 새로고침해도 진행이 남아 있는가 ③ 오늘의 행성을 하고 공유 텍스트를 붙여 보면 친구가 스포일러 없이 점수만 보는가 |

## 일정 규칙
1. 마일스톤이 예상 사이클의 **150%**(위 표의 한도)에 닿으면 PM이 범위 축소를 결정한다. 남은 항목 중 완료 기준과 무관한 것은 다음 마일스톤이나 보류로 옮기고, 이유를 TALK 📋에 남긴다. 완료 기준 자체는 낮추지 않는다.
2. 한 작업 항목이 2사이클 연속 끝나지 않으면 다음 사이클 시작 전에 PM이 반으로 쪼갠다.
3. FUN 지표 목표를 바꾸려면 FUN QA의 근거(유저군 논리)와 TALK 기록이 있어야 하고, 오너 테스트 요청 때 그 사실을 밝힌다. 통과시키려고 목표를 옮기는 것은 금지다.
4. 완료 기준을 모두 넘으면 남은 체크박스와 상관없이 QC로 간다. 남은 항목은 다음 마일스톤으로 넘긴다.
5. 오너 피드백이 오면 다음 사이클은 그 피드백이 최우선이다(1~2사이클, 마일스톤 일정과 별도로 센다). 반영 뒤 다음 마일스톤을 시작한다.
6. 전체 예산은 M2–M5 28사이클이고 절대 상한은 35다. 35에 닿으면 M5 범위를 PM이 잘라서 끝낸다.
7. 매 사이클 PM은 "지금" 표(진척 %, 다음 오너 테스트 시각 UTC/KST)를 다시 계산한다.
