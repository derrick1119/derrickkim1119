### 안 받아들임 / 바꿔 받아들임
- **조작을 A|B로 시험** → 바로 "누른 곳으로 간다"를 기본으로 했다. 이유: 이 저장소의 A|B는 오너가 직접 두 판을 해 봐야 판정되는데, 화면 아래쪽 반전은 버그에 가까워 기다릴 이유가 약하다. 대신 STATUS "오너에게"에 되돌릴 수 있다고 적었다.
- **몸으로 막을 때 편대 0.4초 경직** → 보류. M1은 손맛만, 규칙 비용은 M2 초보 봇 측정 후 판단(경직은 조작감을 해칠 위험이 크다).
- **처치 보상 웨이브 반비례** → M3에서 측정 후. 지금 판 길이(4분)에서는 광산이 아직 함정 카드가 아니다(잘하는 봇도 광산을 고른다).

## R2 — M1 빌드 스크린샷 7장 + juice/audio (2026-11-07)

리뷰어 한 줄: "손맛 뼈대는 섰다. 입력 충돌과 화면 크기를 고치기 전엔 튜토리얼을 쓰지 마라."

### 받아들임 (M1에 바로 반영)
- 카드가 없을 때도 아래 16%가 조종 불가 → **카드가 떠 있을 때만** 아래 띠가 카드 영역, 아니면 어디든 조종.
- 몸으로 막기 효과 다섯 겹 과다 → 저음 0.5→0.22(행성 피격 0.8과 귀로 구분), "막았다!"는 처음 두 번과 연속 3 이상만.
- 자동 사격음이 콤보 음계를 덮음 → 편대 사격만 아주 작게(0.018), 포탑 무음.
- 맞았는데 안 죽은 순간이 약함 → 불꽃 늘림 + 흰 작은 고리(운석 흰 번쩍은 이미 있음).
- 죽는 순간이 흔들림 상한에 잘려 피격과 같은 세기 → 죽음은 상한 예외(0.07).
- 행성 옆 어긋난 얇은 원(포탑 사거리) 의미 불명 → 삭제.
- 배가 화면에서 가장 작은 물체 → 흰 외곽선(크기는 충돌 판정과 같게 유지 — 보이는 것보다 넓게 막으면 거짓말).
- 방어막 점이 작다 → 지름 약 1.4배.
- 터치 기기에서 카드에 키보드 번호 → `any-pointer: fine`이 없으면 숨김.

### M2로 미룸 (튜토리얼·첫 5분과 같이 설계해야 하는 것)
- **판을 세로로 더 쓰기 / 배·운석 키우기**: 크기 기준이 가로폭에 묶여 있다. 운석 출발 반지름(1.05)·궤도(0.43) 비율을 바꾸는 일이라 밸런스 재측정이 필요 → M2 첫 작업.
- 카드 실수 선택 방지(꾹 누르기·위로 밀기 또는 카드 중 감속): R1의 "카드는 숨 고르기에" 안과 함께 결정.
- 카드 정보 위계(공격·방어·경제 색/아이콘, 현재값→다음값).
- 결과 화면: 무엇에 죽었나 + 다음 목표("광산 하나만 지었어도…"), 첫 판 기지가 초라한 문제.
- 광석 흡수 소리 · 흡수 지점 근처 광석 표시.

### 안 받아들임
- "타이틀 3단 설명 글이 두껍다 → 글 대신 직접 해 보기": 방향엔 동의하지만 M2 튜토리얼 웨이브가 그 일을 한다. 그때까지 3줄은 둔다(BRIEF: 규칙 3줄 이내는 지킴).
