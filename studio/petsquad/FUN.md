### 재미 기준 P1~P12 (재는 법 → 통과선)
- **P1 첫 톡이 크게 반응** (기준 2): 첫 톡 뒤 0.3초 안에 '쿵'·흔들림·말풍선이 나오는지(shots 02). → 통과선: 매번 나옴.
- **P2 첫 30초 안에 합체** (기준 2): 처음 봇의 `첫톡에서첫와초`, 그리고 사람 추정(봇 초 + 톡 수 × 1.5초). → 통과선: 처음 봇 중앙값 ≤ 10초, 사람 추정 ≤ 30초.
- **P3 첫 승리가 빠르다** (기준 2·5): 첫 톡부터 1판 승리 연출까지 사람 추정 초. → 통과선: ≤ 30초.
- **P4 첫 판은 거의 못 진다** (기준 5): 처음 봇의 1판 클리어. → 통과선: ≥ 0.95. 2판 ≥ 0.85.
- **P5 처음 하는 사람이 벽에 막히지 않는다** (기준 5): 처음 봇·캐주얼 봇의 `도달판`. → 통과선: 캐주얼 봇 도달판 ≥ 5, 끝까지 ≥ 0.3 (지면 그 판만 다시이므로 하트 0은 '벽'으로 본다).
- **P6 뒤 판일수록 큰 순간이 줄지 않는다** (기준 4·7): 판별 큰 순간 수(숙련 봇). json에 판별 칸 추가 필요. → 통과선: 2판부터 판마다 1판의 ≥ 80%, 7판(우두머리) ≥ 1판.
- **P7 버릇으로 ★3 금지** (기준 8): 3판부터 버릇 봇 2종의 판별 ★3 비율. json에 칸 추가 필요. → 통과선: < 50% (목표 ≤ 25%).
- **P8 숙련이 ★3에 닿는다** (기준 6): 숙련 봇 판별 ★3 비율·전체 별(최대 18). → 통과선: 판마다 ★3 ≥ 0.6, 전체 별 ≥ 15.
- **P9 실력 격차** (기준 8): 숙련 별 ÷ 처음 봇 별. → 통과선: ≥ 3.
- **P10 번거로움 없음** (기준 11): 판당 톡 수, 판당 다시 뽑기 수(숙련·캐주얼). → 통과선: 판당 톡 ≤ 8, 다시 뽑기 ≤ 2.
- **P11 한 회차 길이와 천장** (기준 7): 숙련 봇 한 회차 초 + 사람 추정. → 통과선: 첫 회차 사람 기준 ≥ 6분, 판 수 ≥ 15(M2까지), 새것 사이 빈 구간 ≤ 3판.
- **P12 웃김** (기준 9): 지는 판 연출(으앙·데굴)과 구경꾼 반응이 지는 판마다 1번 이상. → 통과선: 지는 판 100%.

### 지금 빌드 평가 (M0)
**처음 하는 사람**
- 좋음: 손가락 그림 + "사자 카드를 톡!"(01) → "하나 더! 같은 동물 셋이면 합체"(02) → 빛기둥 '빵! 합체!'(03)까지 단계별 안내가 분명하다. 첫 톡에 '어흥!' 말풍선이 바로 뜬다. 힘 막대 "지금 싸우면 이겨요!"가 다음 할 일을 알려 준다. 첫 승리 '무당벌레 셋 이겼다! ★ 금화 +5'(06)가 깔끔하다.
