# THE LAMP: 작은 밤들

> 한 칸씩, 한 턴씩. 빛이 닿는 곳만 낮이 된다.

밤하늘에 떠 있는 작은 뜰 위에서 전구가 한 칸씩 굴러가는 **3D 디오라마 턴제 퍼즐**입니다.
전구가 실제 광원이 되어 벽과 상자의 그림자를 드리웁니다 (three.js).

```bash
npm start     # http://localhost:8080
npm test      # 풀이기 검증 + 브라우저(WebGL) 테스트
```

## 규칙

한 턴에 한 가지: 한 칸 굴러가거나, 불을 켜고 끄거나. 언제든 무를 수 있습니다.

- **빛**은 전구에서 두 칸까지 번지고, 벽과 상자에 막힌다.
- **낮의 돌**은 빛이 닿는 동안에만, **밤의 돌**은 빛이 닿지 않는 동안에만 딛을 수 있다.
- **빛꽃**은 빛이 닿으면 핀다 (판마다 세 송이).
- **등불**은 불 켠 전구가 곁에 서면 켜지고, 제 옆 칸을 영영 밝힌다. 금도 낫게 한다.
- **상자**는 밀 수 있고 빛을 막는다. 상자 그늘 속의 밤의 돌은 사라지지 않는다.
- **그림자**는 빛이 닿지 않으면 한 칸씩 다가온다. 밤의 돌 위에 있을 때 빛을 비추면 떨어진다.
- **나방**은 불이 켜져 있으면 날아든다.
- 한 번 물리면 금이 가고, 금 간 채로 또 물리면 깨진다.

조작: 방향키/WASD(모바일은 화면 밀기) · 빛 Space · 무르기 Z · 처음부터 R · 힌트 H

## 풀이기가 중심에 있다

턴제라서 판의 상태를 전부 탐색할 수 있습니다. 같은 풀이기(`js/solver.js`)를 세 군데에서 씁니다.

| 쓰임 | 설명 |
|---|---|
| **검증** `tools/verify.mjs` | 모든 판을 다시 풀어, 빛꽃을 다 피우고 깰 수 있는지와 적어 둔 최소 턴이 맞는지 확인 |
| **생성** `tools/gen.mjs` | 무작위 판을 수천 개 만들고 풀이기로 걸러 낸다. 스위치 없이는 못 깨고, 놓인 것 하나하나를 빼면 답이 달라지는 판만 남긴다 |
| **힌트** (게임 안) | 지금 상태에서 풀이기를 돌려 다음 한 수를 알려 준다 |

판은 `js/levels.js`(각 장의 첫 판, 손으로 만든 것)와 `js/levels-gen.js`(생성기가 고른 것)에 글자 지도로 들어 있습니다.

```
#  벽      .  바닥      (빈칸) 허공     D  낮의 돌     N  밤의 돌
L  등불    *  빛꽃(3)   S  시작         E  출구        s  그림자   w  나방   c  상자
```

판을 직접 그려 넣은 뒤 `node tools/verify.mjs` 를 돌리면 풀 수 있는지, 최소 몇 턴인지 알려 줍니다.

## 코드

| 파일 | 내용 |
|---|---|
| `js/rules.js` | 규칙. 화면 없이 Node 에서도 돈다 |
| `js/solver.js` | 너비 우선 탐색 풀이기 |
| `js/scene.js` | 3D 장면: 떠 있는 뜰, 전구의 빛과 그림자, 연출 |
| `js/main.js` | 턴 진행, 무르기, 힌트, 화면 전환, 저장 |
| `vendor/` | three.js r160 (MIT) |
