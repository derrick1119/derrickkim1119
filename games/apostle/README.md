# THE LAMP: 빛의 사도 (Apostle of Light)

**무엇에든 깃드는 빛**이 되어, 잃어버린 빛을 찾아가는 클레이 애니메이션 퍼즐 플랫포머.
주인공은 전구가 아니라 작은 빛 알갱이 — 데이가 떼어 준 빛 한 조각 — 이고, 길에서 만나는 **등불 · 검 · 활**에 들어갔다 나오며 나아갑니다.

```bash
npm start     # http://localhost:8080
npm test      # 자동 플레이 검증(9개 길) + 브라우저 종합 검증(45항목)
```

## 이야기

밤마다 마을을 밝히던 불빛이 하룻밤 사이에 모두 사라졌다. 낮의 아이 **데이**는 제 빛 한 조각을 떼어 사도로 보낸다.
빛을 가져간 건 쌍둥이 동생 **나이트**였다 — 사람들이 밤마다 불을 켜서 별이 보이지 않고, 밤의 아이들이 잘 곳이 없어졌기 때문에.

게임은 이것을 말로 설명하지 않고 **플레이어가 한 일**로 돌려줍니다.

- 처음에 어둠의 아이들(어둑이)은 어둠 속에서 다가와 빛을 꺼뜨리는 적처럼 보인다. 섬광 한 번이면 꺼진다.
- 뒤로 갈수록 그들은 달려들지 않는다. 굴에서 자고 있고, 수정 위에서 졸고, 새끼들을 등 뒤에 가리고 두 팔을 벌려 서 있을 뿐이다.
- 꺼진 자리에는 폭발 대신 작은 한숨 소리와 **빛을 잃은 별 하나**가 남는다. 나이트의 자장가는 아이가 꺼질 때마다 음이 하나씩 빠진다.
- 장이 끝나면 별이 한 줄 뜬다. 설명은 없다. 셋째 장부터 그 줄에 "남은 밤의 아이들"이라는 이름이 붙는다.
- 마지막에 데이가 큰 등의 불빛을 낮추면 밤하늘이 드러나고, **네 장에서 살려 둔 아이들 수만큼만 별이 뜬다.** 빈 자리는 꺼뜨린 아이들의 것이다.

그리고 모든 장에는 **한 아이도 꺼뜨리지 않고 지나가는 길**이 있습니다. 게임은 그 길을 알려 주지 않습니다.

## 깃들 수 있는 것

| | 하는 일 (X) | 몸의 특징 | 살리는 쪽으로 쓰면 |
|---|---|---|---|
| **빛 알갱이** (본모습) | — | 날아다닌다. 떠나온 몸에서 실 한 가닥(10칸)만큼만 멀어질 수 있다 | 희미한 빛이라 아이들이 다치지 않고 **비켜 선다**. 나방은 그냥 따라온다 |
| **등불** | 켜고 끈다. 켜는 순간 **섬광** | 키가 작아 낮은 굴을 지난다. 세워 두면 계속 빛난다 | 멀리서 미리 켜고 다가가면 섬광 없이 물러나게만 한다 |
| **검** | 휘두르면 빛난다 (밧줄 · 수정 · 아이들) | **나무 벽에 박힌다.** 박아 두고 떠나면 다른 몸의 디딤판 | 지키는 것 위로 난 밤의 돌 길은 불이 없는 검에게만 보인다 |
| **활** | 빛의 화살 (↑ 로 비스듬히) | **나무에 꽂힌 화살은 디딤판**이자 작은 등불 | 쏘기 전에 빛 알갱이로 나방을 데려다 놓는다 |

원작의 규칙도 그대로 있습니다: **낮의 돌**은 빛이 닿을 때만, **밤의 돌**은 어둠 속에서만 단단하다.
여기에 **반딧불이 이끼** — 불을 끄고 가만히 서 있어야 모여서 길을 열어 준다 — 가 더해졌습니다. 어둠이 있어야 열리는 문입니다.

## 네 개의 장

| | 장 | 깃드는 것 | 배우는 것 | 밤의 아이들 |
|---|---|---|---|---|
| 1 | 꺼진 숲길 | 등불 | 낮의 돌 · 밤의 돌, 섬광, 공중에서 끄기 | 8 |
| 2 | 버려진 성 | 검 + 등불 | 밧줄 끊기, 나무 벽 타기, 검을 디딤판으로, 등불을 세워 두고 건너기 | 7 |
| 3 | 별 보는 절벽 | 활 (+ 등불) | 멀리 쏘기, 화살 디딤판, 반딧불이, 화살을 번갈아 꽂아 오르기 | 6 |
| 4 | 밤의 정원 | 셋 중 무엇이든 | 아무도 달려들지 않는다. 큰 등까지 | 13 |

## 검증 (`npm test`)

**1. 자동 플레이** — `tools/ghosts.mjs` (화면 없이 실제 규칙 위에서)

장마다 두 가지 대본이 끝까지 닿는지 확인합니다.
- `bright` — 처음 하는 사람이 할 법한 길. 막아서는 것은 꺼뜨리며 간다.
- `spare` — **하나도 꺼뜨리지 않는 길.** 그런 길이 정말 있다는 증명. (넷째 장은 등불로 하나, 검으로 하나 — `gentle`)

```
✓ forest  bright 도착 · 남은 아이 6/8      ✓ forest  spare  도착 · 남은 아이 8/8
✓ castle  bright 도착 · 남은 아이 3/7      ✓ castle  spare  도착 · 남은 아이 7/7
✓ cliff   bright 도착 · 남은 아이 4/6      ✓ cliff   spare  도착 · 남은 아이 6/6
✓ garden  bright 도착 · 남은 아이 11/13    ✓ garden  spare / gentle 도착 · 남은 아이 13/13
```

**2. 브라우저 종합** — `tools/smoke.mjs` (헤드리스 Chromium, 45항목)
첫 화면 → 이야기 → 키보드로 깃들기 · 불 켜기 · 걷기 · 뛰기 → 멈춤 → 꺼짐과 제단으로 되돌아옴 → 장 끝의 별 줄 → 다음 장 → 새로 열어 이어하기 · 장 고르기 → 네 장을 모두 지나 결말 → "뜬 별의 수 = 네 장에서 남긴 아이들의 수" → 영어 전환 → 터치 버튼.

`node tools/shot.mjs <폴더>` 는 대본을 원하는 지점까지 돌린 장면을 스크린샷으로 남기고, `node tools/map.mjs <0-3>` 은 길을 글자로 찍어 줍니다.

## 아직 아닌 것

- **사람이 해 본 적이 없습니다.** 자동 플레이는 "깰 수 있다"와 "살리는 길이 있다"를 증명할 뿐입니다. 퍼즐이 읽히는지, 미안함이 실제로 오는지는 직접 해 봐야 압니다.
- 실제 그래픽 카드에서의 속도를 재 보지 못했습니다 (검증 환경은 소프트웨어 렌더러). 느린 기기에서는 스스로 그림자를 가볍게 바꿉니다.
- 소리는 오류 없이 재생되는 것만 확인했고, 어떻게 들리는지는 모릅니다.
- 깃들 수 있는 것은 셋뿐입니다. 거울 방패(빛을 꺾는다), 연(빛을 싣고 난다), 종(소리로 번지는 빛) 같은 것이 다음 후보입니다.
- 모양과 소리는 모두 코드로 만든 임시본입니다.
