# THE LAMP: 불 꺼진 숲 (The Unlit Wood)

점토로 빚은 어두운 숲을 **전구 머리를 한 아이**가 건너는, 말 없는 횡스크롤 어드벤처.
어둡고 조용하고 죽음이 가까운 분위기(Limbo · Inside 가 연 장르의 문법)를 **클레이 애니메이션**으로 옮겼습니다.
캐릭터와 장면, 퍼즐은 그 게임들에서 가져온 것이 아니라 THE LAMP 의 규칙 — 깨지기 쉬운 유리, 켜고 끄는 빛, 나방과 그림자 — 에서 새로 만든 것입니다.

```bash
npm start     # http://localhost:8080
npm test      # 자동 플레이 검증 + 브라우저 종합 검증
```

## 하나의 스위치, 두 가지 위험

| | 불을 **켜면** | 불을 **끄면** |
|---|---|---|
| 길 | 유리 조각과 구덩이가 보인다 | 윤곽만 보인다 |
| 나방 | 0.8초쯤 뒤 떼로 달려든다 | 길을 잃고 둥지로 돌아간다 |
| 그림자 | 땅에 가라앉아 지나갈 수 있다 | 일어나서 다가온다 |
| 감시자 | 시선 안에 있으면 들킨다 | 그냥 점토 덩어리로 보인다 |
| 그 밖에 | 승강대가 오르고, 빛꽃이 핀다 | — |

전구는 유리라서 한 번 다치면 **금이 가고**, 금 간 채로 또 다치면 **깨집니다**. 등불을 지나면 금이 낫고 그 자리가 다시 서는 곳이 됩니다.
유리 조각·구덩이·감시자·밀물은 한 번에 끝납니다.

## 길 (한 번에 이어진 256칸, 익숙해지면 2분 · 처음엔 10분 안팎)

| | 곳 | 배우는 것 |
|---|---|---|
| 1 | 깨어나는 빈터 | 불 켜기, 걷기, 뛰기. 시작점 **왼쪽**에 첫 빛꽃 |
| 2 | 상자와 턱 | 밀기와 **끌기**. 상자를 반대로 가져가면 선반 위 빛꽃 |
| 3 | 나방 굴 | 불을 켜면 나방, 끄면 유리 조각이 안 보인다 → 짧게 깜빡이며 외워서 지나간다 |
| 4 | 그림자 골짜기 | 불을 켜야 그림자가 가라앉는데, 머리 위엔 나방 둥지 |
| 5 | 감시자의 뜰 | 시선이 지나간 **등 뒤로** 달린다. 지붕 아래는 시선의 그늘 |
| 6 | 승강대 | 발판 위에서 불을 켜고 있는 동안만 오른다. 꼭대기엔 나방 |
| 7 | 끊어진 다리 | 뒤에서 밀물이 덮쳐 온다. 중간의 나방 둥지 밑은 어둠 속에서 뛴다 |
| 8 | 큰 등 | 불을 켠 채 닿으면 숲에 불이 켜진다 |

빛꽃은 일곱 송이. 모두 길에서 조금 벗어난 곳, 불을 켜기 무서운 자리에 있습니다.

## 점토처럼 보이게 한 것들

- **덩어리**: 모든 물체는 꼭짓점을 이어 붙인 뒤 잡음으로 눌러 울퉁불퉁하게 만든다. 이웃한 땅 덩어리는 굴곡이 이어지고, 이음매는 점토판을 맞댄 틈처럼 남긴다.
- **손자국**: 엄지로 누른 자국 · 문지른 자국 · 지문을 높이 그림으로 그린 뒤 법선 지도로 바꿔 모든 점토 재질에 입힌다 (`js/clay.js`).
- **덜 섞인 색**: 두 가지 색을 꼭짓점 단위로 얼룩지게 섞고, 위를 보는 면에는 이끼 색을 덧바른다.
- **스톱모션의 박자**: 인형의 자세는 1초에 12번만 바뀌고(이동은 부드럽게), 표면은 1초에 9번 미세하게 '끓는다'. 카메라 흔들림과 필름 알갱이도 같은 박자.
- **미니어처 세트의 렌즈**: 화각 30° 망원, 위아래 초점 흐림, 비네트.
- **빛**: 뒤에서 비추는 달빛이 윤곽을 따고, 전구의 따뜻한 빛이 비스듬히 스치며 손자국을 드러낸다. 감시자의 시선은 실제 스포트라이트라서 지붕이 진짜 그늘을 만든다.
- 그림 파일 · 소리 파일 없음. 모양과 무늬, 소리 모두 코드로 만든다.

## 검증 (`npm test`)

**1. 자동 플레이** — `tools/ghosts.mjs`
- 대본(`tools/ghost-script.mjs`)이 화면 없이 실제 규칙 위에서 처음부터 끝까지 간다: **한 번도 금 가지 않고, 빛꽃 7송이를 모두 피우고** 도착.
- 반대 검증 10가지: 조심하지 않으면 정말 깨지는지. (불 켠 채 굴을 달리면 나방 · 불 끈 채 걸으면 유리 조각 · 시선 안에서 불 켜고 서 있으면 감시자 · 다리에서 멈추면 밀물 …)

**2. 브라우저 종합** — `tools/smoke.mjs` (헤드리스 Chromium, 32항목)
- 첫 화면 → 시작 → 키보드로 불 켜기 · 걷기 · 뛰기 · 상자 끌기 → 멈춤 → 등불 저장 → 깨짐과 되살아남 → 새로 열어 이어하기 → 끝 화면 → 영어 전환 → 터치 버튼.

`node tools/shot.mjs <폴더>` 는 대본을 원하는 지점까지 돌린 장면을 스크린샷으로 남깁니다. `node tools/map.mjs` 는 길을 글자로 찍어 줍니다.

```
js/world.js    규칙 (화면과 무관, Node 에서도 실행) — 물리, 상자, 나방, 그림자, 감시자, 승강대, 밀물

js/actors.js   배우: 주인공, 나방, 그림자, 감시자, 등불, 빛꽃, 승강대, 밀물, 큰 등
js/scene.js    조명 · 카메라 · 세계 상태를 인형에 옮기기
js/main.js     루프, 메뉴, 저장, 화면 효과      js/audio.js  합성음
vendor/        three.js r160 (MIT)
```

## 아직 아닌 것

- **사람이 해 본 적이 없습니다.** 자동 플레이는 "깰 수 있다"와 "위험이 작동한다"만 증명합니다. 무서운지, 공정한지, 조작이 손에 붙는지는 직접 해 봐야 압니다.
- 실제 그래픽 카드에서의 속도를 재 보지 못했습니다 (검증 환경은 소프트웨어 렌더러). 느린 기기에서는 스스로 그림자를 가볍게 바꾸고, 멈춤 메뉴에서도 바꿀 수 있습니다.
- 길이는 한 장(章) 분량입니다. 이야기(쌍둥이 자매 낮과 밤)는 아직 넣지 않았습니다.
- 모양과 소리는 모두 코드로 만든 임시본입니다. 진짜 점토 인형을 찍어 텍스처로 쓰면 훨씬 좋아질 자리입니다.
