# THE LAMP: 마지막 불씨

> [THE LAMP 모음](../../README.md)의 번외 시제품 (로그라이트 생존 액션). 원작을 확인하기 전에 "빛과 어둠" 주제로 먼저 만들어 본 것입니다.

> 빛은 무기이고, 어둠은 숨을 곳이다.

도시의 가로등이 모두 꺼진 밤, 마지막 등불지기가 새벽까지 불씨를 지키는 **로그라이트 생존 액션**입니다.
램프를 **켜면 싸우고, 끄면 숨는다** — 버튼 하나로 빛과 어둠을 오가는 것이 게임의 전부이자 핵심입니다.

설치 없이 브라우저에서 바로 실행되고(PC · 모바일 겸용), 그림과 소리는 모두 코드로 만들어 외부 에셋이 없습니다.

## 실행

```bash
npm start          # http://localhost:8080
```

빌드 단계가 없습니다. `index.html` 과 `js/`, `css/`, `assets/` 를 그대로 정적 호스팅에 올리면 됩니다.

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 아무 곳이나 끌기 |
| 램프 켜기·끄기 | Space (또는 클릭) | 오른쪽 아래 버튼 (또는 다른 손가락으로 톡) |
| 레벨업 선택 | 1 · 2 · 3, 다시 고르기 R | 카드 누르기 |
| 멈춤 | Esc | 오른쪽 위 버튼 |

게임패드(왼쪽 스틱 + A)도 됩니다.

## 게임 구조

- **기름 = 생명 = 시야.** 램프를 켜 두면 기름이 줄고, 맞으면 쏟아집니다. 기름이 줄수록 빛도 작아집니다.
- **빛(램프 켬)** — 빛 안의 그림자를 자동으로 공격합니다. 모든 그림자가 당신을 향해 옵니다.
- **어둠(램프 끔)** — 그림자가 당신을 놓칩니다. 더 빨리 움직이고, 불씨(경험치)가 멀리서 끌려오고, 기름이 줄지 않습니다.
  어둠 속에서 모은 힘은 다시 켜는 순간 **섬광**으로 터집니다.
- **가로등** — 곁에 서면 불이 붙습니다. 켜진 가로등은 기름을 채워 주고 그림자를 느리게 만듭니다.
  꺼진 가로등 곁에는 그림자가 잠들어 있어, 어둠으로 다가가 섬광으로 깨우는 것이 정석입니다.
- **그림자들** — 그을음(기본), 나방(가로등 불빛에 날아듦), 추적자(빛을 받으면 굳고 어둠 속에서 달려옴),
  침 뱉는 것(원거리), 덩치(돌진), 소등꾼(가로등을 끔), 그리고 **월식**(섬광으로만 깨지는 장막).
- **성장** — 한 판 안에서는 17종의 업그레이드와 3종의 각성, 판 사이에는 루멘으로 사는 영구 강화(등불 공방).
- **다섯 밤** — 새벽을 맞으면 다음 밤이 열립니다. 셋째 밤부터는 월식을 쓰러뜨려야 새벽이 옵니다.

## 코드

| 파일 | 내용 |
|---|---|
| `js/config.js` | **모든 밸런스 수치** — 적, 밤, 업그레이드, 공방 가격 |
| `js/game.js` | 게임 로직. 화면과 분리되어 있어 Node 에서 그대로 돌아갑니다 |
| `js/render.js` | 캔버스 렌더러 (빛/어둠 합성, 그림자, 파티클) |
| `js/audio.js` | 효과음과 배경음 합성 (Web Audio) |
| `js/ui.js` · `js/main.js` | 화면 UI, 메인 루프, 저장 |
| `js/i18n.js` | 한국어 / 영어 문구 |
| `tools/sim.mjs` | 봇이 대신 플레이하는 밸런스 시뮬레이터 |
| `tools/smoke.mjs` | 실제 브라우저에서 한 바퀴 돌려 보는 테스트 |

## 밸런스 조정

수치를 바꾼 뒤 봇에게 수백 판을 시켜 결과를 봅니다.

```bash
npm run sim                                   # 첫째 밤, 봇 종류별 요약
node tools/sim.mjs --night 3 --meta 3 --bot full --policy dark --runs 30
node tools/sim.mjs --trace --seed 7           # 한 판을 15초 단위로 추적
npm test                                      # 최소 조건 + 브라우저 스모크 테스트
```

봇 종류: `afk`(가만히) · `kiter`(도망만) · `camper`(가로등 밑) · `light`(램프를 켠 채로만) · `full`(빛과 어둠을 오감).
현재 수치로 봇이 낸 결과(각 12판, 영구 강화는 밤 번호만큼 올린 상태)는 대략 다음과 같습니다.

| | 승률 |
|---|---|
| 첫째 밤 · 가만히 있기 | 0% (약 39초에 사망) |
| 첫째 밤 · 램프를 켠 채로만 | 약 25% |
| 첫째 밤 · 도망만 다니기 | 약 30~50% |
| 첫째 밤 · 빛과 어둠을 오가기 | 약 70~80% |
| 둘째 밤 → 다섯째 밤 · 빛과 어둠을 오가기 | 약 65% → 50% → 10% → 10~30% |

봇은 사람이 아니고 표본도 작습니다. 최종 난이도는 반드시 실제 플레이테스트로 확인해야 합니다.
특히 "도망만 다녀도 첫째 밤을 절반쯤 넘긴다"는 점과 후반 밤에서 어둠(섬광) 빌드가 빛 빌드보다 강한 점은 더 다듬어야 합니다.

## 출시까지 남은 일

지금 상태는 **핵심 재미를 검증하기 위한 플레이 가능한 버전**입니다. 상용 출시를 위해서는:

1. **플레이테스트** — 처음 하는 사람 10명에게 설명 없이 시켜 보고, 램프 전환을 몇 분 만에 이해하는지 확인.
2. **아트 · 사운드** — 지금은 전부 코드로 그린 임시 그래픽입니다. 캐릭터와 적의 스프라이트, 음악을 교체.
3. **콘텐츠** — 등불지기(캐릭터) 여러 명, 밤마다 다른 지형과 규칙, 업그레이드 추가.
4. **스토어 패키징** — 모바일은 Capacitor, PC(Steam)는 Electron/Tauri 로 감싸면 코드 수정 없이 올라갑니다.
   오프라인 실행을 위한 서비스 워커와 웹폰트 내장이 필요합니다.
5. **서버 기능** — 일일 도전(시드 고정은 이미 지원), 순위표, 클라우드 저장.
