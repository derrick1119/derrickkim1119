# 0006 — 쉬운 원자 늘리기 (오너 피드백 후속)

## 배경
0005에서 도전자 자격을 이해도 0.7 이상으로 세운 뒤 통과한 발견은 27개 중 4개뿐이다.
라운드를 계속 열려면 **머릿속에 바로 그려지는 재료**가 더 필요하다.

## 가설
설명 한 줄로 그림이 그려지는 원자 두 개를 추가하면, 자격을 통과하는 발견이 늘어난다.
- `diag4` 대각선 4칸 (단서): 숫자 = 대각선으로 맞닿은 4칸 중 칠한 칸 수. 지뢰찾기 8칸에서 십자 4칸을 뺀 나머지. 친숙도 0.9.
- `kline1` 줄마다 하나 (전역): 모든 가로줄과 세로줄에 정확히 1칸 (체스 룩 배치·라틴 방진). 친숙도 0.95.
- 자명/불가능 조합은 INCOMPATIBLE에 추가: kline1 × {kline, balanced, rowcol(바깥 숫자가 전부 1), no2x2f(자명),
  nothree(6칸 줄에 1칸만 칠하면 빈칸 3연속 불가피 → 불가능), no2x2e(빈 2×2 불가피 → 불가능), connf(불가능)}.
- 알려진 장르: givens × kline1 = 룩 배치(스타배틀류)로 제외.

## 측정
- 새 원자가 포함된 조합을 `--only`로 우선 시험(이번 사이클 탐색 40개와 별도로 최대 12개).
- 지표: 새 발견 수, 그중 이해도 ≥ 0.7(= A|B 자격) 수.

## 폐기 기준
- 새 원자 조합 12개를 시험해 발견 0개이면, 원자는 남기되(원자 의미 고정 규칙상 삭제 대신 유지) 친숙도 표 재검토를 BACKLOG에.
- 새 원자 때문에 기존 테스트가 깨지면 되돌린다.
