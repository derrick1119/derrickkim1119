# 0003 — 재미 지표 + A|B 루프 + 계기판 아티팩트 (오너 요청)

## 배경
오너 요청(2026-11-05): ① 계기판 아티팩트를 사이클마다 갱신 ② 게임의 고유 재미를 평가해 새 아이디어 시도
③ 새 아이디어(B)와 기존 아이디어(A)를 A|B로 비교해 제안 → 오너가 고르면 그게 새 A가 되고 다음 B를 발굴.

## 가설
fitness(생성 품질)와 별개로, 사람식 풀이 기록에서 "재미의 대리 지표"를 뽑을 수 있다.
- 아하(aha): single이 아닌 단계 비율이 0.3 근처일 때 최고 (너무 적으면 기계적, 너무 많으면 고역)
- 열쇠(cascade): 어려운 한 수 뒤에 연쇄로 풀리는 칸 수 (막힌 문이 열리는 쾌감)
- 맞물림(interplay): 어려운 단계 중 재료 2개 이상을 함께 써야 하는 비율 (= 융합도)
- 고른 재료(balance): 풀이 전체에서 원자 사용의 엔트로피 (장식 재료 없음)
- 머릿속 부담(mental): 가정 추론의 평균 연쇄 깊이가 3을 넘으면 감점
- 간결함(elegance): 원자 수가 적을수록(규칙 설명이 짧을수록) 가산, 단서 밀도 낮을수록 가산
재미 = 가중 기하평균. **가중치는 임시값**이고 오너의 A|B 선택 기록(`fusion/ab/history.json`)으로 나중에 보정한다.

## 측정
- 발견 전체에 대해 6×6 보통·어려움 각 10개 = 퍼즐 20개로 재미 평균·표준오차.
- A = 현재 데일리 규칙(기준선, `fusion/ab/baseline.json`), B = A/B 이력에 없는 발견 중 재미 1위.
- 계기판(`fusion/reports/dashboard.html`)에 A·B를 직접 풀 수 있게 넣어 아티팩트로 게시.

## 폐기 기준
- 재미 지표가 발견들 사이에서 변별력이 없으면(최고-최저 < 0.1) 지표 설계를 되돌린다.
- 계산이 발견 20개 기준 10분을 넘으면 n을 줄이거나 되돌린다.
- 계기판 번들이 아티팩트 한도를 넘거나 교차점 번들(30KB gzip)에 영향을 주면 되돌린다.

## 메모
- 계기판 플레이어 번들에 esbuild(vite의 하위 의존성, 이미 설치됨)를 node API로만 쓴다. 새 의존성 추가 없음.
- 데일리 은행은 이제 기준선(오너가 고른 A)으로 새 날짜를 만든다. 기존 날짜 파일은 그대로.
