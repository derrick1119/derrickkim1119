# 발견 공장 가설 백로그

맨 위부터. 한 사이클에 하나 (탐색은 별도로 매 사이클).

- [ ] **연결성의 누명 벗기기**: conne/connf가 장식 판정을 받는 이유가 원자 자체인지, 사람식 추론기에 연결성 기법(분리점: "이 칸을 칠하면 빈칸이 끊긴다")이 없어서인지 구분. 분석기에서 trial 깊이 0의 전역 모순을 별도 기법으로 집계해 비교.
- [ ] **원자 빈도 분석**: 원장으로 원자별 "발견 기여도"(그 원자가 포함된 조합의 발견 비율)와 원자 쌍 궁합표를 만들어 `fusion/reports/atoms.json`에 쓰고 STATE에 요약. 다음 원자 추가 방향을 데이터로 정한다.
- [ ] **원자 추가 1 — 토러스**: 판의 가장자리가 반대편과 이어지는 변형을 '판 원자'로 추가 (모든 이웃 계산이 감싸짐). 새 원자 id로만.
- [ ] **원자 추가 2 — 영역**: 판을 무작위 영역으로 나누고 "영역마다 정확히 1칸" (스타배틀식). 퍼즐 데이터에 영역 배치 추가 필요 — 엔진 변경 없이 fusion 쪽에서 가능한지 견적부터.
- [ ] **교차점 UI: 재료 설명 카드** — 첫 방문 시 "오늘의 재료" 칩을 누르면 원자의 출처 장르와 한 줄 설명을 보여준다.
- [ ] **교차점 PWA·OG 메타** — 공유 미리보기 카드.
- [ ] **발견의 계보**: 상위 발견끼리 원자 하나씩 교환한 자식 조합을 우선 탐색 큐에 넣는 옵션 (`--breed`).
