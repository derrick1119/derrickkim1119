# 발견: 십자의 물결

`fx-orth4-x-nothree` · 발견일 2026-11-06

## 재료
- **십자 4칸** — 출처: 여러 개수 단서 퍼즐
- **셋 연속 금지** — 출처: 타쿠주·빈에리

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 상하좌우 4칸 중 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 가로나 세로로 같은 상태(칠함/빈칸) 3칸이 연달아 올 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)

| 융합도 | 0.84 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 1 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (십자 4칸 1, 셋 연속 금지 1) |
| 난이도 적중률 | 0.781 | ≥ 0.75 |
| 단서 밀도 | 0.244 | 낮을수록 우아함 |
| fitness | 0.6441 | |
