# 발견: 시선 물결 속 섬

`fx-rook-x-nothree.notouch` · 발견일 2026-11-05

## 재료
- **룩의 시선** — 출처: 체스 룩
- **셋 연속 금지** — 출처: 타쿠주·빈에리
- **맞닿기 금지** — 출처: 히토리·여러 칠하기 퍼즐

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 같은 가로줄과 세로줄 전체(자기 칸 제외)에서 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 가로나 세로로 같은 상태(칠함/빈칸) 3칸이 연달아 올 수 없습니다.
4. 칠한 칸끼리 상하좌우로 맞닿을 수 없습니다.

| 단서 밀도 | 0.097 | 낮을수록 우아함 |
| fitness | 0.9639 | |
