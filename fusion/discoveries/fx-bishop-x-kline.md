# 발견: 사선의 쌍

`fx-bishop-x-kline` · 발견일 2026-11-05

## 재료
- **비숍의 사선** — 출처: 체스 비숍
- **줄마다 둘** — 출처: 스타배틀·N퀸

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 그 칸을 지나는 두 대각선 위에서 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 모든 가로줄과 세로줄에 정확히 2칸씩 칠합니다.

## 왜 발견인가 (n=8×4 난이도)
| 지표 | 값 | 기준 |
|---|---|---|
| 융합도 | 0.766 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 1 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (비숍의 사선 1, 줄마다 둘 1) |
| 난이도 적중률 | 0.844 | ≥ 0.75 |
| 단서 밀도 | 0.181 | 낮을수록 우아함 |
| fitness | 0.7019 | |
