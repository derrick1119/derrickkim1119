# 발견: 시선과 별

`fx-rook-x-kingtouch` · 발견일 2026-11-06

## 재료
- **룩의 시선** — 출처: 체스 룩
- **대각선까지 맞닿기 금지** — 출처: 스타배틀

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 같은 가로줄과 세로줄 전체(자기 칸 제외)에서 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 칠한 칸끼리 대각선을 포함해 어느 방향으로도 맞닿을 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)
| 지표 | 값 | 기준 |
|---|---|---|
| 융합도 | 0.759 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 0.875 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (룩의 시선 1, 대각선까지 맞닿기 금지 0.875) |
| 난이도 적중률 | 0.938 | ≥ 0.75 |
| 단서 밀도 | 0.217 | 낮을수록 우아함 |
| fitness | 0.648 | |
