# 발견: 십자 별과 외길

`fx-orth4-x-kingtouch.kline1` · 발견일 2026-11-05

## 재료
- **십자 4칸** — 출처: 여러 개수 단서 퍼즐
- **대각선까지 맞닿기 금지** — 출처: 스타배틀
- **줄마다 하나** — 출처: 체스 룩 배치·라틴 방진 (0006)

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 상하좌우 4칸 중 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 칠한 칸끼리 대각선을 포함해 어느 방향으로도 맞닿을 수 없습니다.
4. 모든 가로줄과 세로줄에 정확히 1칸씩 칠합니다.
