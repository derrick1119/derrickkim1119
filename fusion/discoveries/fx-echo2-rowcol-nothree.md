# 발견: 메아리 눈금의 물결

`fx-echo2-rowcol-nothree` · 발견일 2026-11-05

## 재료
- **두 칸 너머 고리** — 출처: 발명 공장의 메아리
- **줄 개수** — 출처: 텐트·배틀십 (가장자리 개수)
- **셋 연속 금지** — 출처: 타쿠주·빈에리

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 정확히 두 칸 떨어진 고리(5×5 테두리) 안의 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 판 바깥 숫자 = 그 가로줄/세로줄에 칠한 칸 수.
4. 가로나 세로로 같은 상태(칠함/빈칸) 3칸이 연달아 올 수 없습니다.

| 필수성(최소) | 0.844 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (두 칸 너머 고리 1, 줄 개수 0.844, 셋 연속 금지 1) |
| 난이도 적중률 | 0.969 | ≥ 0.75 |
| 단서 밀도 | 0.259 | 낮을수록 우아함 |
| fitness | 0.6748 | |
