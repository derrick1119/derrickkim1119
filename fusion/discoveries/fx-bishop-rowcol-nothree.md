# 발견: 사선 눈금의 물결

`fx-bishop-rowcol-nothree` · 발견일 2026-11-06

## 재료
- **비숍의 사선** — 출처: 체스 비숍
- **줄 개수** — 출처: 텐트·배틀십 (가장자리 개수)
- **셋 연속 금지** — 출처: 타쿠주·빈에리

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 그 칸을 지나는 두 대각선 위에서 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 판 바깥 숫자 = 그 가로줄/세로줄에 칠한 칸 수.
4. 가로나 세로로 같은 상태(칠함/빈칸) 3칸이 연달아 올 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)
| 지표 | 값 | 기준 |
|---|---|---|
| 융합도 | 0.845 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 0.969 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (비숍의 사선 1, 줄 개수 0.969, 셋 연속 금지 1) |
| 난이도 적중률 | 1 | ≥ 0.75 |
| 단서 밀도 | 0.221 | 낮을수록 우아함 |
| fitness | 0.8272 | |
