# 발견: 도약 눈금을 건넌 별

`fx-knight-rowcol-kingtouch` · 발견일 2026-11-05

## 재료
- **나이트 도약** — 출처: 체스 나이트
- **줄 개수** — 출처: 텐트·배틀십 (가장자리 개수)
- **대각선까지 맞닿기 금지** — 출처: 스타배틀

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 체스 나이트가 한 번에 뛰어갈 수 있는 칸(최대 8칸) 중 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 판 바깥 숫자 = 그 가로줄/세로줄에 칠한 칸 수.
4. 칠한 칸끼리 대각선을 포함해 어느 방향으로도 맞닿을 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)
| 지표 | 값 | 기준 |
|---|---|---|
| 융합도 | 0.871 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 0.938 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (나이트 도약 1, 줄 개수 0.938, 대각선까지 맞닿기 금지 1) |
| 난이도 적중률 | 1 | ≥ 0.75 |
| 단서 밀도 | 0.251 | 낮을수록 우아함 |
| fitness | 0.7882 | |
