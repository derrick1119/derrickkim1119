# 발견: 가로와 물결

`fx-rowline-x-nothree` · 발견일 2026-11-05

## 재료
- **같은 가로줄** — 출처: 룩의 시선 절반 (0007)
- **셋 연속 금지** — 출처: 타쿠주·빈에리

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 같은 가로줄에서 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 가로나 세로로 같은 상태(칠함/빈칸) 3칸이 연달아 올 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)
| 지표 | 값 | 기준 |
|---|---|---|
| 융합도 | 1 | ≥ 0.35 — 어려운 단계 중 두 재료를 함께 써야 풀린 비율 |
| 필수성(최소) | 1 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (같은 가로줄 1, 셋 연속 금지 1) |
| 난이도 적중률 | 0.75 | ≥ 0.75 |
| 단서 밀도 | 0.257 | 낮을수록 우아함 |
| fitness | 0.697 | |
