# 발견: 모서리 쌍의 섬

`fx-diag4-x-kline.notouch` · 발견일 2026-11-06

## 재료
- **대각선 4칸** — 출처: 지뢰찾기의 모서리 이웃 (0006)
- **줄마다 둘** — 출처: 스타배틀·N퀸
- **맞닿기 금지** — 출처: 히토리·여러 칠하기 퍼즐

## 규칙
1. 몇몇 칸을 칠해서 아래 규칙을 모두 만족시키세요. 정답은 하나뿐입니다.
2. 숫자 = 대각선으로 맞닿은 4칸 중 칠한 칸 수. 숫자 칸은 칠하지 않습니다.
3. 모든 가로줄과 세로줄에 정확히 2칸씩 칠합니다.
4. 칠한 칸끼리 상하좌우로 맞닿을 수 없습니다.

## 왜 발견인가 (n=8×4 난이도)

| 필수성(최소) | 0.969 | ≥ 0.7 — 재료 하나를 빼면 정답이 여러 개가 되는 비율 (대각선 4칸 1, 줄마다 둘 1, 맞닿기 금지 0.969) |
| 난이도 적중률 | 0.938 | ≥ 0.75 |
| 단서 밀도 | 0.134 | 낮을수록 우아함 |
| fitness | 0.9775 | |
