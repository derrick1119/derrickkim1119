## 0006 — 2026-11-05 · 재미 지표 + A|B 1라운드 (오너 요청)
- **시도**: 풀이 기록 기반 재미 지표(긴장·퍼짐·아하) 추가, 새 규칙 '나이트 메아리' 추가, `npm run abtest`로 챔피언 echo vs 도전자 후보 평가, 계기판을 저장소에서 자동 생성(`npm run dashboard`)하고 A|B 투표 버튼 추가. 프로토콜에 A|B 루프·계기판 갱신 단계 추가.
- **결과**: B = 마름모 메아리(fam-d3-manh-notouch) 재미 0.637±0.005 vs A echo 0.579±0.010 (+10%), fitness 0.483 vs 0.440. 나이트 메아리 재미 0.638이나 어려움 적중 0.887로 자격 미달. 테스트 20개 통과, 번들 gzip 8.53KB.
- **배운 것**: echo는 긴장(막힘)이 높고 퍼짐·아하가 낮다. 긴장이 재미인지 답답함인지는 오너 선택이 알려줄 것.
- **다음**: 오너 A|B 선택 대기. 그동안 나이트 메아리 적중률 보정(다음 도전자).

## 0005 — 2026-11-05 · 상위 4개 n=20 재검증
- **시도**: evaluate에 시드 집합(seedBase) 추가, `npm run reverify`로 상위 4개 + echo를 n=20 × 시드 집합 4개로 재평가.
- **결과**: 순위 뒤집힘. 1위 fam-d1-cheb-notouch 0.4832±0.0040, 2위 fam-d3-manh-notouch 0.4829±0.0012, 기존 1위 fam-d3-cheb-no2x2는 0.4613으로 4위. echo 0.4399±0.0182. 재현성 확인(0.4883).
- **배운 것**: n=6 단일 시드 순위는 운. 0.01 이하 차이는 노이즈. 오리지널 후보 1순위는 fam-d3-manh-notouch(d1-cheb-notouch는 지뢰찾기 변형류라 보류).
- **다음**: explore를 다중 시드 기본으로 → 판 크기 민감도.

## 0004 — 2026-11-04 · 인지 부하 지표
- **시도**: evaluate에 scanLoad(단서당 세야 할 칸)·ringClip(고리의 판 밖 비율)·overlap 추가, fitness = v1 × sqrt(min(1, 8/scanLoad)). 패밀리 재탐색.
- **결과**: 지표 채택, 가설 부분 기각. echo v1 재현(0.5166). d3-cheb-no2x2 여전히 1위(0.4883)지만 echo 대비 격차 0.058→0.025, 2~4위와는 0.001 차(노이즈). echo는 0.4632로 7위.
- **배운 것**: d=3 체비셰프는 고리 절반 이상이 판 밖이라 실제 세는 칸은 11칸뿐. 진짜 위험은 판 크기 의존성. 마름모+맞닿기금지가 새 상위 후보로 부상.
- **다음**: 상위 4개 n=20 재검증 → 판 크기 민감도.

## 0003 — 2026-11-04 · 플레이테스트 모드
- **시도**: `?play=<규칙id>&seed=<n>&tier=<난이도>[&size=n]`로 등록된 아무 규칙이나 브라우저에서 즉석 생성해 플레이. e2e에 결정성·승리 케이스 추가.
- **결과**: 가설 채택. e2e 3케이스(라이트/다크/플레이테스트) 통과, 번들 gzip 8.27KB(+2.3KB), 브라우저 생성 hard 최대 874ms(echo), d3 후보는 ≤200ms.
- **배운 것**: 위반 표시를 모델 제약 기반으로 일반화하니 규칙별 UI 코드가 필요 없어짐. d=3 6×6은 화면으로 봐도 테두리가 판을 거의 덮음 — 인지 부하 지표가 필요.
- **다음**: 인지 부하 지표(BACKLOG 최상단).

## 0002 — 2026-11-04 · 규칙 계보 탐색기
- **시도**: echo를 (고리 거리 d × 거리 척도 × 전역 규칙) 18개 조합 패밀리로 일반화하고 fitness 순위표 작성 (`npm run explore`).
- **결과**: 가설 채택. 1위 `fam-d3-cheb-no2x2` 0.575 > echo 0.517. echo와 동일한 조합이 동일 점수 → 계기판 재현성 확인. 테스트 18개 통과.
- **배운 것**: 마름모 고리는 정보 부족으로 열세. 맞닿기 금지는 생성만 느리게 함. 단, d=3 우세는 '사람이 24칸을 세는 부담'을 지표가 못 보는 맹점일 수 있음.
- **다음**: 플레이테스트 모드(오너가 후보 규칙을 직접 만져볼 수 있게) → 인지 부하 지표.
