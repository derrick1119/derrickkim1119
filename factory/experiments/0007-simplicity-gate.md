# 0007 — 단순함 게이트 (오너 피드백: "너무 복잡하다 — 규칙 이해가 어려움")

## 배경
오너가 1라운드 A(메아리)·B(마름모 메아리)를 보고 "규칙 이해가 어렵다"고 답했다. 이것이 재미의 첫 실제 측정값이다.
원인 진단: 숫자가 세는 칸이 **숫자 칸에서 떨어진 추상 도형**(거리 2 정사각 테두리, 거리 3 마름모)이라 머릿속에 그려야 한다.
재미 지표(긴장·퍼짐·아하)는 이해 비용을 전혀 보지 않았다 → 지표의 맹점.

## 가설
세는 칸을 "보이는 개념"으로 제한해도 품질(자격)과 재미를 유지하는 규칙이 있다:
- **접촉형**: 숫자 칸에 닿은 칸 (대각선 4칸 / 상하좌우 4칸 / 8칸)
- **직선형**: 숫자 칸에서 뻗는 줄 (같은 가로·세로줄 = 십자 / 두 대각선 = X자)
새 후보 (규칙 = 숫자 문장 1개 + 전역 규칙 0~1개):
- `fam-d1-diag-*` 대각선 메아리: "숫자 = 대각선으로 닿은 칸 중 칠한 수"
- `fam-d1-cross-*` 십자 시선: "숫자 = 같은 가로줄·세로줄의 칠한 수"
- `fam-d1-xline-*` X자 시선: "숫자 = 두 대각선 줄 위의 칠한 수"
전역 규칙 none / notouch / no2x2. 알려진 장르(8칸+없음 = 지뢰찾기)는 제외.

## 측정
- `npm run abtest` (n=10 × 2, 유망하면 n=20 × 4): 자격(적중 ≥ 0.9·단조·생성 ≤ 2s) + 재미.
- **단순함 게이트**를 abtest 자격에 추가: 세는 칸의 종류가 접촉형·직선형이어야 하고, 전역 규칙 ≤ 1.
- B = 게이트·자격 통과자 중 재미 최고. echo는 게이트 미달이지만 현재 제품이므로 A로 남는다.

## 폐기 기준
- 게이트 통과 + 자격 통과 후보가 0개 → 게이트를 '접촉형 + 직선형 + 거리 2까지'로 완화하는 대안을 기록만 하고, 1라운드 무효 처리만 커밋.

## 결과 → **가설 채택. A|B 1라운드 무효, 2라운드 B = 사선 세기(fam-d1-xline-none)**
n=10 × 2 탐색 (게이트 통과 후보 9개):
| 규칙 | 재미 | fitness | 최저 적중 | 판정 |
|---|---|---|---|---|
| diag (대각선 4칸) ×3 | 0.35–0.47 | 0.10–0.21 | 0.0–0.1 | 미달 — 정보가 너무 적어 어려운 퍼즐을 못 만듦 |
| cross (십자 줄) ×3 | 0.58–0.61 | 0.39 | 0.55–0.70 | 미달 — 어려움 적중 부족 |
| xline-notouch | 0.663 | 0.485 | 0.80 | 미달 (근소) |
| **xline-none** | 0.613 | 0.489 | 0.95 | 자격 |
| **xline-no2x2** | 0.651 | 0.489 | 1.00 | 자격 |

n=20 × 4 결승: xline-no2x2 재미 0.633±0.011 · fitness 0.4945±0.0078 vs xline-none 0.612±0.013 · 0.4858±0.0024
→ 재미·fitness 모두 2×sd 안 동률 → **규칙 문장이 적은 xline-none을 B로** (규칙 2문장: "숫자 칸은 칠하지 않는다" + 숫자 문장).
- 사선 세기는 echo보다 재미 +0.033, fitness +0.046, 세는 칸 10.4 → 7.8, **퍼짐 0.63 → 0.87**(대각선이 판 끝까지 뻗어 먼 곳끼리 연결).
- 원본성 주의: 발견 공장(fusion)이 같은 셈법을 '비숍의 사선'이라는 기존 조각으로 쓰고 있다. 단독 규칙으로 알려진 장르는 아니지만 '발명'보다는 '단순한 좋은 규칙'으로 보고한다.

## 배운 것
- 재미 지표는 이해 비용을 못 본다. 오너 피드백 하나가 탐색 방향 전체를 바꿨다 → 게이트로 박제.
- 접촉형(대각선 4칸)은 단순하지만 정보량이 너무 적다. 직선형이 '단순함 + 정보량'의 균형점.
- 나이트·마름모 계열은 게이트로 전부 탈락 — 0006의 나이트 보정 항목은 폐기.
