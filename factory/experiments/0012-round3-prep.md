# 0012 — 3라운드 후보(사선 세기 + 맞닿기 금지) 미리 다지기

## 가설
fam-d1-xline-notouch는 수치(0008: 재미 0.658±0.010, fitness 0.503, 자격 ✓)는 갖췄다. 판정 직후 바로 3라운드를 열려면
제품 품질도 확인돼야 한다: **실제 브라우저에서 힌트 버튼만 따라가도 끝까지 풀리고**, 모든 힌트 문구가 이 규칙에 맞는다
(메아리 전용 단어 '고리'·'테두리'가 나오지 않음, 맞닿기 힌트는 맞닿기 설명).

## 측정
- e2e에 케이스 추가: xline-notouch 어려움 seed 1을 열고 힌트 → 반짝이는 칸을 정답대로 표시 → 반복, 승리 화면까지.
  힌트 횟수, 기법별 문구 종류, 금지 단어 0개, 콘솔 에러 0. 스크린샷 play-hint-*.png 직접 확인.

## 폐기 기준
- 힌트만으로 못 끝내거나(막힘/무한 반복) 금지 단어가 나오면: 코드 변경은 되돌리지 않고 *원인*을 BACKLOG 최상단에 올리며,
  3라운드 후보 자격을 '보류'로 기록.

## 결과 → **채택 (3라운드 후보 준비 완료)**
- e2e hint-solve: xline-notouch 어려움 seed 1을 **힌트 21번만으로 승리**, 문구 7종, 콘솔 에러 0.
- 새 e2e가 **제품 문구 버그 2개**를 잡아 고쳤다:
  1. "테두리 표시된 숫자 N의 …" — 화면 강조를 뜻했지만 메아리 규칙의 '테두리'와 같은 말이라 혼동 → "숫자 N의 …"로.
  2. "세는 칸를 함께 보세요" — 받침 뒤 조사 오류 → '을'.
  e2e가 두 패턴(고리·테두리·칸를)을 앞으로도 막는다.
- 스크린샷 확인에서 UX 문제 발견: 힌트 대상 칸과 근거 칸의 강조가 거의 같아 구분이 어렵고, 같은 숫자가 여럿이면 "숫자 1과 2"가 어느 것인지 모호 → BACKLOG.
