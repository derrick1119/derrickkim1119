# 0011 — A|B 장기 대기 대비

## 가설
오너는 가끔만 본다. 라운드가 오래 열려 있으면 (a) 계기판에 '열린 지 N시간'이 보이고 (b) 24시간이 지나면 STATE '오너에게' 맨 위에
**딱 한 번** 리마인드가 붙는 편이, 매 사이클 같은 말을 반복하거나 아무 말도 안 하는 것보다 낫다. 기계 지표는 없다 — 동작의 정확성만 측정.

## 측정
- `scripts/lib/ab.ts`의 순수 함수 `roundAgeHours`, `needsReminder`를 테스트: 23h → 리마인드 없음, 25h → 있음, 이미 remindedAt 있으면 없음, 판정 끝난 라운드는 없음.
- `npm run ab:status`: 필요 시 rounds.json에 remindedAt 기록 + STATE '오너에게' 맨 위에 한 줄. 두 번 실행해도 한 줄만(멱등).
- rounds.json에 열린 시각(UTC) `openedAt` 추가. 2라운드 = 계기판 게시 시각 2026-11-05T04:47Z.

## 폐기 기준
- 멱등성 테스트 실패 또는 계기판 390px 레이아웃이 깨지면 되돌린다.

## 결과 → **채택**
- 테스트 2개 추가(총 56개 통과): 23h 없음 · 25h 있음 · 이미 알림/판정 끝/열린 시각 없음 → 없음 · STATE 줄 삽입 멱등.
- 지금 2라운드는 19.6시간 → 리마인드 없음(정상). 계기판 A|B 설명에 "열린 지 19시간." 표시.
- 프로토콜 3½단계에 `npm run ab:status` 추가.
