# 0006 — 재미 지표 + 나이트 메아리 + A|B 1라운드 (오너 요청)

## 배경
오너 요청: (1) 계기판을 매 사이클 갱신, (2) 게임 고유의 재미를 평가해 새 아이디어 시도,
(3) 기존(A) vs 새 아이디어(B)를 A|B로 제안 → 오너가 고르면 그게 새 기존(챔피언)이 되고 다시 도전자를 발굴.

## 가설
H1. 풀이 기록만으로 "재미"의 대리 지표를 만들 수 있다: 
- **긴장 T** = 풀이 단계 중 그 시점에 확정 가능한 칸이 2개 이하인 단계의 비율 (막혔다가 뚫리는 맛. 할 일이 사방에 널린 '청소' 풀이는 지루함)
- **퍼짐 S** = 연속 단계 사이 거리(맨해튼, 칸 중심) ÷ 무작위 기대값(2n/3), 상한 1 (판 전체를 오가며 보는가)
- **아하 A** = pair/trial 추론 한 번이 뒤이어 single로 풀어주는 칸 수 평균 ÷ (판 칸 수 × 0.15), 상한 1 (돌파의 보상 크기)
- **fun = (T + S + A) / 3**, 보통·어려움·지옥 평균 (쉬움은 보고만).
H2. 새 규칙 **나이트 메아리**(숫자 = 나이트 이동으로 닿는 8칸 중 칠한 칸 수)는 세는 칸이 8칸 이하라 부하가 낮고,
  고리가 서로 성기게 얽혀 퍼짐 S가 echo보다 높을 것이다. 전역 규칙 none/notouch/no2x2 중 가장 나은 것을 B로 고른다.

## 측정
- `npm run abtest` → `factory/reports/ab.json`: 후보별 fitness(n=10×2 시드 집합)와 fun(T,S,A).
- 후보: echo(A), fam-d1-knight-{none,notouch,no2x2}, 참고로 fam-d3-manh-notouch.
- B 자격: 전 난이도 적중률 ≥ 0.9, 단조, hard 생성 ≤ 2s. 자격자 중 fun 최고를 B로.

## 폐기 기준
- 나이트 3종 모두 B 자격 미달 → 나이트 폐기, 자격 있는 다른 후보(fam-d3-manh-notouch)를 B로.
- fun 지표가 난이도와 무관하게 모든 규칙에서 같은 값(±0.02)이면 변별력 없음 → 지표 폐기 기록.

## 결과 → **H1 채택, H2 부분 채택(나이트는 근소 미달), A|B 1라운드 개시**
n=20 × 시드 집합 4개 (보통·어려움·지옥 평균):

| 규칙 | 재미 | 긴장 | 퍼짐 | 아하 | fitness | 최저 적중 | 자격 |
|---|---|---|---|---|---|---|---|
| fam-d1-knight-notouch (나이트 메아리) | 0.638 ± 0.015 | 0.42 | 0.76 | 0.73 | 0.411 | 0.887 | ✗ (어려움 적중 0.887) |
| **fam-d3-manh-notouch (마름모 메아리) = B** | **0.637 ± 0.005** | 0.54 | 0.76 | 0.60 | **0.483** | 0.90 | ✓ |
| echo (메아리) = A | 0.579 ± 0.010 | 0.67 | 0.63 | 0.44 | 0.440 | 0.81 | (챔피언) |
| fam-d1-knight-none / no2x2 (n=10×2) | 0.571 / 0.593 | | | | 0.32 | 0.70 | ✗ |

- 변별력 있음: 규칙 간 재미 범위 0.57–0.65 (폐기 기준 ±0.02 초과).
- B는 A보다 **퍼짐 +0.13, 아하 +0.16**, 긴장은 −0.13. 즉 echo는 '자주 막히지만 뚫어도 보상이 작은' 풀이, B는 '판 전체를 오가며 큰 연쇄가 터지는' 풀이로 측정됨.
- 나이트 메아리는 재미 공동 1위지만 어려움 적중률이 0.887로 자격선 0.9 바로 아래 → 다음 도전자 후보로 BACKLOG.
- 계기판: A|B 나란히 플레이(퍼즐 3개 × 보통/어려움) + 오너 투표 버튼(아티팩트 DB `ab/round-1`, 오너만 쓰기).

## 배운 것
- 긴장(막힘 비율)은 echo가 가장 높다. 긴장이 '재미'인지 '답답함'인지는 기계가 모른다 — 오너 선택으로 이 축의 부호를 배울 수 있다.
- 쉬움 난이도는 아하가 구조적으로 0이라 재미 평균에서 뺀 것이 맞았다.
