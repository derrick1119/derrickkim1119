# 0009 — 평가 예산 통일 (explore·reverify attempts 20 → 40)

## 가설
0008에서 attempts 20이 어려움 적중률을 과소평가함을 확인했다. explore·reverify도 제품 기준(40)으로 바꾸면
(a) 0004·0005 순위에서 적중률 때문에 눌렸던 규칙(특히 notouch 계열: 생성이 까다로움)이 올라오고
(b) 0005의 결론(1·2위 = d1-cheb-notouch, d3-manh-notouch)은 순서는 바뀌어도 상위 2개 구성은 유지된다.

## 측정
- `npm run explore -- --n 6` (attempts 40) → family.json, 0004 표와 비교 (순위 이동).
- `npm run reverify` (n=20 × 4, attempts 40) 0005와 같은 5개 → top.json, 0005와 비교.
- 참고: 단순함 게이트(0007) 이후 이 패밀리 대부분은 도전자 자격이 없다. 이 실험의 가치는 '과거 결론의 정정'이다.

## 폐기 기준
- explore + reverify 합계 10분 초과 → 예산 변경 되돌리고 n을 줄이는 대안 기록.

## 결과 (explore 41s + reverify 215s = 4.3분) → **가설 (a)(b) 모두 채택**
explore n=6: 적중률 1.00이던 규칙은 값이 그대로, 미달이던 규칙만 상승. echo 0.4632 → 0.4789 (9위 → 5위), fam-d1-cheb-no2x2 0.393 → 0.452, fam-d2-manh-no2x2 0.315 → 0.401. 1~4위 불변.

reverify n=20 × 4 (0005 → 0009):
| 규칙 | 0005 (attempts 20) | 0009 (attempts 40) |
|---|---|---|
| fam-d3-manh-notouch | 0.4829 ± 0.0012 (2위) | **0.4910 ± 0.0077 (1위)** |
| fam-d1-cheb-notouch | 0.4832 ± 0.0040 (1위) | 0.4832 ± 0.0040 (2위, 불변) |
| fam-d2-manh-notouch | 0.4758 ± 0.0052 | 0.4816 ± 0.0059 |
| fam-d3-cheb-no2x2 | 0.4613 ± 0.0084 | 0.4695 ± 0.0067 |
| echo | 0.4399 ± 0.0182 | **0.4556 ± 0.0081** (sd 절반) |

- 상위 2개 구성 유지, 순서만 바뀜. echo의 큰 sd(0.018)는 대부분 예산 부족으로 인한 적중률 흔들림이었다.
- 이 패밀리는 0007 단순함 게이트로 대부분 도전자 자격이 없으므로, 의미는 '과거 기록 정정'과 'echo 실력 재평가'.
