# 34라운드 아이디어 초안 (0093 — 33라운드 판정 전, 만들지 않음)

33라운드 판정이 오면 그에 맞춰 고르고 고친다. 판정 전엔 코드를 만들지 않는다(PROTOCOL: 라운드가 열려 있는 동안 새 게임 금지).

## 지킬 것 (지금까지의 오너 답)
- 실시간 액션 · 첫 1초에 세상이 크게 바뀜 · 밝은 낮 · 직접 그린 캐릭터(31·32·33라운드 답).
- **6개 뼈대가 서로 달라야** 한다(32라운드 "뼈대가 다 비슷함"). 디펜스(기지 지키기) 금지.
- **고른 결을 라운드 전체에 씌우지 않는다**(19→20 · 21→22 · 23→24 세 번 다 폐기). 오너 취향 신호 '그은 길 → 한 번에 크게'(닌자 M1, 0091)는 **6개 중 최대 2개**에만.
- 계기판 새 지표를 처음부터 맞춘다: 손 안 대기 손실 0 · 버릇 ★3 < 50% · 첫 '와' 1초 안팎 · **판마다 손이 하는 일이 바뀜(0092, 변화 ≥ 0.1)** · **2판부터도 큰 순간이 이어짐(≥ 20%)**.

## 고를 때 볼 것
- 33라운드에서 고른 뼈대가 있으면 그 뼈대는 **하나만** 남기고(같은 결 금지), 나머지는 다른 뼈대로.
- 33라운드가 다 폐기면 이유를 먼저 묻는다(32·33 연속이면 방향 질문).
- '그은 길' 결(A·B)은 둘 중 많아야 둘.
- 자가 검사(브리프 기준 19): 디펜스가 아니고, '이걸 빼면 무슨 기존 게임인가'를 각자 적는다. 닮은 게임: A는 선 긋기 러너, C는 소방 하이퍼캐주얼(31라운드 물대포와 닮음 — 고를 때 주의), D는 그네 타기, G는 풍선 비행(뻔함 주의).
