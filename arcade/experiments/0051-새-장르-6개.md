# 0051 — 24라운드: 새 장르 6개 (공장은 계속 돈다)

## 오너 답
- 23라운드: "1,2,4 아이디어 좋네 따로 세션으로 보내서 개발을 진행하자"
  - 양치기 멍멍 · 풍선 팡 연쇄 · 욕조 물결 오리를 스튜디오로 졸업시켰다(게임마다 팀 세션).
- 그 뒤 오너: "발견 공장 운영자! 너는 공장을 계속 돌려야지. 새로운 장르로 시도해봐"
  - PROTOCOL에 '공장은 멈추지 않는다'를 넣었다.

## 가설
- 23라운드에 고른 셋의 공통점은 **한 수의 결과가 손을 떼기 전에 보인다**는 것이다(누르는 동안 미리 보기 / 반경 원).
- 이 결을 지키면서 장르를 바꾸면, 다시 '고를 게임'이 나온다.
- 버린 셋의 결은 피한다: 타이밍, 계속 흘러오는 처리, 순서 퍼즐.

## 방법
- 새 재료 `reflect`(빛 반사)를 넣었다.
- 브리프 v5(`BRIEF24`)를 썼다.
  - 고른 셋(sheepdog·duckbath·balloonpop)을 참고 구현으로 지정했다.
  - '누르는 동안 미리 보기 → 떼면 실행'을 권했다.
  - 1판은 무작위로 해도 ≥ 90%, 2판은 ≥ 50% 넘어가야 한다.
- 에이전트 6명이 동시에 만들었다.
- 통합할 때 눈덩이 굴리기 id가 옛 폐기 후보 '눈덩이 비탈'(`snowball`)과 겹쳐 `snowroll`로 바꿨다. 폐기한 게임은 다시 보이지 않는다는 테스트가 잡아냈다.

## 측정 지표 · 폐기 기준
- 게이트: 숙련 격차 ≥ 3 · 못하는 봇 ≥ 5초 · 잘하는 봇 중앙값 30초~3분 · 규칙 ≤ 3줄 · 펼쳐짐(잘함 2분) ≥ 4.
- 무작위로 1판 ≥ 90%, 2판 ≥ 50% 넘어가야 한다.

- **와우 한 줄씩**:
  - UFO: 원 안의 것이 몽땅 올라간다 — 농부까지.
  - 청소기: 한 번 밀면 벽까지 쭉, 위의 고양이는 근엄.
  - 눈덩이: 지나간 눈만큼 커지고 작은 건 말아 버림.
  - 베개: 놓기만 하면 싸움은 저절로, 마지막엔 아빠.
  - 거울: 빛길이 늘 보이고 지나간 꽃이 퐁퐁.
  - 기찻길: 갈 길 점선과 💥 쾅 미리 보기.
- **선택이 점수를 가르는가**:
  - UFO: 내다보는 봇 3492, 바로 쏘는 봇 3091, 아무 소나 쏘는 봇 1994.
  - 청소기·눈덩이·거울·베개: 잘하는 봇은 모든 판 ★3, 무작위는 3~5판에서 끝난다.
  - 기찻길: 무작위는 판당 별 1.1개, 잘하는 봇은 2.5~3개.
- **실제 계기판(390px, 터치 흉내)**: 6개 모두 입력에 반응했다(청소기는 키보드 ←→와 밀기 둘 다). 가로 스크롤 없음, 콘솔 에러 0.
- `npm run verify` 통과(테스트 113개, 스튜디오 테스트 포함).

## 남은 약점 (에이전트 보고)
- **사람 한 판 길이**: 생각하는 시간을 넣으면 눈덩이·베개·청소기는 2.5~4분으로 추정된다. 기찻길은 실시간이라 약 2.6분이다.
- **베개 싸움**: 별 값을 판마다 같게 매기면 격차가 약 3.1×다. 판이 갈수록 별 값을 키운 덕을 본다. 7·8판은 무작위로 이길 확률이 8%라 미리 보기를 써야 한다.
- **햇빛 거울**: 재미 0.899, 격차 4.07×로 이번 라운드에서 가장 낮다.
- **눈덩이**: 3판(얼음)에서 무작위 통과율이 3%로 뚝 떨어진다.
- **기찻길**: 브리프와 달리, 잘못 내리면 하트를 바로 잃지 않고 '세 번 화나면 하트 −1'이다. 신호등은 3판부터, 급행은 앞 기차 뒤에서 멈춘다.

## 판정
6개 모두 게이트를 통과해 24라운드로 오너에게 보인다. 기계 추천은 재미 최고인 **기찻길 전환**(0.989)이다.
