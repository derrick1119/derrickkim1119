# 0119 — 39라운드: 38의 셋을 이어 다듬기 (오너: "1,2,3번 다 디벨롭 — 1번 힌트, 2·3번 기획")

## 가설
38라운드 오너 판정은 처음으로 '버린 것 0'이었다. 오너 말을 그대로 — 1번은 막히지 않게(힌트), 2·3번은 '기획'(되물어 오너가 넷씩 모두 고름) —
옮기면 다음 판정에서 졸업(스튜디오)이 나온다. 공장이 본 공통 약점: 판 대부분이 '새 장치 하나 + 정답 한 수'이고 시작 안내가 답을 말함.

## 측정
- 게이트(그대로): 격차 ≥ 3 · 버릇 ★3 < 50% · 정밀 ≥ 0.7 · 처음 10초 안전 · 소리 · 콘솔 에러 0 · 390px.
- 새로: 판마다 손댈 것 ≥ 3·그럴듯한 오답(에이전트 판 설계 표), 힌트는 막혔을 때만(지금 상태에서 다음 한 수 한 줄), CPU 4배 게임 코드(기준 27).
- 진짜 측정은 오너 판정(졸업 / 더 다듬기 / 폐기).

## 폐기 기준
- 게이트 미달 게임은 올리지 않는다. 오너가 셋 다 폐기하면 '이어 다듬기'도 끝 — 40라운드 아이디어 메뉴(`arcade/menus/round40-*`)로.

- 되감기: 판마다 손댈 것 ≥ 3(미끼·끝까지 되감으면 다시 벌어짐·너무 일찍), '곧 벌어질 일' 2초 필름 → VHS 되감기, 연쇄 되감기(친 물건이 같이 돌아옴), 복원 = 능력(1장 풍차 바람 1.5배 · 2장 물레방아 두 바퀴 = 둘 함께), 3장 승강기·망보는 도깨비, 큰 글자 한 번에 하나, 장 끝 화면 미리 그려 둠(중앙 45.7 → 7.5ms).
- 크기: 1장 앞 3판만 1수, 2장부터 첫 수 정답 비율 ≤ 1/3 + 잡히는 함정, 동물 특기 = 규칙(코끼리 물 마시기·기린 열쇠·하마 물벼락·판다 볼링·거북 등껍질·사자 어흥·돼지 굴 파기·토끼 폴짝…), 연쇄 ×2 ×3, 엄마 찾기 이야기·장 시작 그림책 컷·가족 사진첩(10/10).
