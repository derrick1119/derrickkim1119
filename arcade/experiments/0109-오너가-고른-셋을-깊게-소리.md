# 0109 — 38라운드: 오너가 고른 아이디어 셋을 깊게 + 진짜 소리

## 오너 답 (37라운드)
- "전체 폐기" — 35·36·37 세 라운드 연속. 이유(오너가 고름): **뻔하거나 이미 있음 · 손맛·첫인상이 약함 · 더 하고 싶지 않음**. 다음 방식: **2~3개만 깊게**.
- 아이디어 넷(무게 훔치기 · 소리로 깨기 · 한 물건만 되감기 · 크기 바꾸기)을 먼저 보여 드렸고 오너가 **무게 훔치기 · 한 물건만 되감기 · 크기 바꾸기**를 골랐다.

## 가설
- 넓게 6개를 빨리 만드는 방식은 매번 '이미 있는 뼈대 + 껍데기'가 됐다(에이전트 스스로 매 라운드 그렇게 적음). 오너가 고른 **처음 보는 규칙** 셋만, 시간을 두 배 쓰고 두 번 다듬어 만들면 오너가 고른다.
- 공장 게임은 지금까지 **소리가 없었다**. 손맛 불만(32·35·37)의 큰 몫일 수 있다 → 공용 효과음(`arcade/sfx.ts`, WebAudio 합성 16가지, 의존성 없음)을 넣고 모든 사건에 소리를 붙인다.
- '더 하고 싶지 않음' → 판 사이 성장(모으기·풀리기·다음 목표가 보임)을 처음부터 설계한다.

## 방법
- `arcade/sfx.ts` + `juice(s).sound(name)` + `play.ts`(첫 누름에 깨움, 아래에 '🔊 소리 켜짐/꺼짐' 단추, 기억). 시뮬레이션은 소리를 모른다(봇 측정·테스트 그대로).
- 에이전트 셋, 브리프 v19(`arcade/kit/BRIEF.md` 갱신): 1차 완성 → 공장이 스크린샷 보고 되돌림 → 2차 다듬기.

## 측정 지표 · 폐기 기준
- 게이트 그대로 + 손가락 오차 ≥ 0.7 + 첫 '와' ≤ 1초 + 모든 사건에 소리 + 판 사이 성장(풀리는 것 ≥ 3가지, 판 ≥ 12).
- **폐기 기준**: 게이트를 못 넘으면 오너에게 안 보인다. 셋 다 폐기면 '적게 깊게 + 오너가 고른 아이디어'도 안 통한 것 — 오너 아이디어를 직접 받는 방식으로 바꾸자고 묻는다.

- **두 번 다듬기**: 1차 스크린샷에서 셋 모두 '놀이가 화면 가운데 얇은 띠, 인물이 작음' → 2차에 카메라 1.4배(놀이 영역 화면 높이 70~80%), 판 12~15 → 17~18, 장 끝 보상 장면(보물 창고 쌓임 · 마을 되살아남 + 시계 바늘 · 도감 폴라로이드 찰칵), 무게 훔치기는 막히면 ↺ 다시(하트 그대로), 되감기는 지나온 길 잔상·시계 표시, 크기 바꾸기는 바뀌는 순간 느려짐·출렁·주변 들썩.
- **소리**: 셋 모두 모든 사건에 `juice(s).sound`(에이전트 보고에 사건별 표). 헤드리스라 귀로는 못 들음 — 실제 계기판에서 소리 단추·콘솔 에러 0 확인.
- **실제 계기판**(390px): 손 안 대고 9초 → 셋 모두 손가락 시범, 긋기 3번 + 톡 5번 → 셋 모두 반응(열쇠 훔침·부품 찾음·탈출 성공), 가로 스크롤 없음, 콘솔 에러 0.
- 닮은 게임(에이전트가 솔직히): 무게 훔치기 — 물리 퍼즐·성질 바꾸기 퍼즐·저울 퍼즐(다름: 무게는 사라지지 않고 옮겨 갈 뿐, 공중에서 다시 무겁게 하면 그 높이에서 쿵). 되감기 — 시간 되감기 퍼즐(다름: 세상 전체가 아니라 한 물건만, 그 엇갈림이 전부). 크기 바꾸기 — 크기 조절 퍼즐·저절로 걷는 무리 퍼즐(다름: 크기는 교환만 — 맡겼다 돌려받기, 장애물·사람·도구도 바꿈).
