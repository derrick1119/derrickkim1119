# 0112 — 소리가 실제 브라우저에서 정말 나나 (38라운드 판정 대기 중)

## 가설
0109에서 공용 효과음을 넣었지만 확인은 '콘솔 에러 0'까지였다. 오너가 38라운드를 해 볼 때 소리가 안 나면
'소리가 손맛을 바꾸나'(BACKLOG) 판정이 의미가 없다. 실제 브라우저(390px)에서 첫 누름 뒤 소리 마디(발진기·잡음 시작)가
실제로 만들어지는지, 소리 단추가 정말 끄는지 센다.

## 측정
- `arcade/kit/browser-check.cjs`에 AudioContext 계측: 게임마다 시작 누름 뒤 9초 기다림 동안·긋기/톡 동안 소리 마디 수, AudioContext 상태.
- 끄기: 한 게임에서 '🔊' 단추를 누른 뒤 톡 5번 → 새 소리 0이어야 함. 다른 게임 단추 글자도 '꺼짐'으로 바뀌어야 함(소리 상태는 페이지 전체 하나).

## 폐기 기준
- 세 게임 모두 이미 소리가 나고 끄기도 맞으면 코드 변경 없이 점검 도구만 남긴다(점검 추가는 채택).
- 고친 것이 verify를 깨면 되돌림.

## 결과 — 채택 (점검 추가 + 버그 하나 고침)
- 실제 브라우저(390px, 헤드리스 Chromium)에서 시작 누름 뒤 AudioContext `running`, 세 게임 모두 소리 남:
  | 게임 | 9초 기다림 | 긋기 3·톡 5 |
  |---|---|---|
  | 🪶 무게 훔치기 | 0 | 33 |
  | ⏪ 한 물건만 되감기 | 9 | 142 |
  | ↔️ 크기 바꾸기 | 11 | 105 |
  (소리 마디 = 발진기·잡음 시작 수, 소리 하나에 1~5마디)
- 끄기: 끈 뒤 톡 5번에 새 소리 0 — 맞음.
- **버그**: 소리 상태는 페이지 전체에 하나인데 단추 글자는 누른 게임 것만 바뀌었다(1번 게임에서 끄면 2·3번 단추는 '🔊 소리 켜짐'인 채 소리는 꺼짐 → 그 단추를 누르면 글자는 그대로인데 소리가 다시 켜짐). `play.ts`에서 모든 단추를 같이 다시 그리게 고침 → 셋 다 '🔇 소리 꺼짐' 확인.
- 무게 훔치기는 기다리는 9초 동안 소리가 없다(처음 10초 안전 기준과 맞음 — 세상이 조용히 기다림). 손대면 바로 남.
