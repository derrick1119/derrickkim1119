# 0034 — 다음 차례 미리 만들기: 중력 쏟기 (메뉴 7번, 16라운드 답 대기 중)

16라운드(줄줄이 오리 한 게임, 좋아/별로)의 답을 기다리는 동안 다음 차례 하나를 미리 만든다(PROTOCOL '아이디어 메뉴 먼저').
**레지스트리·계기판에는 올리지 않는다.** 16라운드에서 '좋아'면 17라운드는 줄줄이 오리 vs 중력 쏟기다. '별로'면 중력 쏟기 + 다음 하나로 연다.

## 설계 (메뉴 그대로, 기준 9 '조작 최소')
- 조합: 합치기(2048류) × 중력 뒤집기 · 스와이프. 손이 하는 일은 **한 번 밀기**뿐이다.
- 와우: 밀면 유리병 전체의 중력이 그쪽으로 바뀐다. 구슬이 와르르 쏟아지고, 같은 숫자끼리 부딪히는 족족 합쳐진다(연쇄).
- 첫 3초: 바닥에 가라앉은 '1' 구슬 더미를 한 번 밀면 '5연쇄!'까지 터진다.
- 목표·보상
  - 판마다 목표 구슬(1판 5 → 2판마다 +1)을 정해진 밀기 횟수(4~7번) 안에 만들면 통과한다.
  - 남은 횟수로 별을 받는다. 남은 횟수의 절반(최대 2)은 다음 판 보너스가 된다.
- 하는 일이 바뀐다(2판 간격):

  | 판 | 새로 나오는 것 | 하는 일이 어떻게 바뀌나 |
  |---|---|---|
  | 2 | 돌 | 안 합쳐진다. 옆에서 합치면 깨진다 |
  | 4 | 무지개 | 아무 구슬과 합쳐진다 |
  | 6 | 폭탄 | 3번 밀면 터진다 → 큰 구슬을 멀리 둔다 |
  | 8 | 말뚝 | 흐름이 갈라진다 |
  | 10 | 얼음 | 옆에서 합쳐야 풀린다 |

## 측정 지표 · 폐기 기준
- 게이트: 숙련 격차 ≥ 3 · 못하는 봇 ≥ 5초 · 잘하는 봇 중앙값 30초~3분 · 규칙 ≤ 3줄 · 펼쳐짐(잘함 2분) ≥ 4.
- 다듬기 두 번 뒤에도 미달이면 보류하고 다음 차례(되감기 골프)로 넘어간다.

## 다듬은 과정
1. **초판: 판이 1초 만에 끝났다.**
   - 원인: 처음 더미에 작은 구슬이 너무 많았고, 판마다 밀기를 6번 이상 줬다.
   - 결과: 아무렇게나 미는 봇도 7판까지 갔다(격차 약 1.3×).
   - 손본 것: 처음 더미를 '목표 구슬 무게의 80~85%'로 정했다.
   - 손본 것: 더미를 합치지 않고 바닥에 가라앉혀 두게 했다. 첫 밀기에 와르르 쏟아진다.
   - 손본 것: 밀기를 4번 + 4판마다 +1로 줄였다.
2. **격차 2.1~2.4×에 머물렀다.**
   - 손본 것: 잘하는 봇이 두 번 밀기까지 내다보게 했다(4×4 방향 흉내).
   - 결과: 격차 3.1× 통과.
3. **새것이 30초 안에 거의 다 나왔다(펼쳐짐 6.8/7/7).** 판이 5초 남짓이라 그렇다. 특별 구슬을 2판 간격으로 늦췄다.
4. **스크린샷이 듬성듬성했다.**
   - 손본 것: 구슬을 키우고(반지름 0.038 + 0.011·단계), 목표를 5부터 시작했다(1판에 '1' 구슬 13개쯤).
   - 손본 것: 위쪽 정보 띠에 어두운 바탕을 깔았다. 중력이 위로 바뀌면 구슬이 글자를 가려서다.
   - 찾은 것: 스크린샷 도구가 스와이프를 3틱 동안 유지해 한 번에 세 번 미는 버그가 있었다(도구만, `runBot`·`evaluate`는 이미 비움). 고쳐서 다시 찍었다.

## 결과 (24판 중앙값)

| 지표 | 값 | 게이트 |
|---|---|---|
| 재미 | 0.858 | — |
| 펼쳐짐 30/60/120초 | 4.3 / 5.6 / 5.9 | 2분 ≥ 4 ✅ |
| 못하는 봇 펼쳐짐 | 3.1 / 3.3 | — |
| 숙련 격차 | 3.57× | ≥ 3 ✅ |
| 못하는 봇 생존 | 31.6초 | ≥ 5초 ✅ |
| 잘하는 봇 생존 | 70.8초 | 30초~3분 ✅ |

게이트를 모두 통과했다. 17라운드를 기다린다.

## 남은 의문
- 물리라서 같은 밀기가 늘 같은 결과는 아니다. 그래도 내다보는 봇이 3.6배 나으니 판단이 통한다.
- 다만 사람이 '두 번 앞'을 읽을지는 모른다. 오너 판정으로 본다.
