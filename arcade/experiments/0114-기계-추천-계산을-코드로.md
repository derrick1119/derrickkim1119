# 0114 — 기계 추천 1·2를 계기판이 직접 계산 (38라운드 판정 대기 중)

## 가설
기계 추천 1(재미 1위)·2(버릇 ★3 최저)는 지금까지 사람이(공장 세션이) `eval.json`을 보고 STATE·`ab.json`에 손으로 적었다.
동률 규칙도 글로만 있다(38라운드: 재미 1·1 동률 → 격차, 버릇 ★3 0·0·0 동률 → 버릇 격차). 계산을 `arcade/picks.ts` 하나로 두고
계기판과 테스트가 같은 함수를 쓰면, 라운드를 열 때 손으로 잘못 적는 일을 테스트가 잡는다.

## 측정
- `machinePicks(reports)` → `{ pick1, pick2 }`. pick1 = 재미 최고(차 < 0.005면 숙련 격차 큰 쪽), pick2 = 버릇 ★3 최저(차 < 0.005면 버릇 격차 큰 쪽).
- 테스트: 동률 규칙 단위 시험 + 열린 라운드 `ab.json`의 `machinePick`·`machinePick2`가 계산과 같다(지금 eval.json에 그 게임이 다 있을 때만).
- 계기판 열린 라운드 칸 아래에 '기계 추천(참고만)' 한 줄.

## 폐기 기준
- 38라운드 손 기록(되감기·되감기)과 계산이 다르면 → 어느 쪽이 틀렸는지 먼저 밝히고, 규칙이 글과 다르면 글에 맞춘다(기록을 몰래 바꾸지 않음).
- verify 실패면 되돌림.

## 결과 — 채택
- `arcade/picks.ts` `machinePicks()` 하나로 계산. 38라운드: 추천 1 = 되감기(재미 1·1 동률 → 격차 32.87 > 11.82), 추천 2 = 되감기(버릇 ★3 0·0·0 동률 → 버릇 격차 6.69). 손 기록과 같음.
- `tests/arcade-picks.test.ts` 3개: 동률 규칙 둘 + 열린 라운드 기록 = 계산. 다음 라운드를 열 때 `ab.json` 추천을 계산과 다르게 적으면 verify가 막는다.
- 계기판 열린 라운드 칸 아래 '기계 추천(참고만)' 한 줄(390px 가로 스크롤 없음 확인).
- 한계: 셋 중 둘 이상이 동률이면 다음 기준 하나로만 가른다. 그것도 같으면 등록 순서.
