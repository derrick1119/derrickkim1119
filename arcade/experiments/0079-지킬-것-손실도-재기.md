# 0079 — 계기판: 하트 말고 '지킬 것'(판 안 자원) 손실도 재기

## 왜
- 0078에서 '처음 몇 초 하트 손실'을 계기판·테스트에 넣었다.
- 그런데 32라운드 빙판·도끼는 손 안 대고 8초에 불빛 1개·판자 1장을 잃었는데도 0%로 나왔다. 하트가 아니라 판 안 자원이었기 때문이다.
- 또 팽이는 하트 칸 이름이 `lives`여서 하트 자체를 못 읽었다.

## 가설
- `GameDef`에 선택 칸 `guard(s)`(지면 줄어드는 판 안 자원의 수: 이글루 하트·체력·쿠키·알·불빛·판자)를 두고, 하트(`hearts` 또는 `lives`)와 함께 보면 손대기 전에 잃는 문제를 모두 잡는다.

## 측정 지표 · 폐기 기준
- 고치기 전 코드(c006619)의 빙판·도끼를 '손 안 대고 10초'에서 잡아야 한다(0%보다 커야 함). 공룡은 계속 잡혀야 한다.
- 지금 코드 6개는 모두 0%여야 한다(테스트에 '손 안 대고 10초에 하트·지킬 것을 잃지 않는다').
- **폐기 기준**: 고치기 전 빙판·도끼를 못 잡으면 되돌린다.

## 결과
- `GameDef`에 선택 칸 `guard(s)`를 더하고 32라운드 6개가 내보내게 했다: 펭귄 이글루 하트 · 해적 체력 · 팽이 쿠키 · 공룡 알 · 빙판 불빛 · 도끼 판자. 하트 칸은 `hearts`가 없으면 `lives`(팽이)도 읽는다.
- 24판(계기판 시드):

| 게임 | 고치기 전(c006619) 손 안 댐 / 느린 사람 | 지금 손 안 댐 / 느린 사람 |
|---|---|---|
| 🦖 공룡 | **100% / 100%** | 0% / 0% |
| 🪓 도끼 | **100%**(판자) / 0% | 0% / 0% |
| 🧊 빙판 | 0% / 0% | 0% / 0% |
| 🐧 · 🪝 · 🌀 | — | 0% / 0% |

- 도끼는 이번에 잡혔다(0078에선 0%). **빙판은 여전히 못 잡는다**: 입력 없음으로 30초를 돌려도 고치기 전 빙판은 불빛을 잃지 않는다. 브라우저에서 8초에 잃은 건 계기판 쪽 입력(시작 클릭 등) 때문으로 보인다.
  - '가운데를 한 번 누르는 시작 클릭'을 흉내 내 보니 고치기 전 빙판은 3.4초에 잡혔지만, 지금 해적도 100%로 잡혔다(해적 1판은 톡 한 번이면 무조건 술통을 끌어 판이 시작됨). 브라우저에서 지금 해적은 8초를 그냥 둬도 아무것도 안 잃었으니 거짓 경보다. 그래서 시작 클릭 흉내는 넣지 않았다.
- **느린 사람은 하트만 본다**: 지킬 것까지 보면 해적 88%·빙판 96%가 '잃음'으로 나왔다. 1.5초마다 한 번 아무 데나 누르는 사람이 체력·불빛 하나 잃는 건 판을 지는 게 아니라서 뺐다.
- 계기판 한 줄: "첫 몇 초: 손 안 대고 10초에 하트·지킬 것을 잃은 판 0% · 3초 늦게 시작한 느린 사람이 13초 안에 하트를 잃은 판 0%".
- 테스트 '손 안 대고 10초에 하트도 지킬 것도 잃지 않는다'(시드 4개) — 6개 모두 통과.

## 판정
- 채택(부분). 도끼처럼 판 안 자원을 손대기 전에 잃는 문제는 이제 기계가 잡는다. 계기판 쪽 입력으로만 생기는 문제(빙판)는 여전히 브라우저에서 직접 기다려 봐야 한다 → 통합 때 '손 안 대고 8초' 브라우저 확인을 계속한다.
