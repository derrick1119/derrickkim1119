- 먼저 `<작업 폴더>/diorama/BRIEF37.md`를 끝까지 읽고 그대로 따른다.
- 네가 쓰는 저장소 파일은 `arcade/games/<id>.ts` 하나뿐. 임시 파일은 `diorama/<id>/`에만.
- **git은 읽기만**(`git show`·`git log`만 — `git status`·`git diff`도 쓰지 말 것: 0103에서 잠금 파일이 남아 커밋이 막혔다). `git add/commit/push/stash/checkout/reset/restore/clean` 금지 — 같은 작업 폴더에서 다른 에이전트 5명과 오너 쪽 세션이 동시에 일한다. 오너 쪽 세션이 네 파일을 '작업 중 사본'으로 커밋할 수 있다(그래도 계속 고치면 된다). 남의 파일은 건드리지 않는다.
- 이번 라운드 1순위는 **살아 움직이는 세계**: 세상은 저절로(느긋하게) 움직이고, 손가락은 톡 또는 한 번 긋기로 끼어든다. 카드·단추로 고르는 구조·기지 지키기 금지.
- 손짓은 과제에 적힌 하나만(톡 또는 한 번 긋기). 꾹 모으기·좁은 타이밍·당겨 겨누기·연타·문지르기 금지. 끼어들 여유 1초 이상, 처음 10초는 안 해도 잃지 않음.
- 버릇 봇 둘(`<var>Habit`, `<var>Habit2`)을 export. 보고에 레지스트리에 넣을 줄을 그대로 적어라: `{ game: ..., dumb: ..., smart: ..., habits: [..., ...] }`.
