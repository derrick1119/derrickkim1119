# 게임 발견 공장 백로그

맨 위부터. 사이클당 하나.

- [ ] **사람 기준 펼쳐짐**: 지금 펼쳐짐은 잘하는 봇 판으로만 잰다. 처음 하는 사람은 2분 안에 몇 가지를 보나? 못하는 봇 판의 펼쳐짐도 재서 계기판에 같이 보이고, 못하는 봇이 30초 안에 2가지도 못 보면 경고 (등불 마을은 못하는 봇이 첫 밤에 끝남).
- [ ] **10라운드 승자 다듬기 후보** — 등불 마을: 곡식이 차면 설계도 둘 중 하나를 눌러 고르기(오너가 고른 '직접 고르는 건설') · 판 끝에 마을 전경. 밧줄 동굴: 판 끝에 내려온 길 지도 · 구역마다 도감(처음 본 것 모으기).
- [ ] **'가리키기' 조작의 다른 조합**: 누른 곳에 바로 일어나는 조작이 이번 두 게임의 공통점. 오너가 이 조작을 좋아하면 다음 라운드도 가리키기 × 다른 핵심 놀이(예: 가리키기 × 3매치 × 낮과 밤).
- [x] **10라운드 두 게임은 새 기준 셋으로** (0023: 등불 마을 · 밧줄 동굴): 취향 쪽(지키고 키우는 내 기지, 궤도 수비 재탕 금지) + 탐험 쪽. 둘 다 손에 붙는 조작 · reveals 2분 4가지↑ · juice 필수. 스크린샷으로 "밋밋한가?" 자문.

- [x] **행성 수호대 2 (챔피언 확장, 별도 게임으로)** (0021, 8라운드에 올림): 원버튼 제약이 풀림 → 조작을 넓힌다. 후보: 행성을 탭하면 광석으로 원하는 건물을 직접 골라 짓기(자동 대신 선택), 수호선 편대를 드래그로 회전, 건물 레벨업(같은 건물 두 번이면 2단계), 판이 끝나면 기지 전경. 완성되면 "행성 수호대 vs 행성 수호대 2" 라운드로 오너에게 묻는다(5라운드처럼).
- [ ] ~~챔피언 다듬기 — 궤도 수비~~ (챔피언이 바뀜): 오너가 고른 게임. 사람이 처음 해 볼 때 막히는 지점(못하는 봇이 10초에 죽음 — 첫 적 몇 마리는 천천히 한쪽에서)을 봇 기록으로 찾고, 손맛(처치 효과·강화 연출·최고 기록 표시)을 더한다. 규칙은 바꾸지 않는다.
- [x] ~~**재미 지표에 '외부 압박' 추가**~~ (0014 폐기: 2라운드 순서를 못 맞힘. 남은 가설: 원버튼 선호·성장 연출 선호): 2라운드에서 봇 추정이 빗나감. 이긴 게임은 위협이 바깥에서 계속 다가오고, 진 게임은 자기 꼬리만 위협. 시간당 '임박한 위협'(0.5초 안에 질 수 있는 상황) 비율을 재는 항목을 넣고, 1·2라운드 결과를 둘 다 맞히는지 확인.
- [x] **4라운드 후보 미리 만들기 — 성장 가설 검증용** (0015 밟기 러너, 격차 15.3×): 원버튼 + 처치/수확 → 무작위 강화가 있는 새 조합 하나 (예: 원버튼 × 슬링샷 × 랜덤 강화). 3라운드가 끝났을 때 도전자 풀이 비지 않게.
- [x] **봇에 사람 반응 속도 공통 적용** (0016: core.REACT=3, 전 게임 재평가, 게이트 전부 유지): 0015에서 매 틱 완벽 반응 봇은 어떤 판도 안 죽어 난이도를 잴 수 없었음 → `runBot`에 반응 간격(기본 3틱) 옵션을 두고 모든 게임에 같은 조건으로 재평가.
- [ ] **재미 지표에 '성장' 항목** (지난 라운드 게임은 폐기됨 → 검증은 git 기록의 옛 코드로, 또는 앞으로의 라운드로): 오너 선택 3번 중 2번이 성장 있는 쪽 승리, 봇 지표는 1/3만 맞힘. 게임 정의에 "판 중 강화 횟수"를 기록하는 훅을 두고 재미 추정에 반영 → 지난 3라운드를 모두 맞히는지 확인(맞히면 채택).
- [x] ~~**원버튼 계열 더 만들기**~~ (오너: 원버튼 고집 안 해도 됨 · 게임은 폐기됨) (원버튼 + 성장 위주): 1라운드 승자가 원버튼 — 다음 후보도 원버튼 조합을 우선 (예: 원버튼 × 타이밍 쌓기 × 머지).

- [x] **새 조합: 서바이버 × 원버튼 궤도** (0012 궤도 수비: 격차 22.6×, 게이트 통과) — 공격은 자동, 플레이어는 탭으로 공전 방향만 뒤집는다. 적이 사방에서 몰려온다 (탄막 서바이버 × 원버튼 × 궤도).
- [ ] **새 조합: 투버튼 × 2048 합치기 (계단 없이)** — 0012에서 재설계 필요 판정: 좌/우 버튼으로 계단 오르기는 특정 게임의 핵심 조작 그대로라 피한다. 대신 "왼쪽/오른쪽 통에 떨어지는 숫자 블록을 나눠 담고, 같은 수가 닿으면 합쳐진다" 같은 투버튼 분류 × 머지.
- [ ] **새 조합: 타이밍 쌓기 × 디펜스** — 쌓은 블록이 성벽이 되고, 적이 성벽 높이보다 높이 날아오면 진다 (타이밍 쌓기 × 타워 디펜스).
